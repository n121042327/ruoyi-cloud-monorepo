# 术语表

本表是全项目的名词权威。文档、接口、数据库字段命名都以这里的 `English` 列为准。

## 1. 组织与租户

| 中文 | English | 定义 | 易混淆点 |
|---|---|---|---|
| 租户 | `tenant` | 一个教育机构或教育集团，是数据隔离的最高单位 | 不是学校。一个租户下辖多所学校 |
| 学校 | `school` | 租户下的一所学校，是教学数据的边界 | 首轮不跨校共享教学数据 |
| 校区 | `campus` | 学校内的物理校区，一个学校可有多个校区 | 校区不改变数据权限边界，仅作位置维度 |
| 学段 | `stage` | 小学、初中、高中等阶段 | 与年级是固定对应关系，不可自由配置 |
| 年级 | `grade` | 某个学段下的具体年级，如"高一" | 与"入学年份"组合成"2026 级高一年级" |
| 年级组 | `grade_group` | 同一学校同一学段下的年级集合，用于设年级主任 | 不是行政组织，是数据范围单位 |
| 学年 | `academic_year` | 如 2026-2027 | 跨自然年 |
| 学期 | `term` | 学年内的上学期 / 下学期 | 当前学年学期全局唯一 |
| 学科 | `subject` | 语文、数学、物理等 | 与"课程"不同，学科是稳定的分类 |

## 2. 人员

| 中文 | English | 定义 | 易混淆点 |
|---|---|---|---|
| 学生 | `student` | 学籍主体 | 一名学生在一个租户内只有一条主体记录 |
| 学号 | `student_no` | 学生编号 | **跨校唯一，即全租户内唯一** |
| 教师 | `teacher` | 教职工主体 | 一名教师可跨校任教 |
| 工号 | `teacher_no` | 教师编号 | 唯一性口径待模块 PRD 明确 |
| 教育角色 | `edu_role` | 校领导、教务主任、年级主任、班主任、任课教师 | 与系统权限角色不同，教育角色决定**数据范围** |
| 任教关系 | `teaching_assignment` | 教师在某个学年学期、某个学科、某个班级的授课关系 | 是数据权限"任课教师"范围的依据 |
| 监护人 | `guardian` | 学生的法定监护人或联系人 | 一名学生可有多个监护人 |

## 3. 班级与学籍

| 中文 | English | 定义 | 易混淆点 |
|---|---|---|---|
| 行政班 | `administrative_class` | 学生日常管理的固定班级 | 一名学生同一时间只能属于一个行政班 |
| 教学班 | `teaching_class` | 按学科或选科组合临时组织的授课班级 | 与行政班完全独立，不属于同一约束 |
| 班级花名册 | `class_roster` | 某班级在某个学年学期的学生名单 | 是"关系"，不是学生属性 |
| 学籍状态 | `enrollment_status` | 在读、休学、退学、毕业、转出等 | 与"是否在当前班级"是两个维度 |
| 在校记录 | `student_school_record` | 学生在某学校的学籍期间记录 | 跨校转学会产生多条记录 |
| 升班 | `promotion` | 学年切换时把学生升入下一年级与班级 | 不修改历史记录，新增下一学年的关系 |
| 留级 | `retention` | 学生留在原年级 | 与升班在同一次操作中处理 |
| 调班 | `class_transfer` | 同一学年学期内更换行政班 | 保留原班级关系的历史 |
| 毕业 | `graduation` | 学生完成学段学习并离校 | 学籍状态变为毕业，不再是"在读" |
| 休学 / 复学 | `suspend` / `resume` | 学籍暂停与恢复 | 复学需校验当前处于休学状态 |
| 退学 | `withdraw` | 学生终止学业离校 | 与毕业不同 |
| 跨校转学 | `cross_school_transfer` | 学生在同一租户内从 A 校转到 B 校 | **允许**；转出校与转入校分别留痕 |

## 4. 选科与教学

| 中文 | English | 定义 | 易混淆点 |
|---|---|---|---|
| 3+1+2 | `stream_312` | 新高考选科模式 | 物理 / 历史二选一，化学 / 生物 / 思想政治 / 地理四选二 |
| 首选科目 | `primary_subject` | 物理或历史 | 二选一 |
| 再选科目 | `secondary_subject` | 化学、生物、思想政治、地理 | 四选二 |
| 选科组合 | `subject_combination` | 一名学生的一套选科结果 | 组合不等于行政班 |
| 选科生效 | `stream_effective` | 选科在某个学年学期开始生效 | 带生效期与变更历史 |
| 选科截止日期 | `stream_deadline` | 学校配置的选科开放截止时间 | 逾期需校级管理员审批 |
| 选科变更申请 | `stream_change_request` | 逾期后发起的变更单 | 需要审批流 |

## 5. 权限与数据范围

| 中文 | English | 定义 | 易混淆点 |
|---|---|---|---|
| 数据范围 | `data_scope` | 一个用户能看到哪些数据的边界 | 与"功能权限"（能不能进这个页面）是两个维度 |
| 功能权限 | `function_permission` | 是否有权执行某个操作 | 由 Sa-Token 权限串控制 |
| 范围类型 | `scope_type` | 平台 / 租户 / 学校 / 年级 / 班级 / 个人 | 数据范围判定的核心字段 |
| 平台运营 | `platform_ops` | 平台方人员 | 查看、修改、导出是三项独立授权 |
| 集团用户 | `group_user` | 集团侧人员 | 不自动获得学校教学数据 |

## 6. 工程术语

| 中文 | English | 定义 |
|---|---|---|
| 教育服务 | `ruoyi-edu` | 承载教育域业务的 Spring Boot 模块 |
| 系统服务 | `ruoyi-system` | 承载租户、用户、角色、菜单、部门的现有模块 |
| 迁移脚本 | `migration` | 建表与结构变更的 SQL 脚本，是数据库结构的权威来源 |
| 基线 | `baseline` | 已冻结、可作为下游依据的产物 |
