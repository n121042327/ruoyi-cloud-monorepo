# 角色与场景

## 1. 角色清单

角色按"数据范围"而不是"职级"区分，因为本项目最重要的约束就是数据范围。

| 编号 | 角色 | 归属 | 默认数据范围 | 主要职责 |
|---|---|---|---|---|
| PER-PLATFORM-OPS | 平台运营 | 平台 | 全平台（查看 / 修改 / 导出分别授权） | 开租户、开学校、排查问题、导出数据 |
| PER-TENANT-ADMIN | 租户管理员 | 集团 | 本租户组织结构与非教学配置 | 维护学校、学年学期、学科、教育角色 |
| PER-GROUP-EXPERT | 集团专家 | 集团 | 集团自有数据 | 教研、标准制定（首轮只读） |
| PER-GROUP-LEADER | 集团领导 | 集团 | 集团自有数据 | 查看集团层面统计（首轮不实现分析） |
| PER-SCHOOL-LEADER | 校领导 | 学校 | 本校全部教育数据 | 审批选科变更、查看全校名单 |
| PER-ACADEMIC-DIRECTOR | 教务主任 | 学校 | 本校全部教育数据 | 编班、导入、学年升级操作 |
| PER-GRADE-LEADER | 年级主任 | 年级 | 所负责年级 | 年级内班级与学生管理 |
| PER-HOMEROOM | 班主任 | 班级 | 所负责班级 | 班级花名册、学生联系方式与监护人信息维护 |
| PER-SUBJECT-TEACHER | 任课教师 | 班级 + 学科 | 任教班级的必要资料 + 本人所授学科数据 | 查看任教班级学生与教学班名单 |
| PER-STUDENT | 学生 | 本人 | 本人数据 | 查看自己的班级与选科（首轮只读） |
| PER-GUARDIAN | 家长 | 本人子女（可多个） | 每个孩子按各自学校范围收窄 | 查看子女信息（后续小程序）。一个家长可有多个孩子，可能落在同班、同年级、同校、不同校甚至不同集团 |

## 2. 场景

场景编号规则 `SCN-<域>-<序号>`。每个场景都必须能对应到原型页面与接口。

### SCN-ORG-01 平台运营开通租户

1. 平台运营进入租户管理，新建租户，填写机构名称、租户套餐、到期时间、账号上限
2. 系统创建租户记录，并初始化该租户的管理员账号
3. 平台运营为租户创建第一所学校，填写学校名称、学段、办学类型
4. 全流程写入审计日志，记录操作人与时间

成功标准：租户与学校创建成功；审计日志可按操作人检索。

### SCN-ORG-02 租户管理员维护学年学期

1. 租户管理员进入学年学期管理，新建学年（如 2026-2027）
2. 在该学年下创建学期（上学期 / 下学期），设置起止日期
3. 设置当前学年学期

成功标准：同一学校同一时间只有一个"当前学年学期"；历史学年可查询但不可设为当前。

### SCN-ORG-03 租户管理员维护学科

1. 选择学段，维护该学段的学科清单（语文、数学、外语、物理、历史、化学、生物、思想政治、地理等）
2. 为学科设置编码、名称、排序、是否参与 3+1+2 选科

成功标准：学科清单可在班级与选科配置中引用。

### SCN-GRADE-01 教务主任维护年级

1. 进入年级管理，选择学校与学段
2. 新增年级，系统按"入学年份 + 学段"生成年级名称（如 2026 级高一年级）
3. 为年级指定年级主任

成功标准：同一学校同一学段下年级名称不重复；年级与学段的对应关系固定，不允许跨学段。

### SCN-CLASS-01 教务主任创建行政班

1. 进入班级管理，选择学年学期、年级
2. 新增班级，填写班级名称、班级类型（行政班）、班主任、教室
3. 保存后进入班级详情维护花名册

成功标准：同一学校、同一学年学期、同一学段下班级名称不重复。

### SCN-CLASS-02 教务主任维护班级花名册

1. 进入班级详情，通过"添加学生"从本校学生池选择学生
2. 系统校验该学生在本学年学期是否已有行政班
3. 若已有，提示冲突并提供"调班"入口；若没有，加入本班

成功标准：一个学生同一学年学期只能属于一个行政班；调班保留历史记录。

### SCN-STU-01 教务主任新增单个学生

1. 进入学生管理，点击新增
2. 填写姓名、性别、入学年份、学段、年级，以及可选的全国学籍号、证件类型与号码、出生日期
3. 按需填写监护人信息与联系方式（上限 3 名）
4. 选择归属行政班（可留空，后续在班级模块编班）
5. 保存，系统统一发号并在页面展示新学号

成功标准：学号由系统统一发号且**全平台唯一**；必填字段校验通过；保存后可在列表检索到；
学生账号自动创建，登录名为 `s` + 学号。

### SCN-STU-02 班主任修改学生监护人信息

1. 班主任进入本班花名册，打开某个学生
2. 修改监护人姓名、关系、联系电话、备注
3. 保存

成功标准：只有本班班主任与更高级别授权者能改；修改写入审计日志，记录修改前后值。

### SCN-STU-03 批量导入学生

1. 下载模板，按模板填写
2. 上传文件，系统解析并做校验（学号重复、班级不存在、必填缺失、格式错误）
3. 展示校验结果：成功行、失败行与失败原因
4. 确认后异步导入，返回任务编号，可查看进度与结果

成功标准：5000 行以内单次导入成功；失败行可下载并修正后重传；重复导入不产生重复数据。

### SCN-TEACHER-01 教务主任维护教师并设置任教

1. 新增教师，填写工号、姓名、联系方式、所属学校
2. 为教师分配教育角色（年级主任 / 班主任 / 任课教师）
3. 设置任教关系：选择学年学期、学科、行政班或教学班

成功标准：教师可跨校任教；任教关系影响其数据可见范围。

### SCN-PROMO-01 学年升级

1. 教务主任选择"从 2026-2027 学年升级到 2027-2028 学年"
2. 系统生成升级预览：每个班级的学生将升入哪个新年级、新班级
3. 教务主任调整个别学生的去向（留级、转班、毕业）
4. 确认后异步执行，返回任务编号
5. 执行完成可查看结果，失败项可重试

成功标准：历史学年的班级与学生关系完整保留；重复点击不会产生重复数据；毕业学生不再出现在在读名单。

### SCN-PROMO-02 学籍异动

支持：转入未报到、报到、休学、复学、出国、失踪、转出、毕业、结业、肄业、退学、开除、死亡、跨校转学、留级。

1. 在学生在校记录上发起异动，选择类型、生效日期、原因
2. 系统校验前置条件（如复学要求当前为休学状态）
3. 保存后更新学籍状态，保留状态变更历史

成功标准：状态流转合法；跨校转学需要转出与转入双方记录，转入校接收后学生状态为"转入未报到"，
实际报到才转为在读；义务教育阶段不得开除。

### SCN-STREAM-01 学生选科

1. 学生在选科开放期内进入选科页面
2. 在物理 / 历史中二选一
3. 在化学 / 生物 / 思想政治 / 地理中四选二
4. 提交

成功标准：组合合法；同一时间只有一条生效选科；变更留有历史。

### SCN-STREAM-02 逾期选科变更审批

1. 截止日期后，学生或班主任发起变更申请
2. 系统提示已逾期，需要校级管理员审批
3. 校级管理员在待办中审批，通过后生效，驳回则保持原选科

成功标准：审批过程留痕；未审批通过的变更不生效。

### SCN-IMP-01 导出名单

1. 在列表中设置筛选条件
2. 点击导出
3. 系统按当前用户的**数据范围**生成导出文件

成功标准：导出内容与列表可见范围一致；导出行为本身写入审计日志。

### SCN-GUARDIAN-01 家长关联多个孩子

1. 家长用手机号注册账号，提交孩子信息（姓名、证件号后四位、学校）申请关联
2. 学校侧（班主任或教务主任）审核通过后建立关联
3. 家长登录后看到孩子列表，逐个切换查看

必须覆盖的五种分布：

| 场景 | 说明 | 对设计的要求 |
|---|---|---|
| 同班 | 两个孩子在同一行政班 | 关联表不限制数量 |
| 同年级不同班 | 同一年级两个班 | 家长落地范围要合并两个班 |
| 同校不同年级 | 同一学校跨年级 | 家长落地范围要合并多个年级 |
| 不同学校 | 同一集团下两所学校 | 关联跨学校租户，需按学校分别授权与过滤 |
| 不同集团 | 两个不同集团的学校 | 关联跨根租户，两集团的授权互不影响 |

成功标准：

1. 一个家长账号可关联任意数量的孩子，无数量上限
2. 切换到某个孩子时，该次请求的数据范围按**该孩子所属学校**收窄
3. 跨集团场景下，家长对 A 集团孩子的可见性不会带来 B 集团数据的可见性
4. 首轮只建数据模型，不实现家长端界面（见 BR-ACCOUNT-010）

### SCN-GUARDIAN-02 学生登录

1. 学校批量导入学生后，系统按 `s` + 学号生成学生登录名
2. 学生首次登录使用学校下发的初始密码，强制修改
3. 小学生不采集手机号，登录不依赖短信

成功标准：同一根租户内登录名唯一；跨校转学后登录名不变；导入不产生重复登录名。
