## 1. 验收怎么进行

三层验收（需求 / 实现 / 交付），本轮只做**需求验收**。
用例状态五选一：`通过` / `失败` / `未执行` / `不适用` / `已失效`。
缺陷分级与通过判定与 `modules/student/acceptance.md` 一致：P0 与 P1 未关闭时不得判定通过。

## 2. 测试数据与账号准备

### 2.1 必备账号

| 账号 | 角色 | 数据范围 | 用途 |
|---|---|---|---|
| `ops_admin` | 平台运营 | 全平台 | 跨校与留痕用例 |

### 2.2 必备数据

| 数据 | 数量 | 说明 |
|---|---|---|
| 学校租户 | 2 个（A 校、B 校） | 跨校用例 |

## 4. 权限与数据范围验收用例

任何一个失败即判定本模块不通过。

| 用例 | 场景 | 期望结果 |
|---|---|---|
| `AC-TERM-101` | 缺 `tenant_id` 调用学年列表 | 拒绝，不返回数据 |
| `AC-TERM-102` | 缺 `school_id` 且角色不是平台运营 | 拒绝 |
| `AC-TERM-103` | 数据范围为空的账号调用列表 | 返回空列表，不返回全量（`DS-DENY-03`） |
| `AC-TERM-104` | A 校账号按 B 校学年 ID 请求详情 | 返回空 / 无权限并记录拒绝原因 |
| `AC-TERM-105` | 教务主任尝试新建学年 | 拒绝（只读） |
| `AC-TERM-106` | 集团租户管理员为下属学校新增学年 | 允许（`DS-10`） |
| `AC-TERM-107` | 学年人数统计接口用不同账号调用 | 统计值随数据范围变化（`DS-DENY-08`） |
| `AC-TERM-108` | 非平台运营角色尝试调用"设为当前"接口 | 拒绝 |
