## 0. 怎么读这份文档

需求编号 `REQ-TERM-xxx`。公共前置的编号只引用不复制。

学年学期是**几乎所有业务对象的时间坐标**：班级挂在它上面、任教关系挂在它上面、
花名册挂在它上面、选科挂在它上面、升班从它出发。所以它不是一张字典表，
而是**历史可回溯性的载体**。

| 内容 | 归属 |
|---|---|
| 学年、学期、当前学年学期 | 本模块 |
| 班级、任教关系、花名册 | 各自模块（依赖本模块的学期 ID） |
| 升班的学年推进 | 升班与学籍异动模块（本模块提供学期清单） |
| 校历、节假日、作息时间 | 首轮不做 |

## 1. 模块定位与范围

### 1.1 解决什么问题

学年学期要保证两件事：

1. **任何业务数据都能定位到唯一的时间坐标**。同一名学生为什么在两个班？
   因为分属两个学年学期。没有这个坐标，历史关系无法解释。
2. **同一时间只有一个"当前"**。否则新建班级、新增学生、选科提交都不知道该落到哪个学期。

`BR-TERM-002` 到 `BR-TERM-006` 五条规则全部围绕这两点。

### 1.2 范围内

| 能力 | 说明 |
|---|---|
| 学年列表与检索 | 按学校、编码、状态筛选 |
| 新建学年 | 编码格式与日期范围校验 |
| 学期管理 | 每学年下的上学期 / 下学期 |
| 设为当前学年学期 | 唯一性与历史限制 |
| 归档 | 已有业务引用的学年只允许归档 |
| 引用检查 | 删除或归档前检查班级、任教关系、学籍关系的引用 |
| 审计 | 关键写操作留痕 |

### 1.3 范围外

| 不做 | 归属 |
|---|---|
| 集团统一校历 | 明确不做（`BR-TERM-001`） |
| 节假日、调休、作息时间 | 首轮不做 |
| 教学周、课时安排 | 首轮不做 |
| 升班的批量执行 | 升班与学籍异动模块 |
| 学期的自动切换 | 首轮不做，由租户管理员手工设置当前学年学期 |

### 1.4 上游依赖

| 依赖 | 用途 | 缺失后果 |
|---|---|---|
| `docs/10-prd/04-business-rules.md` | `BR-TERM-*` | 无法判定唯一性与归档约束 |
| `docs/10-prd/05-permission-matrix.yaml` | 功能权限 | 按钮显隐无依据 |
| `docs/10-prd/06-field-dictionary.yaml` | `academic_year_code`、`term_code`、`start_date`、`end_date`、`is_current` | 字段无定义 |
| 学校管理模块 | 学年所属学校 | 归属无法表达 |
| 班级、教师、学生、选科模块 | 引用检查的数据来源 | 无法判断能否删除 |

## 3. 术语与逻辑实体

### 3.1 术语

学年、学期的定义见 `03-glossary.md`。

本模块必须强调三个区分：

| 区分 | 说明 |
|---|---|
| 学年 vs 自然年 | 学年跨自然年（如 2026-2027 学年从 2026 年 9 月到 2027 年 7 月），编码用起始与结束自然年表示 |
| 学年 vs 年级 | 年级是学生的层级（高一、高二），学年是时间坐标。同一个"高一"在不同学年是两条年级记录（`BR-GRADE-003`） |
| 学期 vs 学段 | 学期是时间划分，学段是教育阶段，两者无关，避免混淆 |

### 3.2 逻辑实体

| 实体 | 含义 | 权威来源 |
|---|---|---|
| 学年 | 某校的一个学年，如 2026-2027 | 本模块（`edu_academic_year`） |
| 学期 | 学年内的上学期 / 下学期 | 本模块（`edu_term`） |

### 3.3 实体关系


## 6. 界面需求（阶段 2 原型输入）

### 6.1 页面清单

| 页面 ID | 页面名 | 类型 | 主要角色 |
|---|---|---|---|
| `PAGE-TERM-LIST` | 学年学期列表 | 列表页（按学年分组，可展开学期） | 租户管理员、校领导 |
| `PAGE-TERM-CREATE` | 新建学年 | 弹窗（md） | 租户管理员 |

| `PAGE-TERM-ARCHIVE` | 归档 | 弹窗（含引用检查结果） | 租户管理员 |

> 载体口径（2026-09-30，`CR-008` / `D-059`）：**表单类浮层统一用弹窗**；**详情类用抽屉**；含表格或分页的内容用独立页。

### 6.2 列表页要素

1. 顶部固定卡片：当前学年学期（醒目）
2. 筛选区：学校、学年编码、状态
3. 操作栏：新建学年
4. 主表格：按学年分组，展开后显示该学年的全部学期
5. 行内操作：编辑、学期管理、设为当前、归档

### 6.3 交互与跳转

| 触发 | 结果 |
|---|---|
| 点击"设为当前" | 二次确认并提示影响范围；历史学年按钮置灰 |
| 点击"归档" | 先展示引用检查结果，有引用时提示"只归档不删除"，无引用时提示"可删除但建议归档" |
| 点击"从上一学年延续" | 自动填充编码与日期，允许修改后提交 |
| 学期行内编辑 | 直接在展开区域内编辑日期后保存 |

### 6.4 页面状态

加载中骨架屏；空态提示"新建第一个学年"；无权限给说明与返回；
当前学年缺失时在页面顶部给出警示（会影响新建班级与设置任教关系）。

## 7. 数据需求

### 7.1 逻辑实体与字段

| 实体 | 关键字段 | 唯一性要求 |

| 按学年列学期 | `(academic_year_id, start_date)` |
| 引用检查按学期统计 | `(term_id)` 相关表的索引 |

### 7.3 审计要求

| 事件 | 记录内容 |
