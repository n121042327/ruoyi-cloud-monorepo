## 1. 验收怎么进行

三层验收（需求 / 实现 / 交付），本轮只做**需求验收**。
用例状态五选一：`通过` / `失败` / `未执行` / `不适用` / `已失效`。
缺陷分级与通过判定与 `modules/student/acceptance.md` 一致：P0 与 P1 未关闭时不得判定通过。

## 4. 权限与数据范围验收用例

任何一个失败即判定本模块不通过。

| 用例 | 场景 | 期望结果 |
|---|---|---|
| `AC-GRD-101` | 缺 `tenant_id` 调用年级列表 | 拒绝，不返回数据 |
| `AC-GRD-102` | 缺 `school_id` 且角色不是平台运营 | 拒绝 |
| `AC-GRD-103` | 数据范围为空的账号调用列表 | 返回空列表，不返回全量（`DS-DENY-03`） |
| `AC-GRD-104` | A 校账号按 B 校年级 ID 请求详情 | 返回空 / 无权限并记录拒绝原因（`DS-DENY-07`） |
| `AC-GRD-105` | 年级主任请求非负责年级的详情 | 返回空 |
| `AC-GRD-106` | 班主任请求本年级之外的年级详情 | 返回空 |
| `AC-GRD-107` | 任课教师请求年级在读学生统计明细 | 返回空或仅摘要，不含学生明细 |
| `AC-GRD-108` | 租户管理员访问年级教学统计接口 | 仅限组织配置范围；教学统计按 `DS-DENY-05` 判定，不因租户管理员身份放行 |
| `AC-GRD-109` | 批量指定年级主任时含一条越权年级 | 整体拒绝并说明原因（`DS-DENY-06`） |
| `AC-GRD-110` | 年级班级数统计接口用不同账号调用 | 统计值随数据范围变化（`DS-DENY-08`） |
