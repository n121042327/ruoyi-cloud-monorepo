- 本文件是新增版本补充，旧 PRD 保留原样，不覆盖其余冻结规则。

| 顺序 | 列名 | 必填 | 说明 |
|---|---|---|---|
| 1 | 学号 | 是 | 定位学生；学校侧访问仍须经过本校在校记录及数据范围校验 |
| 2 | 姓名 | 否 | 供核对；填写后与学号对应姓名不一致时，阻止该行执行；不替代学号定位 |
| 3 | 目标班级 | 是 | 按“学年＋年级＋班名”组合定位；限定当前学校、向导选择的目标学期与可操作范围；学年必须与向导上下文一致 |
| 4 | 班级类型 | 否 | 行政班 / 教学班；空值默认行政班；导入教学班时明确填写教学班 |

一行一个学生；仍按先校验、后确认异步执行的两阶段流程处理；同批次重复提交须幂等。
行政班关系唯一写入入口仍是班级管理；支持向已有行政班、已有教学班编入学生。
本文件不授权导入时创建班级。教学班的成员关系独立于行政班，不以行政班唯一关系约束替代教学班规则。

## 已确认的定位与核对规则

1. 班级定位采用学年、年级、班名组合，不采用推荐的班级编号方案。
2. 使用导入向导已有的目标学年学期上下文（`class-import-roster.html` 第 101—107 行），避免同学年两个学期的目标混淆。
3. 姓名可不填；填写后与学号对应姓名不一致，阻止该行执行。
4. 行政班与教学班一起纳入支持范围，不采用“首批仅行政班”方案。

## 已确认的教学班校验行为

用户在本次会话明确选择“组合不符阻止，重新生成保留合规关系（推荐）”：

1. 导入教学班成员必须符合该班的选科组合；不符时阻止该行执行，不作为人工例外放行。
2. 重新生成教学班时保留仍符合规则的导入关系，不把合规导入关系全部清空。
3. 两阶段校验、范围检查及幂等仍适用；本裁决不授权导入时创建教学班。
