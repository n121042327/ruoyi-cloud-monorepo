## 1. 验收怎么进行

三层验收（需求 / 实现 / 交付），本轮只做**需求验收**。
用例状态五选一：`通过` / `失败` / `未执行` / `不适用` / `已失效`。
缺陷分级与通过判定与 `modules/student/acceptance.md` 一致：P0 与 P1 未关闭时不得判定通过。

## 2. 测试数据与账号准备

### 2.1 必备账号

| 账号 | 角色 | 数据范围 | 用途 |
|---|---|---|---|
| `ops_admin` | 平台运营 | 全平台 | 跨租户与留痕用例 |
| `t_admin` | 租户管理员 | 学校组织配置 | 验证其看不到班级教学数据 |
| `s_leader` | 校领导 | 本校 | 只读用例 |
| `academic` | 教务主任 | 本校 | 主流程用例 |
| `grade_leader_a` | 年级主任 | 高一 | 本年级建班与编班用例 |
| `homeroom_1` | 班主任 | 高一(1)班 | 花名册只读与字段用例 |
| `teacher_1` | 任课教师 | 高一(1)班数学 | 字段裁剪与禁止导出用例 |

### 2.2 必备数据

| 数据 | 数量 | 说明 |
|---|---|---|
| 学校租户 | 2 个（A 校、B 校） | 跨校用例 |
| 独立学校租户 | 1 个（C 校，无集团） | 跨根租户用例 |
| 年级 | A 校 6 个（高一 / 高二 / 高三各 2 个学期视角） | — |
| 行政班 | A 校 12 个（高一 1–6、高二 1–6） | 覆盖不同容量与校区 |
| 教学班 | A 校 4 个（按学科与选科组合） | 教学班用例 |
| 学生 | A 校 600 名，已编入 12 个行政班 | 花名册用例 |
| 未编班学生 | 30 名 | 编班用例 |
| 已跨班冲突学生 | 1 名（人为构造同时在两个班） | 唯一行政班校验用例 |
| 满容量班级 | 1 个（在读人数 > 容量） | 容量只提示不拦截用例 |
| 历史学年班级 | A 校上一学年 12 个班 | 历史只读用例 |
| 超规模数据 | 10 万学生 / 100 万条班级关系（独立压测库） | 性能用例 |

### 2.3 前置系统能力

学年学期已设置当前与历史学年；学科已配置；教师与教育角色已建立；任教关系已建立；
校区字典已配置。
