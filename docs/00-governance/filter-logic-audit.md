# 列表筛选顺序与学校上下文核查

- 日期：2026-10-01
- 来源：用户要求检查“班级管理校区是否应该紧跟学校，以及其他页面是否有类似问题”。
- 范围：45 个业务原型 v1 页面及学生 v2 样板；高保真 v1 采用对应业务页面结构。
- 方法：源码逐页扫描与独立只读审查；学生 v2 另运行浏览器回归。未将静态检查写成全页交互验证。
- 清单证据：`evidence/governance/2026-10-01_filter-inventory.yaml`。

## 结论与建议

班级列表的校区应紧跟学校显示，便于先确认所查学校与校区，再选时间和年级等条件。
学生列表应先显示学校上下文，再显示学年学期、年级、班级；本批已在 v2 样板调整。
教师列表可把任教年级与任教班级相邻分组，但现有顺序来自冻结 PRD，属于设计调整候选，不能说成实现漏改。

“排列相邻”与“数据逐级从属”是两件事。现有通用规则将校区、年级、班级列为学校下的并列维度，
学生列表的年级联动已单独获用户裁决；不得只为了统一视觉，自行令其他页面的年级必须从属于校区。
未发现已有校区控件排在学校之前；45 页中只有班级列表已有校区筛选，不向其他页面擅自新增字段。
