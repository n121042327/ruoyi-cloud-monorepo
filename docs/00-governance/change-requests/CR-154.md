## 2. 导出任务的学校怎么定（`resolveExportSchoolId`）

后台执行没有登录态，学校必须在**请求线程**定下来随任务落库（与 D-218 / D-231 同一口径）：

- 数据范围内恰好一所学校 → 用它；
- 数据范围内多所学校 → 明确拒绝（导出入口还没有「目标学校」下拉，GAP-115 只做了导入侧）；
- 数据范围内没有学校、只有班级范围（班主任 / 任课教师）→ 按班级反推 `edu_class.school_id`，
  跨多所学校或班级信息缺失时拒绝。

## 3. 为什么把「跳过审计」改成「拒绝下载」

`edu_audit_log.school_id` 是 NOT NULL，历史实现写成「取不到学校就只记 warn、不阻断下载」，
结果是下载成功但没有留痕 —— 违反 `REQ-IMP-043`，也与「缺少上下文必须拒绝执行」的硬约束相反。
本批把学校落到源头（任务与文件引用），审计侧只保留兜底；兜底也取不到时**拒绝下载**并给出明确文案，
不允许出现「下载了但查不到是谁下的」。
