## 2. 口径

- **归档检索**：归档数据只读，检索结果同样受数据范围约束并写访问审计（REQ-AUD-033）。
  检索条件是 `EduAuditArchiveBatchBo` 的字段：时间范围（`rangeStart` / `rangeEnd`）、操作类型、
  对象类型 / 标识、操作人、关键字；前端只暴露时间范围、操作类型与关键字三项，其余由后端上下文补。
- **任务行明细**：`/{batchNo}/rows` 是 REQ-IMP-006 要求的「分页展示校验 / 执行结果」端点，
  返回 `EduImportErrorVo`（行号 / 对象 / 结果 / 失败原因 / 原始数据）。弹窗支持按「成功 / 失败」
  与关键字过滤，与任务列表的 `failedCount` / `successCount` 呼应。
- 两个入口都放在各自页面的工具栏 / 操作列，不新增路由。
