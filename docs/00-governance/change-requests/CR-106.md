# CR-106 — 阶段 6 第二十六批：修教育域弹窗「分组标题 / 提示」无样式导致的丑布局

用户反馈新建学校弹窗布局丑（截图：窄弹窗里两列挤在一起，提示文字被压成 6 行占满右半屏）。

## 1. 根因（两个叠加）

1. **`.form-section-title` 与 `.hint` 在全前端没有任何样式定义**。这两个 class 只出现在教育域：
   `class="form-section-title"` 44 处 / 23 个文件、`class="hint"` 42 处 / 21 个文件（`src/views/edu/**`），
   但 `src/assets/styles/*` 与组件内都没有定义它们 —— 于是分组标题落成浏览器默认的 `<h3>`（1.17em 粗体 + 默认外边距），
   提示落成默认正文 14px，颜色与正文一致，视觉上就是一大团灰字。
2. **弹窗内两列过窄**：`SchoolFormDialog.vue` 用 `width="620px"` + `el-col :span="12"` + `label-width="110px"`，
   每列可用宽度只剩约 200px，长提示（BR-ORG-011 那段）被折成 6 行，把 学校类型 / 所属租户 挤得上下错位。

## 2. 改动

| 路径 | 改动 |
|---|---|
| `apps/plus-ui/src/assets/styles/index.scss` | 新增 `.form-section-title`（14px / 600 / 左侧 3px 主色竖条 / 组间距）与 `.hint`（12px / 次要色 / 1.5 行高）两个全局样式 |
| `apps/plus-ui/src/views/edu/school/sch_list/components/SchoolFormDialog.vue` | 宽度 620 → 720；字段改 2×2 栅格（学校名称 \| 学校编码 / 学校类型 \| 所属租户）；两处长提示删除，说明收敛为表单底部一行 `.hint` |

为什么把样式做成全局：这两个 class 是教育域 23 个弹窗 / 抽屉的公共写法，每个组件各写一份 `<style scoped>` 会重复 20+ 次；
放在 `index.scss` 一次定义，其它弹窗（年级、班级、选科、升班…）自动受益。因为 class 只在 `src/views/edu/**` 出现，
不影响 RuoYi 原有页面。
