用户于 2026-10-02 对挂起缺项批注「按推荐走」，即按每条缺项的推荐选项执行。本批先落实其中两条：GAP-047（下拉级联）与 GAP-078（撤销离职后的账号与角色口径）。其余四条（GAP-063 / 064 / 066 / 067）的处理见文末。

## GAP-047 — 学校变化后收窄下拉（选项 A）

`prototypes/{functional,high-fidelity}/v2/pages/grade-list.html`：

- 入学年份与年级主任的 `<option>` 增加 `data-school`；学校变化时重建这两个下拉，只保留该校范围内的选项；原值不在新范围内时清空为「全部」。
- 学段 chip 增加 `data-school`；学校变化时隐藏该校没有的学段，并把已选中的失效学段清除（再同步 chip 高亮）。
- 归属取自 `content-samples.json` 的 `grades[].school_id` / `stage_code` / `grade_leaders`：学校 201 有小学 / 初中 / 高中与 2021—2026 六个入学年份；学校 202 只有初中一个年级（2026 级 初一）且未指定年级主任。

`prototypes/{functional,high-fidelity}/v2/pages/teacher-list.html`：

- 任教年级与任教班级的 `<option>` 增加 `data-school`，学校变化时按同样规则重建；归属取自 `grades[].school_id` 与 `classes[].school_id`（现有三个年级与三个班级都属学校 201）。
- 任教学科是平台级配置，不随学校变化；教育角色 chip 同理。

学生列表的 年级 / 班级 收窄已在 CR-020 完成，本批未改。**学年学期是唯一仍未按学校收窄的筛选项**：`calendar` 样例没有 `school_id`，按 GAP-067 不能编造归属，等两校学期样例补齐后再做。

## GAP-078 — 撤销离职 / 调离登记后的口径（选项 A）

- 教师 PRD 升到 **1.0.5-draft**，4.9 新增 `REQ-TCH-071`：撤销离职 / 调离登记后账号自动重新启用；离职前的教育角色不自动恢复，由管理员重新分配。`acceptance.md` 同步新增 `AC-TCH-071`，PRD 第 11 节映射补一行。
- `DIALOG-TCH-REVOKE` 的影响范围与提示改写为该口径，去掉就地标注的 GAP-078；`page-actions.yaml` 的 `ACT-TCH-040` 结果同步。

理由：账号启用只恢复登录能力，不恢复数据范围；教育角色决定数据范围，重新分配留痕更可解释。
