## 2. 变更原因

`GAP-039` 记录的是「已交付的学生 / 教师表单用抽屉，与 `apps/plus-ui` 的 dialog 习惯不一致」。
用户裁决选项 B：**表单类改弹窗、详情类保留抽屉**，并要求载体与现有代码库一致。

核查证据（命令见 `evidence/stage2-prototype/README.md` 第 4 节）：
`apps/plus-ui` 全库 `<el-dialog>` **40 处**、`<el-drawer>` **0 处**；dialog 宽度以 `500px`（13 次）最常见。

同时发现两处必须一起处理的问题：

1. **弹窗内长内容会被裁切**：`.dialog-body` 没有 `flex:1`，在三步表单这种高内容下既撑不出滚动区、又被
   `.dialog { overflow:hidden }` 裁掉。本次一并修好（否则转换后会变成"更差的抽屉"）。
2. **样式钩子名不副实**：弹窗内部仍使用 `drawer-header` / `drawer-body` / `drawer-footer`。
   载体统一后，这些钩子按容器类型改名，避免阶段 6 映射时误判容器。

## 3. 变更内容

1. **学生模块**：新增学生（三步）、编辑学生 → 弹窗（md）；学生详情 → 抽屉（lg，`navigation.yaml` 补 `container: drawer`）。
2. **教师模块**：新增教师（三步）、编辑教师 → 弹窗（md）；教师详情 → 抽屉（不变）。
3. **学校模块**：编辑学校 → 弹窗（md）；校区管理 → 独立页（含表格，按 `layout-spec` 的"表格类内容放独立页"）。
4. **学年学期模块**：新建学年 → 弹窗（md）；学期管理 → 独立页（含表格）。
5. **学科模块**：新建 / 编辑学科 → 弹窗（md）。
6. **五份 PRD** 各补一条载体口径说明：表单类浮层统一用弹窗、详情类用抽屉、含表格或分页用独立页。
7. **原型实现**：`student-list.html` 与 `teacher-list.html` 的四个表单浮层由抽屉改弹窗；弹窗内的样式钩子改名；
   教师详情抽屉保持不变。
