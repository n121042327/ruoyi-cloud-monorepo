## 2. 为什么在请求线程解析
`DataScopeResolver` 依赖登录态（用户 → 角色 → 学校 / 年级 / 班级 / 任教班级）；
后台线程没有登录态，`EduDataPermissionHandler` 不会注入条件 —— 这也是 D-218 定下的口径。
把解析放在发起导出的请求线程，执行阶段只按落库的范围过滤，范围不会因为「跑在后台」而变宽。

## 3. 年级范围怎么落到班维度导出
两张已接入的表都是「班级维度」的（编班表按班级、任教关系挂班级），
而年级主任的范围是 `gradeIds` —— 因此 `EduExportScopeResolver` 把 `gradeIds` 展开成
「该年级下的行政班 ID 列表」，导出器统一按 `class_id in (...)` 过滤即可，不必各自实现年级 → 班级的推导。
