## 口径（与 PRD / BR 对齐）

- 选科配置按**学校 + 学年学期唯一**（`REQ-STR-004`，命中 `uk_stream_config` 则更新不新增）。
- 开放期状态**按当前时间实时比较** `stream_open_from` / `stream_deadline`，**不依赖定时任务**刷状态（`REQ-STR-005`）。
- **截止前**自助提交 / 修改**立即生效**并直接落 `edu_student_stream`；**截止后**只能走变更申请，**审批通过前保持原组合不变**（`BR-STREAM-006`）。
- 组合**不在库里拼字符串**：实体只存 `primary_subject_code` + `secondary_subject_codes`，展示名由服务层派生（`CR-016`）。
- **同一学生同一学期同时只允许一条待审批申请**（`REQ-STR-029`）；**驳回必须填审批意见**（`REQ-STR-037`，服务层校验非空）。
- 首次提交 / 开放期内自助变更 / 变更申请通过三类动作**都追加** `edu_stream_history`（`REQ-STR-043`），历史跨学年学期保留（`REQ-STR-044`）。
- 教学班生成**预览只读不写**（`REQ-STR-056`）；执行按唯一键**幂等**（`REQ-STR-057`），复跑不产生重复教学班；**核对差异只提示不自动修正**（`REQ-STR-060`）。
- 校验简化的地方已在代码注释标注：首选 / 再选科目的合法性目前用 `subjectNameMap()` 的键判断（依赖 `IEduSubjectService` 的启用学科集合），未额外做「3+1+2 组合白名单」校验。

## 边界与经验

- 本批修掉一个 MapStruct Plus 类型不匹配：实体 `secondarySubjectCodes` 是逗号分隔 `String`，展示侧 `EduMyStreamVo` 是 `List<String>`，双向生成的
  `EduStudentStreamToEduMyStreamVoMapper` / `EduMyStreamVoToEduStudentStreamMapper` 都报 `Can't map property`。
  **正确做法**是：`@AutoMapping` / `@ReverseAutoMapping` 必须写在带 `@AutoMapper` 的那个类上，**两个方向各写一条**；
  写在没带 `@AutoMapper` 的类上不生效（本轮先踩了这个坑，`EduStudentStream` 上的注解已删除）。
- `exportStreamSelection`（`/edu/stream/export`）归入导入导出引擎批次，本批不落地。
- `EduMyStreamVo` 的 `termName` / `primarySubjectName` / `secondarySubjectNames` / `teachingClassNames`、
  `EduStreamSelectionVo` 的 `studentNo` / `studentName` / `gradeName` / `className`、`EduStreamStatVo` 与
  `EduUnselectedStudentVo` 的同名展示字段需要连接查询，随各模块 `*Mapper.xml` 在后续批次补齐。
- 下一步按队列做**导入导出引擎与异步任务**（`edu_import_template` / `edu_import_batch` / `edu_import_error` /
  `edu_async_task` / `edu_async_task_retry` / `edu_dead_letter_task` / `edu_file_ref`，含全部 `export*` operationId）。
