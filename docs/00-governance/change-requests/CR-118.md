## 2. 口径

- **学籍异动**：沿用已有的 `changeEnrollmentStatus`（`POST /edu/student/{id}/enrollment-change`），
  页面入口不变；本批补的是异动前后需要联动的账号与导出能力。
- **学号变更**：单独弹窗（新学号 + 原因）。学号是导入 / 导出对照表的键，变更写审计。
- **重置密码**：二次确认后调用，不传新密码时由后端生成。
- **激活码**：弹窗读取 `getActivationCode`；「打印激活单」「导出激活码」都按单学生提交
  （后端接收集合，为后续批量留了扩展）；「标记已激活」二次确认后调 `activateStudent`。
- **导出学生**：单行导出，走统一导出引擎，提示到异步任务中心下载。
