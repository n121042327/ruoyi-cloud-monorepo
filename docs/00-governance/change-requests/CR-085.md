## 口径（与 PRD / BR 对齐）

- 一个学校对应一个租户（`BR-ORG-002`）：`edu_school` 的 `tenantId` 唯一；学校与租户的绑定关系一经创建不可修改（`REQ-SCH-022`），`updateByBo` 显式不接收租户字段。
- 层级不超过三级（运营方 → 集团 → 学校，`BR-ORG-003`）；学校编码在**父租户内唯一**（`BR-ORG-011`）。
- 校区**不参与数据权限判定**（`BR-ORG-009`）；有班级挂在校区上，因此「删除校区」实现为**停用**（写 `campusStatus=disabled`）并要求原因。
- 未开设的学段在学科与年级配置里置灰（`REQ-SUB-026`）：`saveSubjectStage` 会校验 `edu_school_stage.status='1'`，未开设直接拒绝并给出学段编码。
- 「一条学科主体 + 学段启用表」（`RV-SUB-04`）：学科编码校内唯一（`BR-SUBJECT-001`），同一学科在不同学段启用只加启用记录、不拆多条主体；**学科编码不提供修改入口**。
- 删除学科前检查三类引用（任教关系 / 教学班 / 学生选科），有引用时只允许停用；排序号决定再选科目展示顺序（`REQ-STR-017`）。
- 开通初始化 `initSchoolBaseline` **幂等**：学段已有记录只置 `status='1'`；学年按「同校同学年编码只建一次」跳过；学科模板按「已存在编码跳过」不覆盖已有配置（`REQ-SCH-019` / `045`）。默认同时初始化学科模板（`initSubject` 缺省为 true）。
