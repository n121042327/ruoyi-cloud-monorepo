## 口径

- 编班表导入复用导入导出模块的通用引擎与模板（`downloadImportTemplate` / `validateImportFile` / `executeImport` / `downloadImportFailedRows` / `downloadImportResult`，`REQ-IMP-002` / `BR-IMP-001`），模块编码 `classRoster`。
- 模板 4 列：学号（必填）/ 姓名（选填，用于核对）/ 目标班级（必填）/ 班级类型（选填，默认行政班）（`REQ-CLS-035`）；导入幂等（`REQ-CLS-037`）；模板字段变更必须升版本（`BR-IMP-007`）。
- 重复判定：同一学生在一个学年学期只允许一条行政班关系（`BR-STU-016`）。
- 行政班与教学班是两套独立关系，选科组合不等于行政班；教学班创建入口唯一在「按组合生成教学班」向导，本页只做查询 / 详情 / 停用（CR-017 裁决）。
- 停用后不再出现在新建可选列表，历史成员保留，停用写审计。
