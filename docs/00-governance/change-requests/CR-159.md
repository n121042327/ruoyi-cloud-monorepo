## 2. 口径（用户 2026-10-10 确认「按推荐」）

- **在读学生**：`edu_student_enrollment.school_id = 学校` 且 `enrollment_status = 'enrolled'` 的**去重学生数**，**不限学年**。
  与 `getSchoolSummary` 的统计摘要共用同一口径，不出现两套数字。
- **按开设学段筛选**：命中 `edu_school_stage.status = '1'` 的记录；没有开设任何学段的学校不会命中任何学段筛选；
  筛选结果为空时返回空列表，**不退化**为全量（与 `DS-DENY-03` 同口径）。
- 为什么不去按当前学年：同一学校在不同学年会显示不同人数，与「台账看总量」的用法不符。
