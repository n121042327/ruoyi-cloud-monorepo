## 口径（与 PRD / BR 对齐）

- 升班按学年**追加**下一学年的班级与学生关系，**不改写历史**（`BR-PROMO-001`）；班级关系仍由班级管理写入（`DP-01`），执行时调 `IEduClassService.addRoster` 落班。
- **同一源 → 目标学期的未结束任务唯一**（`REQ-PRM-005`）、**目标学期年级与班级必须齐备**（`REQ-PRM-009`）：`addTask` 前先跑 `readiness`，阻塞直接拒绝创建。
- **预览不写任何学生数据**（`REQ-PRM-020`），重新预览**覆盖旧明细**（`REQ-PRM-021`）；明细来源是源学期花名册（`edu_class_member.status='1'`）。
- 明细**幂等键 = (task_id, student_id)**（`REQ-PRM-029`）；**重试只处理失败 / 跳过项，已成功的行不动**（`REQ-PRM-032` / `037`）。
- 校验规则：升班 / 转班 / 留级必须有目标班级，**毕业不需要**（`REQ-PRM-027`）；校验不通过的行标 `failed` 并写失败原因。
- 执行时毕业走**学籍异动记录**（`edu_enrollment_change`，学籍状态唯一流转入口 `DP-01`）；统计成功 / 失败 / 留级 / 毕业四项，失败且部分成功置「部分失败」。
- **取消保留已完成部分、不做整批回滚**（`REQ-PRM-036`）；已完成任务不允许取消；取消必须填原因（≥ 5 字）。
- 教学班与行政班**完全独立**（`BR-CLASS-001`），不设班主任、不参与 DS-06；唯一键 `uk_teaching_class`（school + term + combination + class_name）是**幂等生成**的前提（`REQ-STR-056` / `057`），成员唯一键 `uk_tclass_member` 保证重复生成不产生重复成员。
- 教学班停用必须填原因（≥ 5 字），**历史成员保留**；手工增删成员不开放（成员只能由生成或本服务生成时批量写入）。
