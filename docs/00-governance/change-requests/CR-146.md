## 2. 账号为什么不在导入路径创建（GAP-116）

教师导入模板（PRD 4.8）9 列里没有「登录名」，而 `BR-ACCOUNT-001` 明确「教师登录名由学校统一分配，
规则沿用现有基线」——也就是说法定输入是学校分配的登录名，不是系统能推出来的值；初始密码同样没有依据。

自行编排（如「登录名 = 工号、初始密码 = 手机号后六位」）会引入两条没人确认过的安全策略：
登录名规则与初始密码规则。因此本批只做「建档 + 教育角色」，账号开通留给管理员在教师页处理，
并登记 GAP-116，推荐方案是把「登录名」列加进导入模板（属阶段 1 产物新版本，需要确认）。
