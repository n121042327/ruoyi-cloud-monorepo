# CR-027 — 学生、年级表格与新建编辑表单字段布局

用户于 2026-10-01 要求继续此前建议的批次：把 `docs/00-governance/page-field-layout.md` 的约束落到学生、年级两页的表格与新建 / 编辑表单。继续授权不记为人工验收通过；GAP-075 未获表态，本批不动教师非在职行的入口。

## 表格

- 学生表：学号、姓名、性别（基础信息）→ 入学年份、学段、年级、班级、学籍状态（教育信息）→ 联系电话（联系方式）→ 更新时间（管理信息）→ 操作。相对冻结 `REQ-STU-006` 只挪动了入学年份，使其与新建学生的分组顺序一致（入学年份 → 学段 → 年级 → 行政班）。
- 年级表：学段、入学年份、年级名称、学段内序号、年级主任（教育信息）→ 班级数、在读学生数、状态（管理信息）→ 操作。相对冻结 `REQ-GRD-003` 把学段、入学年份提到年级名称之前，并把年级主任并入身份组，使班级数与在读学生数保持相邻。
- 两张表每个数据单元格登记 `data-field`，表头登记 `data-layout-group`，表头下方显示分组名称；选择列与操作列独立。

## 表单

- 新建 / 编辑学生第 1 步拆为 基础信息（学号、全国学籍号、姓名、性别）、教育信息（入学年份、学段、年级、行政班、学籍状态、入学日期）、补充信息（学生照片）。
- 新建 / 编辑学生第 2 步拆为 证件信息（证件类型、证件号码、出生日期）、联系方式（学生手机号、联系地址）；第 3 步补监护人信息标题。
- 新建年级与按学段批量生成补教育信息分组，字段顺序维持 所属学校 → 学段 → 入学年份 → 学段内序号 → 年级名称。
- 校验结果、并发提示与「保存后会发生什么」保持在分区之外；提交按钮仍在页脚。

## 读取方式

学生、年级原有脚本按列序号读取单元格（`cell(tr, i)`、`cell(row, i)`、`row.children[n]`）。列序调整后会读到相邻列，因此本批统一改为按字段名读取：学生 `readRow` 与年级编辑 / 归档 / 批量预览全部改为 `cell(row, '<field>')`，并对选择列、操作列显式排除。
