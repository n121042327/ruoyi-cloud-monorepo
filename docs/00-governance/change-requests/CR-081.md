## 一、学生纵切列名修正（对齐 schema.yaml）

CR-054 的 `EduStudent` / `EduStudentBo` / `EduStudentVo` 与事实源不一致，本批修正：

| 项 | CR-054 的写法 | schema.yaml（事实源） | 本批改为 |
|---|---|---|---|
| 主键 | `@TableId(value = "student_id")` | 列是 `id`（`student_id` 是本表在其它表里的外键名） | `@TableId(value = "id")` + 字段名仍叫 `studentId`（接口契约字段名不变） |
| 照片 | `photoFileId`（bigint） | `photo_url varchar(255)` | `photoUrl` |
| 联系电话 | `studentPhone` | **表里没有该列** | 删除（见 GAP-090） |
| 联系地址 | `address` | **表里没有该列** | 删除 |
| 入学年份 | 无 | `enroll_year smallint NOT NULL` | 新增 `enrollYear` |
| 毕业日期 | 无 | `graduation_date date` | 新增 `graduationDate` |

顺带修掉 `EduStudentBo` 里 `enrollYear` 重复声明（一个 String 查询字段 + 一个 Integer 写入字段重名，
编译期报「已在类中定义变量 enrollYear」并连带 Lombok 不生成 getter/setter，产生 30+ 条级联错误）。

### 口径（与 PRD / BR 对齐）

- 行政班必填年级；教学班必填组合标识，且**教学班创建入口唯一在「按组合生成教学班」向导**（CR-017），本服务只做通用维护。
- 容量只提示不拦截（`BR-CLASS-005`）；有在读学生不允许删除、只允许停用（`BR-CLASS-006`），停用原因至少 5 个字。
- 学年学期与年级一经创建不可修改（`REQ-CLS-022`）——`updateByBo` 显式不接收这两个字段。
- 学生班级归属的唯一写入入口是班级管理（`DP-01`）；加入前逐条校验「同一学年学期只能属于一个行政班」（`BR-STU-003`），**冲突整体拒绝、不做部分成功**（原型 PAGE-CLS-ROSTER-ADD 的口径）。
- 关系追加式：移出 / 调班都把原关系置 `status='0'` 并写 `leave_date`，不物理删除（`BR-PROMO-012` 同口径）。
- 班级合并：源班级在读学生在目标班级下新增在班关系、源班级置 `disabled`，历史花名册保留（GAP-088 的推荐口径）。
- 教学班不设班主任（`BR-CLASS-007` / `REQ-CLS-039`），`assignHeadTeacher` 直接拒绝。
- 数据范围：查询条件在服务层拼进 wrapper，不先取数再判断（`DS-DENY-07`）；`DataScopeResolver` 在阶段 7 后续批次接入。
