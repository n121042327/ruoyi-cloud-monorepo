# CR-048 — 阶段 6 第五批：学籍异动与调班浮层

继续阶段 6，本批交付学生模块两个写入弹窗：**学籍异动**（`PAGE-STU-STATUS`）与**调班**（`PAGE-STU-TRANSFER`），
并接到学生列表行内动作与详情抽屉底部。

## 交付内容

| 落点 | 说明 |
|---|---|
| `.../components/StudentStatusDialog.vue` | 学籍异动：异动信息（异动类型 → 生效日期）→ 复学 / 报到安排（条件必填班级）→ 异动说明（原因 ≥ 5 字）；异动类型选项由 `listEnrollmentStatusOption` 按当前状态返回，需审批的动作给出提示 |
| `.../components/StudentTransferDialog.vue` | 调班：班级关系（目标班级 → 生效日期，默认取当前学年学期开始日）→ 调班说明（调班原因）；目标班级停用不可选，选项带「在读 / 容量」提示 |
| `.../stu_list/index.vue` | 行内动作补「学籍异动」「调班」（按 `enrollment.status:update` / `org.class:update` 显示），并挂上两个弹窗 |
| `.../StudentDetailDrawer.vue` | 底部补「学籍异动」「调班」两个入口，通过事件交给列表页打开对应弹窗，不重复实现表单 |
| `apps/plus-ui/src/api/edu/student/**` | 新增 `listEnrollmentStatusOption`、`changeEnrollmentStatus` |
| `apps/plus-ui/src/api/edu/class/**` | 新增 `transferClass`（学生班级归属的唯一写入入口在班级管理，`DP-01`） |
| `apps/plus-ui/src/api/edu/term/types.ts` | `TermVO` 补 `startDate` / `endDate`，供调班默认生效日期使用 |
| `tools/check_fe_page_structure.py` | 新增两个浮层对照：异动弹窗 3 个分组、调班弹窗 2 个分组 |

## 与原型 / PRD 的对应

- 学籍异动：原型 `PAGE-STU-STATUS` 的三个 `data-layout-group`（异动信息 / 复学 / 报到安排 / 异动说明）与
  `ACT-STU-030`（提交异动，`changeEnrollmentStatus`）；状态机口径见 `BR-PROMO-010`、`REQ-PRM-041` / `043` / `044`。
- 调班：原型 `PAGE-STU-TRANSFER` 的两个分组（班级关系 / 调班说明）与 `ACT-STU-032`（确认调班，`transferClass`）；
  与班级模块同口径（`CR-029` 裁决：统一复用 `transferClass`，原关系保留历史）。
