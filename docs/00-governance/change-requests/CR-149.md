## 2. 工具扩展

`parse_prototype_columns(html, table_index=None)`：指定原型里的第 N 张 `<table>`。
原因：弹窗 / 抽屉里的表在原型里通常不是第一张表，而原检查只认第一张（含 `data-role="table"` 的那张）。
CHECKS 条目新增可选键 `table_index`；**不写时行为不变**，既有 50 余条对照不受影响。
