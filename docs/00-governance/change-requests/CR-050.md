## 附：本批踩到的一个坑

`src/router/index.ts` 在 Windows 检出下是 CRLF，`apply_patch` 插入的行是 LF，导致
`prettier/prettier` 一次性报 29 条 `Insert ␍`（把 lint 总数从 124 抬到 153）。已把该文件统一为 CRLF，
lint 回到 124；提交入库时 Git 按 `core.autocrlf` 转成 LF，仓库内的换行口径不变。
