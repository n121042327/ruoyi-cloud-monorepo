设置任教（跳任教关系页）、变更工号、重置密码、停用账号、启用账号。

## 2. 口径

- **教育角色**：一个教师可有多条角色记录，弹窗先列出已有角色（`listTeacherRole`），再分配新角色；
  移除必须填原因（`removeTeacherRole` 的 `reason` 参数写审计）。
- **离职 / 调离登记**：登记类型（离职 / 调离）+ 生效日期 + 原因，三者必填；页面提示「登记后不能再新增任教关系，
  已有关系与历史数据保留，撤销后可恢复」。撤销登记用 `ElMessageBox.prompt` 收集原因。
- **工号变更**：单独弹窗（新工号 + 原因），因为工号是导入 / 导出对照表的键，变更要写审计。
- **重置密码**：二次确认后调用，不传新密码时由后端生成。
- **账号停用 / 启用**：停用需填原因；页面说明「停用账号不影响在职状态与任教关系」。
  后端的 `EduTeacherVo` 没有账号状态字段，所以「停用 / 启用」两项都放在下拉里，由操作人按实际情况选择。
