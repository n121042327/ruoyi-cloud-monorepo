## 口径

- 新建学年必填：所属学校、学年编码、起止日期（`REQ-TERM-007`）；编码格式 `YYYY-YYYY` 且结束年 = 起始年 + 1（`REQ-TERM-008`），校内唯一（`REQ-TERM-009`）。
- 新建学年同步创建默认学期结构（上学期 / 下学期），允许微调（`REQ-TERM-012`）；新建 / 编辑 / 归档 / 撤销归档写审计（`REQ-TERM-013` / `037`）。
- 已产生班级或学籍关系的学年只允许归档、不允许删除（`REQ-TERM-028`）；归档前必须展示引用检查结果（`REQ-TERM-029`）；归档后移出新建业务可选列表但历史数据可查（`REQ-TERM-030` / `031`）；归档可撤销且写审计（`REQ-TERM-033`）。
