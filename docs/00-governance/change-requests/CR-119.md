# CR-119 — 阶段 6 第三十八批：班级批量生成与停用

自动化队列第 3 项。班级列表此前工具栏只有「新建 / 导出」，操作列只有「编辑 / 花名册」；
高保真 `class-list.html` 的工具栏还有「批量生成班级」，弹窗层还有「停用班级」。

## 1. 交付内容

| 层 | 内容 |

| api 层 | 补 `batchAddClass`（POST /edu/class/batch，入参 `classList` 数组） |
| 弹窗 | 新增 `ClassBatchDialog`（按「起始序号 ~ 结束序号」生成同年级多班，含命名预览） |
| 页面 | 工具栏加「批量生成班级」；操作列加「停用」（填原因，`disableClass`），宽度 160 → 220 |

本批的另外两项（班主任指定、花名册导出）在 CR-115 交付班级详情页时已实现，此处不重复。

## 2. 口径

- **批量生成**：一次只生成同一个学年学期 + 同一个年级下的多个行政班，命名规则 `${年级名} (${序号}) 班`，
  与高保真的「按规则生成」（ACT-CLS-031）一致；序号范围支持 1~99，容量只提示不强制（BR-CLASS-005）。
  已存在的班级名由后端唯一约束拒绝，前端不预判。
- **停用班级**：入口在列表操作列（仅 `class_status !== 'disabled'` 时出现），必填原因；
  与 BR-CLASS-006「有在读学生不允许删除、只允许停用」一致。
- 班级物理删除**未接前端**：高保真里有「删除班级」弹窗，但学生主体与班级关系的口径是追加式，
  删除风险高，与 D-199 对学生删除的处理保持同一口径，留待业务口径明确后再做。
