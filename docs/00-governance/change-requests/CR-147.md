# CR-147 — 阶段 7 第六十六批：导入结果文件（GAP-094 收尾）

## 1. 交付

| 文件 | 内容 | 依据 |
|---|---|---|
| 学号对照表（`import_result`） | 原始行号 / 姓名 / 系统学号 | REQ-STU-058 |
| 失败明细（`failed_rows`） | 原始行号 / 姓名 / 失败原因 | BR-IMP-006 / REQ-STU-060 |

两者都由 `EduImportTaskRunner` 在执行结束后生成：CSV（带 UTF-8 BOM）→ `RemoteFileService.upload` →
`edu_file_ref`（bizType=import_batch、bizId=批次号、7 天有效）→ 回写批次的 `result_file_id` / `failed_file_id`
与任务的 `failed_file_id`。

## 2. 两个实现细节

1. **模块只回填自己要对账的字段**：学生导入把生成的学号放进 `EduImportRowResult.extras`，引擎负责汇总成对照表。
   这样「对照表长什么样」是引擎的事，模块只回答「这一行生成了什么」。
2. **空内容不落文件**：没有成功行就不生成结果文件；失败明细同理。落下只有表头的空文件会让人以为「导出的内容丢了」。
