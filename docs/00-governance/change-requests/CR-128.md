# CR-128 — 阶段 6 第四十七批：教师 / 年级详情抽屉 + 学生详情在校记录段

第二轮队列第 6 项「详情抽屉：教师详情（PAGE-TCH-DETAIL）、年级详情（PAGE-GRD-DETAIL）、
学生详情在校记录段」。做抽屉时发现教师模块有若干字段名 / 码值与后端契约不一致，一并修正。

## 1. 交付内容

| 页面 | 交付 |
|---|---|
| 教师列表（`/edu/teacher/list`） | 姓名列改为链接，打开只读详情抽屉：基础信息 / 任职信息 / 任教清单（`listTeachingAssignment`） |
| 年级列表（`/edu/grade/list`） | 年级名称列改为链接，打开只读详情抽屉：基础信息 / 下辖班级（`listClass`） |
| 学生详情（PAGE-STU-DETAIL） | 教育信息段之后并入在校记录段（`GET /edu/student/{id}/enrollment`），字段 enrollDate / enrollmentStatus / statusEffectiveDate / leaveDate / remark |

两个抽屉都写明「只读视图」：教师在职状态只有「离职 / 撤销离职登记」一个写入入口、教育角色只有「教育角色」一个写入入口；
年级只提供「学段内序号 +1」的只读参考，升班唯一执行入口在升班模块（AGENTS 第 7 节）。

## 2. 顺带修正的契约错位

| 问题 | 证据 | 处置 |
