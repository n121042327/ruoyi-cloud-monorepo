## 口径

- 403：无权限时页面不渲染空表格、接口层同样拒绝，且要求租户 / 学校 / 执行人上下文（`NFR-SEC-05`）；缺少权限的访问同样写审计（`NFR-AUDIT-02`）。
- 500：批量类写操作（导入 / 升班）都是异步任务，失败整批记录原因并可在任务中心重试（`NFR-MQ-02`），因此不会出现部分写入；页面展示请求编号与错误码，上报已含请求编号 / 路径 / 用户 / 租户。
- 组件归属（GAP-087 裁决）：登录与 404 复用框架既有组件（`src/views/login.vue`、`src/views/error/404.vue`）；403 / 500 新建在 `views/error/` 下，与框架 `401.vue` / `404.vue` 同区。

## GAP-087 的处理方式（重要）

页面树 `docs/40-detailed-design/frontend-page-tree.yaml` 把登录与异常页的 `view_component` 写成 `views/edu/common/*`，
但该文件头标注 `generated_by: tools/gen_api_and_map.py`，是生成器按 `conventions.views_root: apps/plus-ui/src/views/edu/<module>/<page>/index.vue`
推导出的投影；同一文件的 `conventions` 已写明「仅登录页与异常页是静态路由」。因此：

1. 不改这份生成产物（也不改其上游原型产物），避免与生成器下次运行冲突；
2. 在 CR-080 与 GAP-087 里写明实际组件路径与推导原因；
3. 建议阶段 5 产物下一版修订时给生成器加一条例外：静态路由（登录 / 401 / 403 / 404 / 500）不套 `views_root`。
