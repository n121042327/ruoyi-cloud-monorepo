# CR-167 — 阶段 8 验收首轮缺陷修复：班级列表 500（不可变 Map 用 null 键）

## 1. 缺陷现象

阶段 8 运行时验收（蜀国 / liubei）第一步就命中：`GET /edu/class/list` 无论在哪个筛选组合下都返回

```json
{"code":500,"msg":"发生未知异常，请联系管理员","data":null}
```

其它接口（`/edu/school/list`、`/edu/grade/list`、`/edu/term/list`、`/edu/teacher/list`、`/edu/teaching-class/list`）
都正常，只有班级列表整体失败。

## 2. 根因

`services/.../ruoyi-modules/ruoyi-edu/logs/ruoyi-edu/error.log` 的堆栈直接指到：

```
java.lang.NullPointerException
    at java.base/java.util.Objects.requireNonNull(Objects.java:208)
    at java.base/java.util.ImmutableCollections$MapN.get(ImmutableCollections.java:1232)
    at org.dromara.edu.service.impl.EduClassServiceImpl.fillNames(EduClassServiceImpl.java:135)
    at org.dromara.edu.service.impl.EduClassServiceImpl.queryPageList(EduClassServiceImpl.java:89)
```

`fillNames` 在集合为空时用 `Map.of()` 作兜底，而 `Map.of()` 是**不可变 Map**：`Map.of().get(null)`
会走 `Objects.requireNonNull` 直接抛 NPE。班级行里只要有一个外键为空（本次是 `campus_id`，教学班/未指定校区的班级都会为空），
整个分页查询就 500。

## 3. 修复

| 文件 | 改动 |
|---|---|
| `EduClassServiceImpl.fillNames` | 4 个兜底 Map 从 `Map.of()` 改成 `Collections.emptyMap()`；4 处取值改成「外键为空则不查 Map」（`row.getX() == null ? null : map.get(...)`） |
| `ClassRosterExportHandler.toRows` | 同一缺陷模式加固：`Map.of()` → `Collections.emptyMap()`，`students.get(member.getStudentId())` 加空键保护 |

全库扫描确认 `ruoyi-edu` 内其余 `Map.of()` 用法只有 `EduImportTaskRunner` 一处，键是字符串字面量，不受影响。
