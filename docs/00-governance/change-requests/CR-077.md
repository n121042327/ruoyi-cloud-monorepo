## 口径

- 审批通过后学生选科**立即生效**并记录生效时间与审批人，相关统计与缓存失效（`REQ-STR-036` / `040`）；教学班名单**不会自动同步**，需教务主任人工触发增量生成并核对差异（`REQ-STR-060`）。
- 审批页必须同时展示原组合与新组合（`REQ-STR-038`）；驳回意见必填（`REQ-STR-037`）；审批动作写入审计，含审批人 / 意见 / 时间（`REQ-STR-039`）。
- 生成预览只读不写；执行按组合新建或增量并入，已存在的同组合教学班不重复创建（幂等）；核对差异只提示不自动修正。
