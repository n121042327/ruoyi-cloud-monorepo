## 口径

- 变更明细只列发生变化的字段，含变更前值与变更后值（`REQ-AUD-003`）。
- 日志只允许追加、不可修改与删除；抽屉与接口层都没有编辑 / 删除入口（`REQ-AUD-025` / `030`）。
- 日志本身不含敏感字段明文，只记录字段名与掩码值（`REQ-AUD-010`）。
