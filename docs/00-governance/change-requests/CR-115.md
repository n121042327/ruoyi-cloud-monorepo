- **变更记录**：接审计时间线 `listObjectChangeLog('class', classId)`，按操作时间 / 操作人 / 类型 / 结果 / 明细展示。

## 2. 后端修复：班级详情的名称字段为空

实测发现 `GET /edu/class/{id}` 返回的 `schoolName` / `gradeName` / `termName` 全为空 —— `EduClassServiceImpl.queryById`
用的是 MyBatis-Plus 的 `selectVoById`（单表查询，不 join），而 `EduClassMapper` 注释里规划的
`resources/mapper/edu/EduClassMapper.xml` 从未创建。

处置：在 Service 层补 `fillNames(List<EduClassVo>)` —— 按 id 集合对学校 / 年级 / 学年学期做三次批量查询后回填，
列表与详情共用同一方法，避免 N+1，也不需要新写 XML。编译：`mvn -o -DskipTests -pl ruoyi-modules/ruoyi-edu -am compile`
→ **BUILD SUCCESS**。

> 该改动需要**重启 ruoyi-edu 服务**才会在页面生效（当前进程仍是旧字节码）。
