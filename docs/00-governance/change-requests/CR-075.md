## 口径

- 首选科目只能是物理或历史（`BV-STREAM-001` / `BR-STREAM-001`），不提供其它选项；再选科目固定为化学 / 生物 / 思想政治 / 地理，必须选满 2 门且不能重复（`BR-STREAM-002`），组合结果共 12 种。
- 选科配置按学年学期保存；开放日期不能晚于截止时间；默认「逾期变更需校级管理员审批」（`BR-STREAM-005`），逾期提交进入审批待办（`PAGE-STR-APPROVE`）。
- 学生侧：开放期内提交直接生效（首次 `submitMyStream` / 变更 `updateMyStream`）；截止后提交必须填写变更原因，转为变更申请，审批通过前保持原选科不变。
- 选科结果决定教学班归属；行政班不变（教学班与行政班是两套独立关系）。
- 配置保存与选科提交都写审计（`NFR-AUDIT-01`）。

## 边界

- 结构对照首轮报「原型 0 列 / 生产页 4 列」，原因是把「未选科学生」弹窗的表格放在页面文件里；检查器只比对页面文件里的全部 `el-table-column`，因此**凡不属于主表的表格一律放子组件**（本批把未选科学生、选科历史两个弹窗拆到 `components/`）。这条经验已写入本 CR 与 D-150。
