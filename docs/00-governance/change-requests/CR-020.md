## 原因与内容

旧版静态选项没有学校归属标记；学校变化未重建选项，也未立即刷新筛选结果。
以 `content-samples.json` 中已有班级归属标记学校与年级，对原有选项按学校与年级收窄，
保留空班；无效值清空，切校、切年级、深链接与空态清空均执行同一重建规则。
页头与分页明确显示筛选后的样例行数，避免把 137 的静态演示总数当成筛后真实总数。

通用级联规则写“年级与班级互不约束”，学生 PRD 写“选择年级后联动”。
用户裁决仅学生列表按后者执行；本批不改变其他列表的规则。

回归还发现高保真外壳没有执行 `data-role-enabled`，使学校角色的学校下拉未禁用。
在新外壳中补齐与业务外壳一致的声明式角色禁用，超级管理员仍按既有例外放行。
独立审查随后发现角色切换遗留他校上下文，新增 SC-18 / SC-19 复现后修复：
两个 v2 外壳派发角色变更事件，页面对学校角色恢复样例所属学校再重建选项，深链接也走同一规则。
根据用户追加的筛选逻辑核查，学校移至筛选区首位，其后学年学期、年级、班级；SC-20 验证顺序。

## 影响与替代方案

本批仅一个学生列表文件及其已有浮层。v1 保留原样；新页面复用只读 v1 CSS，
非样板菜单与跨页跳转继续指向 v1，不把 v2 声称为全站版本。未变动 API、DDL 或生产代码。
替代方案为继续延期并登记缺口；代价是后续仍无法逐项验收筛选与映射。
若修复有误，会影响样板筛选选项及样例结果；可继续查看保留的 v1，原业务数据不受影响。
