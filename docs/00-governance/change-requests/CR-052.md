# CR-052 — 阶段 6 第九批：班级管理列表页 + GAP-086 登记

本批原计划做学生导入向导，但发现它的动作有两套接口（见下），按缺项流程先登记；
同批改为交付**班级管理列表页**（第二个模块的列表样板，不依赖该裁决）。

## 一、新缺项 GAP-086（open）

学生导入向导的「下载模板 / 上传校验 / 确认执行 / 下载失败行 / 下载结果」在两份 PRD 里各有一套接口：

- 导入导出模块：`downloadImportTemplate`（`/edu/import/template/{module}`）、`validateImportFile`、`executeImport`、
  `downloadImportFailedRows`、`downloadImportResult`；
- 学生模块：`downloadStudentImportTemplate`、`importStudentValidate`、`importStudentExecute`。

冻结原型 `prototypes/functional/v1/pages/student-import.html` 的动作全部指向**通用接口**，
而 `requirement-links.yaml` 的 `REQ-STU-052 ~ 060` 挂的是**学生模块**的三个接口。
同一个导入批次会出现两个写入口，与 `DP-01` 冲突。推荐 A：统一走导入导出模块的通用接口，
学生模块的三个接口标注废弃；未裁决前**学生导入向导页面不做**。
