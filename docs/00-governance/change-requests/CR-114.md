# CR-114 — 阶段 6 第三十三批：排版检查器（文字不换行 / 组件对齐）+ 折行修复

用户附了两张截图反馈：查询区「证件号后四位」label 折成两行、学校管理页操作列
「校区管理 / 学段配置」各占一行。要求「增加同时检查组件对齐、文字不换行」。

## 1. 根因

| 现象 | 根因 |
|---|---|
| 查询区 label 折行 | Element Plus 的 `.el-form-item__label` 默认允许换行，inline 查询表单里没有 `nowrap` 保护；label 文本越长越先被折（「证件号后四位」比「学年学期」长一个字） |
| 操作列按钮折行 | `.el-table .cell` 默认 `white-space: normal`，学校管理页操作列 `width="220"` 放不下同行 4 个按钮（编辑 / 停用 / 校区管理 / 学段配置 ≈ 230px） |

## 2. 修复

| 位置 | 改动 |
|---|---|
| `src/assets/styles/index.scss` | 新增两条排版保护：`.el-form--inline .el-form-item__label { white-space: nowrap }`、`.el-table .cell > .el-button { white-space: nowrap }` |
| `school/sch_list/index.vue` | 操作列 `width` 220 → 260；`page-head` 从 `<template v-else>` 内移到根容器第一位（与其余 39 页一致）；`scope-hint` 文案统一为「数据范围：本租户 · 可写」 |
| `student/stu_list/components/GuardianTable.vue`、`StudentDetailDrawer.vue` | 操作列补 `fixed="right"`（横向滚动时不再与数据列错位） |

## 3. 新增检查器 `tools/check_fe_text_nowrap.py`

五条规则，全部可自动判定：

1. **全局排版保护在位** —— `index.scss` 必须含上述两条 `nowrap` 规则（防回归）；
2. **操作列宽度足够** —— 按「同行最多同时出现的按钮」估算总宽：无条件按钮全部计入；
   带 `v-if` / `v-else` 的按钮按条件字符串分组，**同组相加、组间取最大值**；
   `<template v-if>` 包裹的整块算一个条件组。
   估算口径：中文 14px、其它字符 8px、按钮间距 12px、单元格左右内边距 26px。
3. **page-head 在根容器第一位** —— 否则标题区会跑到查询区下方；
4. **同一 `el-form` 不混用 `label-width`** —— 混用会让标签与控件基线不一致；
5. **操作列必须 `fixed="right"`**。

第 2 条的分组口径是必要的：`prm_list` 的操作列有 15 个按钮，但按状态分支互斥、同行最多 3 个，
若不分组会得出「需要 922px」的假结论；分组后为 162px，`width="240"` 合理。

**自检**：把 `sch_list` 操作列临时改回 220，检查器输出
`操作列宽度不足：width=220，估算需要 230（编辑 / 校区管理 / 学段配置 / 停用）` 并返回 exit 1；
恢复 260 后通过。
