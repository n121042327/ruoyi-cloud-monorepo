## 2. 变更原因

批次 2-7b 落地「组合分布统计 / 变更审批待办 / 按组合生成教学班 / 教学班管理」四页时，公共前置反查暴露两处缺口：

1. **教学班的三个动作没有接口落点**。班级 PRD 8 节只登记了列表与新建，
   而 4.6 节的 `REQ-CLS-038` ~ `042` 与 6.1 的「列表页 + 抽屉」都要求「看详情」「停用」「看成员」。
   原型只能给按钮写一个不存在于接口清单的 `data-api`，阶段 4 的接口清单会缺这三项。
2. **教学班能否手工新增没有裁决**。4.6 节 `REQ-CLS-038` 说「支持创建教学班」，
   但没有说入口在哪。若在 `PAGE-CLS-TEACHING` 再放一个「手工新增成员」，
   就与 `REQ-STR-056`（成员写入归班级模块、由生成流程触发）形成两条写入路径，违反 `DP-01`。
