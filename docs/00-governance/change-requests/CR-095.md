## A1 — 学生联系电话落点（阶段 5 新版本）

| 落点 | 说明 |
|---|---|
| `docs/40-detailed-design/migrations/V6__edu_student_contact.sql`（新增） | **追加式增量**：`ALTER TABLE edu_student_enrollment ADD COLUMN student_phone varchar(20)`；V1—V5 冻结版本不动 |
| `docs/40-detailed-design/database/schema.yaml`（改） | 事实源 `edu_student_enrollment` 增加 `student_phone` 列定义（敏感字段），下次完整重新生成时并入 V1 的 CREATE TABLE |
| `docs/10-prd/06-field-dictionary.yaml`（改） | `student_phone` 补 `note`，写明落点是 `edu_student_enrollment.student_phone` 与权限口径 |
| `.../domain/EduStudentEnrollment.java`（改） | 实体增加 `studentPhone` |
| `.../domain/vo/EduStudentPhoneVo.java`（新增） | 响应体形如 `{ studentPhone }`，与前端 `viewStudentPhone` 的声明一致 |
| `.../service/impl/EduStudentProfileServiceImpl.java`、`IEduStudentProfileService.java`（改） | `viewStudentPhone`：取在校记录 → 返回完整电话 → 写敏感数据访问日志 |
| `.../controller/EduStudentProfileController.java`（改） | `GET /{studentId}/phone`，权限 `person.student_contact:read_contact` |

口径：默认掩码是列表页的展示口径（掩码展示**不记录**日志，`REQ-AUD-009`）；只有本接口这种「查看全量」才留痕
（`REQ-AUD-008` / `BR-AUDIT-002`）。学校上下文缺失时按 `DS-DENY-02` 拒绝而不是写不完整日志——学生主体是平台级实体，
经在校记录两段式取数（`DS-DENY-09`），审计日志的 `school_id` 只能来自在校记录。

## B1 — 学生照片走统一文件服务

仓库里文件服务**已经存在**：`ruoyi-api-resource` 的 `RemoteFileService` + `ruoyi-resource` 的
`RemoteFileServiceImpl`（底层 `OssClient`）。因此 B1 没有新建模块，只做两件事：

| 落点 | 说明 |
|---|---|
| `ruoyi-api/ruoyi-api-resource/.../RemoteFileService.java`（改） | 新增 `byte[] downloadByUrl(String url)`：`photo_url` 只存地址，取原图字节需要它（与既有 `upload` / `selectUrlByIds` 配套） |
| `ruoyi-api/ruoyi-api-resource/.../RemoteFileServiceMock.java`（改） | 降级实现同步补齐（否则接口变更会让 mock 编译失败） |
| `ruoyi-modules/ruoyi-resource/.../dubbo/RemoteFileServiceImpl.java`（改） | 实现：`removeBaseUrl` 还原对象键 → `getObjectContent` 取流 → 字节数组；与 `SysOssServiceImpl.download` 用同一套 OssClient |
| `services/RuoYi-Cloud-Plus/ruoyi-modules/ruoyi-edu/pom.xml`（改） | 引入 `ruoyi-api-resource` 依赖（Dubbo 远程契约） |
| `.../service/impl/EduStudentProfileServiceImpl.java`（改） | `uploadStudentPhoto`：校验后缀（jpg/jpeg/png/webp）与大小（≤ 2 MB，拒绝可执行文件与伪装扩展名，`NFR-SEC-04`）→ 调文件服务上传 → 只把返回的文件地址写进 `edu_student.photo_url`；`getStudentPhoto`：先写敏感访问日志再按地址取字节 |
| `.../controller/EduStudentProfileController.java`（改） | `POST /{studentId}/photo`（`multipart/form-data`，权限 `person.student:update`）、`GET /{studentId}/photo`（返回二进制，权限 `person.student:read_sensitive`） |
