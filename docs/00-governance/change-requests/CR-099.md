## 关键口径

- **nacos 在 bridge 下必须用服务名连库**：`db.url.0` 覆盖为 `jdbc:mysql://mysql:3306/ry-config...`；
  Windows 上跑的服务连库/连 nacos 仍然用 `127.0.0.1`（`datasource.yml` 保持 `localhost:3306` 不变），
  两种形态各自成立，互不影响。
- **互斥提醒**：compose 里的 app 服务（gateway/auth/system/resource/edu/…）现在也是 bridge，
  但它们仍按 `127.0.0.1` 找 nacos、按 Nacos 配置里的 `localhost` 找库，所以**不要 `docker compose up -d` 全起**；
  本机推荐只起基础设施：`docker compose -f script/docker/docker-compose.yml up -d mysql redis nacos minio`。
  若将来要容器化跑应用，需要另一轮把 nacos 地址与数据源 host 改成服务名——但那样会和 Windows 上跑的服务抢端口。
