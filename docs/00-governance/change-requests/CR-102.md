# CR-102 — 阶段 7 第二十三批（一）：超管权限通配符补两段式 `*:*`，修 edu 全量 403

用户反馈：admin 重新登录后左侧能看到「教育管理」菜单，但点开任何教育页面都提示**没有权限**。

## 1. 现象与定位

| 步骤 | 观察 |
|---|---|
| 用同一个 admin token 调接口 | `/system/user/list` 200、`/resource/oss/list` 200，而 `/edu/grade/list`、`/edu/school/current`、`/edu/subject/list` 返回 `{"code":403,"msg":"没有访问权限，请联系管理员授权"}` |
| `logs/ruoyi-edu/error.log` | `SaTokenExceptionHandler - 请求地址'/edu/grade/list',权限码校验失败'无此权限：org.grade:read'` |
| Redis 会话 `global:Authorization:login:token-session:<token>` | `loginUser.menuPermission = ["*:*:*"]`（超管默认），说明不是会话丢失、也不是菜单没授权 |

用「改 Redis 会话里的 `menuPermission` 再打接口」做对照实验（每次间隔 6.5 秒，避开 `PlusSaTokenDao` 的 5 秒 Caffeine 本地缓存，`ruoyi-common-satoken/.../core/dao/PlusSaTokenDao.java` 第 27-42 行）：

| 会话里的 `menuPermission` | `/edu/grade/list`（`org.grade:read`，1 个冒号） | `/system/user/list`（`system:user:list`，2 个冒号） |
|---|---|---|
| `["*:*:*"]` | **403** | 200 |
| `["*:*:*","org.grade:read"]` | 200 | 200 |
| `["*:*"]` | 200 | 200 |
| `["*"]` | 200 | 200 |

**根因**：RuoYi 超管通配符 `*:*:*` 走 Sa-Token 的模糊匹配，要求被校验的权限码里**至少有两个冒号**才能命中；
而本项目的权限矩阵 `docs/10-prd/05-permission-matrix.yaml` 采用「资源:动作」两段式权限码
（`org.grade` / `person.student` / `stream.config` …，CR-016 已把选科权限码对齐到该矩阵），
ruoyi-edu 的 183 个 `@SaCheckPermission` 全部只有 1 个冒号 —— 于是超管在 edu 上一个都命中不了，
而 system / resource 用的仍是 stock 三段式（`system:user:list`），所以只有 edu 全线 403。

## 2. 改动

| 路径 | 改动 |
|---|---|
| `services/RuoYi-Cloud-Plus/ruoyi-modules/ruoyi-system/src/main/java/org/dromara/system/service/impl/SysPermissionServiceImpl.java` | `getMenuPermission` 的超管分支在 `perms.add("*:*:*")` 之后补 `perms.add("*:*")`（两段式通配符），并写明依据 |

不改前端：`apps/plus-ui/src/utils/permission.ts` 的 `checkPermi` 用 `'*:*:*'` 短路，行为不变；
不改 edu 控制器：183 个权限码仍按权限矩阵取值，符合「字段/接口不以实现者口味自造」的口径。

## 3. 验证

- `mvn -o -DskipTests -pl ruoyi-modules/ruoyi-system -am compile` → **BUILD SUCCESS**（17.1 s，ruoyi-system class 数 267）；
  反编译/字节检查 `SysPermissionServiceImpl.class` 同时含 `*:*:*` 与 `*:*`。
- 会话置 `["*:*:*","*:*"]`（等价于修复后重新登录生成的快照）后复测：
  `/edu/grade/list`、`/edu/subject/list`、`/edu/class/list`、`/edu/student/list`、`/edu/term/list`、`/edu/audit/log/list` **全部 200**。

## 4. 生效条件

权限快照在**登录时**由 `RemoteUserServiceImpl` 写入会话，改代码后必须：**重启 `ruoyi-system` → 重新登录**。
本次排障期间已把当前会话临时补成 `["*:*:*","*:*"]` 便于当场验证，重新登录后即为正式快照。
