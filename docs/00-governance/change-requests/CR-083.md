## 口径（与 PRD / BR 对齐）

- 学年编码必须是 `YYYY-YYYY` 且为**连续两个自然年**（`REQ-TERM-008` / `BR-TERM-003`），同一学校内唯一（`REQ-TERM-009`）。
- 学年日期**连续不重叠**：新学年的区间与已有学年区间相交时直接拒绝（`RV-TERM-08`）。
- 学期日期必须落在所属学年范围内，且同校学期之间不重叠（`REQ-TERM-015` / `016`）。
- 新建学年时**同步创建默认学期结构**（第一学期 / 第二学期，日期按学年对半切），允许后续微调（`REQ-TERM-012`）。
- 同一学校同一学年只能有一个当前学期（`BR-TERM-002`）：`setCurrentTerm` 先把该校全部学期置 `is_current='0'`，再把目标置 `'1'`；已归档的学年 / 学期不允许设为当前。
- 删除学期前做引用检查，已被班级或花名册引用则拒绝删除（`REQ-TERM-019`）；当前学期直接不允许删除。
- 归档学年时**级联归档**其下未归档的学期并清掉当前标记（归档后不在新建业务的可选列表，`REQ-TERM-030`）；归档可撤销（`REQ-TERM-033`），两者都要求原因 ≥ 5 字。
- 引用检查覆盖四类（`REQ-TERM-029` / `034`）：班级数与花名册人数本批已接（`edu_class` / `edu_class_member` 已交付）；任教关系数与选科人数在教师模块、选科模块交付后填充，`TermReferenceVo` 字段不变。

## 一处口径澄清（承接 CR-071 留的待办）

CR-071 曾记「`checkTermReference` 的路径参数在 OpenAPI 里是 `/edu/term/{id}/reference`，本批按学年 ID 传入；若后端确认它接收的是学期 ID，需对齐后回改」。
本批定为**按学年 ID**：路径变量命名为 `{academicYearId}`，检查范围是该学年下的全部学期（聚合计数），
与前端 `AcademicYearArchiveDialog` 传入 `academicYearId` 的调用一致；PRD 6.1 的归档流程也是「归档学年时先看引用」。
