## 2. 为什么用 table_index=3

`teacher-assign.html` 有 5 张 `table`：第 1 张是左侧班级选择面板、第 3 张才是任教关系主表；
此前 `PAGE-TCH-ASSIGN` 条目的 `filter_note` 记录了「默认切片取不到主表列」，
现在检查器已支持 `table_index`（1-based），组件级条目可以直接指到主表。

## 4. 标注型原型改动的口径

本批对原型的改动**只有 `data-role` / `data-field` 元数据**，不改任何可见文案、列序与结构。
这类「标注补齐」是让既有原型可被检查器读取，不构成视觉或业务内容的版本变更；
若阶段 8 收口时需要严格的文件级版本化，再统一把 v1 原型整体升版。
