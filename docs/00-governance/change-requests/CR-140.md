## 1. 交付

| 项 | 说明 |
|---|---|
| `job/ClassRosterExportHandler` / `ClassRosterExportRow` | 编班表导出器（`class_roster`），xlsx + csv，8 列 |
| 默认列 | 班级 / 学号 / 姓名 / 性别 / 学籍状态 / 加入日期 / 监护人 / 联系电话（掩码） |
| 用的取数 | `edu_class_member`（学校 + 行政班 + 在班）→ `edu_student` → `edu_student_enrollment`（学籍状态）→ `edu_student_guardian` + `edu_guardian`（主监护人优先）→ `edu_class`（班级名） |

## 2. 两个判断

1. **加「班级」列**：花名册列表在班级详情里不需要班级列（上下文已定），但导出器支持两种用法 ——
   传 `classId` 导单班、不传导全校；不传时没有班级列就看不出归属，且导入模板里的「目标班级」列正与之对应。
2. **只导行政班**：`class_type = 'administrative'`。教学班是选科组合班，与行政班的编班表不是一回事
   （AGENTS 第 7 节：行政班与教学班是两套独立关系），混在一张表里会让「一个学生多个班」看起来像数据错误。
