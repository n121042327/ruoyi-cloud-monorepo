## 口径

- 任务列表默认只显示本人发起的任务；任务结果的查询与下载都重新解析数据范围（`REQ-IMP-032` / `036`）。
- queued 可取消；failed / partial_failed 可重试，重试沿用原批次号与幂等键，不产生重复数据（`REQ-IMP-034` / `037`）。
- 超过最大重试次数进入死信，运维可查看与重放，**重放动作写入审计**（`REQ-IMP-038`）；两个危险动作都做二次确认。
