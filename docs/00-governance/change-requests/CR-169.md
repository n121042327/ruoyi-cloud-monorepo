# CR-169 — 阶段 8 验收缺陷修复（第三批）：花名册行字段与年级列表计数

按「学校 → 校区 → 年级 → 班级 → 教师 → 学生」的业务链路验收时，`/edu/class/{id}/roster` 与
`/edu/grade/list` 暴露两个取值缺陷，本批修复。

## 1. 花名册行字段全空

- 现象：编班成功后 `GET /edu/class/{classId}/roster` 返回 `total=1`，但行里
  `studentNo / studentName / gender / enrollmentStatus / className / currentClassName` 全为 null ——
  花名册页面只看得到行存在，看不到学生是谁。
- 根因：`EduClassServiceImpl.queryRoster` 只做了 `fillGuardians`，没有回填学生主体与班级名称。
- 修复：新增 `fillRosterFields`：按 `edu_student`（学号 / 姓名 / 性别）、`edu_student_enrollment`（学籍状态）、
  `edu_class_member(status='1')` → `edu_class`（当前行政班与班级名）批量回填；在 `fillGuardians` 之前调用。

## 2. 年级列表「班级数 / 在读学生数」恒为 0

- 现象：年级列表与详情显示 班级数 0 / 在读学生数 0，但该年级确实有 1 个行政班、1 名在班学生
  （抽屉「下辖班级 共 1 个行政班」是对的）。
- 根因：`edu_grade.class_count / student_count` 是建年级时写死的 0（`insertByBo` 里
  `add.setClassCount(0)`），此后编班 / 建班都没有维护，列表直接读这两个过期列。
- 修复：年级列表改为**实时统计**（`fillListCounts`）：班级数按 `edu_class.grade_id` 计数；
  在读学生数按这些班级下 `edu_class_member.status='1'`（在班）的记录数统计。存量列暂不迁移（后续若要可加定时任务回填）。

## 3. 登记但本批未修（缺口 GAP-118）

| 项 | 现象 | 需要的动作 |
|---|---|---|
| 班级列表「在读」列 | `enrolledCount` 为 null，页面显示 0（实际 1 名在班学生） | 与年级同样做实时统计（或维护 `edu_class.enrolled_count`） |
| 班级「类型」列 | 页面显示 `administration`（英文码值），且与后端常量 `administrative` 不一致 | 列表返回中文（行政班 / 教学班），并核对迁移种子里的班级类型取值 |
| 年级「所属学校」 | 列表与详情 `schoolName` 为 null（显示「—」） | 按 `edu_grade.school_id` 回填 |
| 学生「联系电话」 | `EduStudentVo` 没有该字段（数据在 `edu_student_enrollment.student_phone`，敏感字段） | 需掩码 + 查看留痕，属功能补齐 |
