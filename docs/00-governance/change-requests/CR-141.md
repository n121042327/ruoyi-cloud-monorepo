## 2. 模板列与校验规则的来源

- 模板列 = 学生 PRD 第 4.8 节「导入模板列」14 列（姓名 / 性别 / 入学年份 / 学段 / 年级 / 班级 / 全国学籍号 /
  证件类型 / 证件号码 / 出生日期 / 监护人姓名 / 与监护人关系 / 监护人电话 / 联系地址），顺序固定，
  **不含学号**（BR-STU-019：学号由系统发号）；
- 校验维度 = `REQ-STU-054`：必填缺失、格式错误、年级或班级不存在、证件号重复、全国学籍号重复、文件内自身重复。

## 3. 两个实现细节

1. **表头严格比对**：不做「按列名找列」的宽松匹配 —— 模板列顺序固定是 PRD 明写的（REQ-STU-052），
   宽松匹配会让「列错位」这种致命问题变成静默错数据。
2. **统一目标班级优先**：选了 `targetClassId` 时忽略文件里的班级列（`EduImportValidateBo` 的既有口径），
   因此也不再校验文件里的班级是否存在。
