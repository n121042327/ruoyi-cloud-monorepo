# CR-124 — 阶段 6 第四十三批：新建 / 编辑学期

第二轮队列第 2 项。学年有「新建学年」入口（`addAcademicYear`，已接），但学期一直只能由学年创建时
按 `termCount` 顺带生成，学期管理页没有「新增学期」，后端 `POST /edu/term`（`saveTerm`）无人调用。

## 1. 交付内容

| 层 | 内容 |
|---|---|
| api 层 | 补 `saveTerm`（POST /edu/term，有 `termId` 为编辑） |
| 类型 | 补 `TermForm`（对齐 `EduTermBo`：academicYearId / termCode / termName / startDate / endDate / isCurrent） |
| 弹窗 | 新增 `TermFormDialog`（学期名称 / 开始日期 / 结束日期，「设为当前」开关） |
| 页面 | 学期管理页工具栏加「新增学期」；操作列加「编辑」（原只有删除），列宽 120 → 160 |

## 2. 口径

- **新建学期**必须挂在某个学年下：`academicYearId` 从当前页面的路由参数取（学期管理页本来就是
  「某个学年的学期列表」），弹窗内不重复选择学年。
- **日期校验**：学期名称、开始日期、结束日期必填；结束日期必须晚于开始日期（前端校验，
  后端也有校验）。
- **设为当前**：开关对应 `isCurrent`（'1' / '0'）。页面提示「同一学校同一时间只允许一个当前学年学期」，
  唯一性由后端保证。
- **termCode** 不由前端填写：`edu_term.term_code` 校内唯一，由后端按命名规则生成，
  前端不暴露该字段（避免与自动生成规则冲突）。
- 编辑复用同一弹窗与同一接口（`saveTerm` 按 `termId` 是否存在区分新建 / 编辑）。
