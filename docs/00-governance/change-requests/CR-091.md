## 口径（与 PRD / BR / 权限矩阵对齐）

- 导入向导固定四步「下载模板 → 上传文件 → 校验结果 → 确认执行」（`REQ-IMP-001` / `BR-IMP-001`）；**校验阶段不写业务数据**，校验结果有效期 24 小时，过期需重新上传（`REQ-IMP-014` / `BR-IMP-008`）。
- **幂等**：同一文件 + 同一模块在 24 小时内重复校验复用原批次（`REQ-IMP-017`）；`executeImport` 命中已有任务时返回第一次的任务并标记 `createdNewTask=false`（`BR-IMP-002` / `BR-IMP-009`）；导出与导入都落 `edu_async_task` 以便统一追踪与重试。
- **上传限制**：单文件 ≤ 10 MB 在服务层直接拒绝（`REQ-IMP-004` / `BR-IMP-010`）；5000 行上限写进校验结果指引（`REQ-IMP-051`，行数需解析文件才能判定）。
- **失败原因分组**：校验结果返回 `failGroups`，便于一次性修正同类问题（`REQ-IMP-007` / `BR-IMP-016`）；失败行明细经辅助端点分页（`REQ-IMP-006`）。
- **模板版本**：旧版本模板**仍可下载**并给强提示（`REQ-IMP-003` / `IMP-Q-05` 已裁决）；当前版本按 `status='1'` 取。
- **结果文件**：过期下载一律拒绝（`BR-IMP-013` / `REQ-IMP-031`）；下载返回 5 分钟短时签名链接描述并 `download_count + 1`（`REQ-IMP-042`）。
- **导出**：格式限 `xlsx` / `csv`，默认 `xlsx`（`REQ-IMP-026`）；**导出前重新解析数据范围**（`REQ-IMP-025` / `DS-DENY-04`）；**明文导出**要求调用方持有模块对应的 `read_sensitive`（未登记模块一律拒绝，不回退放行），映射取自 `docs/10-prd/05-permission-matrix.yaml` 的资源清单（`REQ-IMP-028` / `BR-IMP-012`）。
- **权限口径**：导入 / 导出类端点按 `05-permission-matrix.yaml` 的资源动作写成 `<resource>:import` 与 `<resource>:export`（而不是统一写 `:create`），因为矩阵为每个资源显式列出了 `import` / `export` 动作，PRD 5.1 也把「发起导入 / 发起导出」分别挂到 `data.import` 的 `import` 与 `data.export` 的 `export` 上。
- **批次可见性**：非平台范围只能看本人发起的批次（与 CR-090 的任务中心同口径），平台运营按 `super_admin` 放行。
- **辅助端点**：`GET /edu/import/{batchNo}/rows` 是契约外的辅助端点，理由是 `REQ-IMP-006` 明确要求「校验结果**分页展示**」而契约里只有文件下载；做法与 CR-088 的两个辅助端点一致，已在本文档登记。
