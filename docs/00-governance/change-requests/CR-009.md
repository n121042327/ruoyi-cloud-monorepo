## 2. 变更原因

### 2.1 `GAP-040`：三个浮层的载体与 `D-059` 冲突

`docs/10-prd/modules/class/PRD.md` 第 336 行写「新建班级 = 抽屉」、第 338 行写「添加学生 = 抽屉（左侧学生池 + 右侧待加入）」，
而 `D-059`（由 `CR-008` 落地）已经裁决：**表单类浮层统一用弹窗，含表格或分页的内容用独立页**。
班级新建是表单；添加学生是本校学生池的检索 + 多选（等价于含表格），两者都应按 `D-059` 修正。

反查同时发现 `navigation.yaml` 第 96 行的 `PAGE-CLS-BATCH` 被登记为 `drawer`，
而 PRD 第 337 行写的是**弹窗**——这是原型规范与上游 PRD 不一致，按上游优先原则一并修正。

### 2.2 `GAP-041`：5 个 PRD 要求的页面未登记

以下内容由已冻结 PRD 明确要求，但 `navigation.yaml` 的 `pages` 里没有条目，
导致班级列表「指定班主任」入口与升班预览的逐条调整无法接线（点了没反应或给出错误提示）：

| 序号 | 内容 | PRD 依据 |
|---|---|---|
| 1 | 指定 / 变更班主任（含生效日期） | class PRD 第 177 行 `REQ-CLS-006`、第 264 ~ 267 行 `REQ-CLS-048` / `050`、第 358 行 6.3 |
| 2 | 复制班级 | class PRD 第 213 行 `REQ-CLS-061` |
| 3 | 批量迁学生 | class PRD 第 214 行 `REQ-CLS-062` |
| 4 | 停用 / 删除的二次确认 | class PRD 第 252 ~ 258 行 `REQ-CLS-043` ~ `047` |
| 5 | 升班预览中的学生去向调整 | promotion PRD 第 352 行 6.3、第 188 行 `REQ-PRM-017` / `018` |

## 3. 变更内容

1. **`PAGE-CLS-CREATE`**：抽屉 → **弹窗（md）**。表单类浮层，按 `D-059`。
2. **`PAGE-CLS-BATCH`**：抽屉 → **弹窗（md）**。与 class PRD 第 337 行一致。
3. **`PAGE-CLS-ROSTER-ADD`**：抽屉 → **独立页**（`route: /edu/class/roster/add`）。
   左「本校学生池（可检索列表）」右「待加入清单」，按 `D-059` 的「含表格或分页 → 独立页」，
   同时解决抽屉宽度装不下双栏选择器的问题。
4. **新增 `PAGE-CLS-LEADER`**：指定 / 变更班主任，**弹窗（md）**。
   唯一写入入口（`DP-01`、`REQ-CLS-048`），支持生效日期与历史任职（`REQ-CLS-050`）。
5. **新增 `PAGE-CLS-COPY`**：复制班级，**弹窗（md）**。以某班级为模板在指定学年学期与年级下生成新班级；
   不复制花名册与班主任（`REQ-CLS-061`）。
6. **新增 `PAGE-CLS-MOVE`**：批量迁学生，**独立页**（`route: /edu/class/move-students`）。
   含影响预览表格，按 `D-059` 用独立页；逐条校验唯一行政班（`REQ-CLS-062`、`BR-STU-003`、`DS-DENY-06`）。
7. **停用 / 删除二次确认**登记为**同页浮层片段** `DIALOG-CLS-DISABLE` / `DIALOG-CLS-DELETE`，
   按 `markup-contract.md` 第 215 行与 `DIALOG-GRD-DELETE` 的既有做法，不单独占页面编号。
8. **新增 `PAGE-PRM-ADJUST`**：升班预览中「调整学生去向」，**弹窗（md）**，父页面 `PAGE-PRM-PREVIEW`。
   可选留级 / 转班 / 毕业 / 跳过（promotion PRD 6.3）。
9. **`jump_map` 同步**：班级详情「添加学生」由 `overlay: drawer` 改为 `overlay: page`；
   新增「班级列表 → 指定班主任 / 复制班级 / 批量迁学生」与「升班预览 → 调整去向」四条跳转。
10. **动作组**：`page-actions.yaml` 新增 `class_list` 动作组 10 条（列表页全部可点元素），
    其余页面动作在各自小批交付时追加（`GAP-042` 选项 A）。

- **选项 B（班级模块维持抽屉）**：不返工 PRD，但阶段 6 要为抽屉单独写一套容器用法，

  抽屉没有先例可抄。

  与 `REQ-CLS-027` / `029` 的检索与批量添加要求不符，且一次最多只能加几个人。

  会在 2-3e 时二次改 `navigation.yaml` 与动作清单。
- **`GAP-041` 选项 C（暂不补）**：已冻结 PRD 要求的入口在原型里点不通，验收必然判为入口缺失。
