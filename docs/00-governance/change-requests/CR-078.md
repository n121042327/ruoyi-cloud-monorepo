## 口径

- 学生班级归属的唯一写入入口是班级管理（`DP-01`）；任教关系的写入入口是本页（`person.teaching_assignment:create`）。
- 权限与数据范围：教务主任可见全校；年级主任限本年级；平台运营只读并留痕；跨校任教需运营方授权且只读。
- 非在职教师（离职 / 调离）只保留查看与撤销离职登记，不可新增任教（`GAP-075` 的裁决口径）。
- 复制上一学年任教关系不覆盖目标学期已有配置；删除（结束）任教关系必须填原因并写审计。
- 教师导入：模板与校验规则由教师模块声明；导入幂等（同一批次重复提交不重复写入）；校验阶段不写业务数据；教师账号在导入成功后自动创建。
