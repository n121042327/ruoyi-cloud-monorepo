## 2. 口径

- **年级主任任职**（DS-05 的写入入口）：弹窗先列出该年级的任职记录（年级主任 / 是否主管 / 状态 / 学年学期），
  再指定新任职（教师 + 主管 / 协助）。一个年级同一学年学期只允许一名主管，由后端校验。
  离任走 `removeGradeLeader`（置 `status=0`，不物理删除），必须填原因。
- **归档**：`archiveGrade` 填原因后调用；已归档年级不再显示归档入口。
  归档后不允许新增班级，数据只读保留。
- **升班视图**：只读弹窗，展示「学段内序号 +1」的参考（含学段、年级、序号、升班去向、班级数、在读学生数）。
  页面明示「升班的执行入口在升班模块，年级管理不写数据」，与 AGENTS 第 7 节的模块边界一致。
  学段上限取 REQ-GRD-012：小学 6、初中 3、高中 3，到达上限显示「毕业（学段结束）」。
- **导出**：`handleExport` 原本已通过 `proxy.download('edu/grade/export')` 对接，本批补了 api 层函数备用，
  未改调用路径。
