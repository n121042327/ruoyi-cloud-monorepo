# CR-125 — 阶段 6 第四十四批：新增校区 / 变更学校编码 / 学校概要

第二轮队列第 3 项。前端 api 层此前缺 4 个接口：`getSchool`、`updateSchoolCode`、`addCampus`、
`getSchoolSummary`；校区管理页只有「刷新」和「停用」，学校列表没有变更编码与概要入口。

## 1. 交付内容

| 层 | 内容 |
|---|---|
| api 层 | 补 `getSchool` / `updateSchoolCode` / `addCampus` / `getSchoolSummary` |
| 类型 | 补 `CampusForm`（对齐 `EduCampusBo`）、`SchoolSummaryVO`（对齐 `SchoolSummaryVo`） |
| 弹窗 | 新增 `CampusFormDialog`（新增校区）、`SchoolCodeDialog`（变更编码）、`SchoolSummaryDialog`（学校概要） |
| 页面 | 校区管理页工具栏加「新增校区」；学校列表操作列加「更多▾」（变更编码 / 学校概要），列宽 260 → 340 |

## 2. 口径

- **新增校区**：`schoolId` 来自页面上下文（校区管理页本来就是「某学校的校区列表」，学校由
  `getCurrentSchool` 解析），弹窗内不重复选学校。校区名称与编码必填，地址 / 负责人 / 负责人电话选填。
- **变更学校编码**：单独弹窗（新编码 + 原因）。编码是导入 / 导出对照表的键，变更写审计 ——
  与变更学号（CR-118）、变更工号（CR-117）同一口径。
- **学校概要**：只读弹窗，展示学段 / 校区 / 学年 / 学期 / 年级 / 班级 / 教师 / 学科计数与初始化状态。
  数据来自 `getSchoolSummary`，不做本地聚合。
- 操作列的「更多▾」沿用 D-198 的口径：行内按钮最多 4 个，其余进下拉。
