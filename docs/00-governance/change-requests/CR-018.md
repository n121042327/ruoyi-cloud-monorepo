## 2. 变更原因

审计 PRD 6.3 的交互表把「导出」定义为打开一个导出配置弹窗，4.5 节又给这个弹窗规定了
格式（xlsx / csv）、行数上限（50000）、有效期（7 天）与用途说明；
但 6.1 的页面清单只列了 7 个页面，没有登记这个弹窗。

不补登记的后果：阶段 2 的原型要么把「导出」做成没有配置步骤的直出按钮（与 6.3 冲突），
要么给按钮写一个 `navigation.yaml` 里不存在的浮层编号 —— 这与 `GAP-054`（升班取消确认片段未登记）
和 `GAP-058`（教学班两个片段未登记）是同一类缺口，当时的处理方式都是补登记片段。

## 3. 变更内容

1. `docs/10-prd/modules/audit/PRD.md`：版本升 `1.0.1-draft` 并补变更记录；
   6.1 的 `PAGE-AUDIT-LOG-LIST` 行下补 `DIALOG-AUD-EXPORT` 的登记与口径。
2. `prototypes/functional/v1/navigation.yaml`：登记 `DIALOG-AUD-EXPORT`（dialog / md / parent `PAGE-AUDIT-LOG-LIST`）

3. `prototypes/functional/v1/page-actions.yaml`：新增 `audit_log` / `audit_ops_access` /
   `audit_sensitive_access` / `audit_security_event` / `audit_archive` 五组动作。
