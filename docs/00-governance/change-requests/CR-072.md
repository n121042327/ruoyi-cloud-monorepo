## 口径

- 升班按学年追加、不改写历史（`BR-PROMO-001`）；创建必填源 / 目标学年学期且目标必须晚于源（`REQ-PRM-007` / `008`）；目标学期年级与班级须齐备（`REQ-PRM-009`）。
- 预览不写入任何学生数据（`REQ-PRM-020`），重新预览覆盖旧明细（`REQ-PRM-021`）；可按源班级整体指定目标班级（`REQ-PRM-018`）。
- 校验通过才允许执行（`REQ-PRM-027`）；失败逐条记录原因，重试只处理失败项、已成功记录不重复执行（`REQ-PRM-032`）。
- 取消后保留已完成部分、不做整批回滚，可继续执行剩余项或逐条回滚（`REQ-PRM-036`），取消写入审计且不可删除（`REQ-PRM-058`）。
- 结果导出含成功 / 失败 / 留级 / 毕业四张清单（`REQ-PRM-034`）；任务台账导出（`REQ-PRM-019`）。
