## 口径

- 通用导入向导：各业务模块只声明模板与校验规则，引擎 / 批次 / 错误明细 / 结果文件都在导入导出模块（`REQ-IMP-002` / `GAP-086` 裁决）；导入幂等（`BR-IMP-002`）；模板字段变更必须升版本（`BR-IMP-007`）；「统一目标班级」填写后文件里的目标班级列被忽略。
- 失败行处理：选「忽略失败行」只导入可执行行；选「全部修正后重新上传」时执行按钮禁用（`IMP-Q-04` 口径）。
- 班级合并（GAP-088）：源班级全体在读学生在目标班级下新增在班关系，源班级置为「已停用」并保留历史花名册，**不物理删除**；已结束（休学 / 转出等）的学生不参与合并；合并按学年追加、不改写历史（`BR-PROMO-001`）；动作写审计。
