# CR-139 — 阶段 7 第五十八批：教师导出器（GAP-094 第二批续）

## 1. 交付

| 项 | 说明 |
|---|---|
| `job/TeacherExportHandler` / `TeacherExportRow` | 教师导出器（`teacher`），xlsx + csv，9 列 |
| 默认列 | 工号 / 姓名 / 性别 / 所属学校 / 教育角色 / 任教学科 / 任课班级数 / 在职状态 / 联系电话 —— 取自 `PAGE-TCH-LIST` |
| 敏感字段 | 联系电话默认掩码（前 3 后 4，BR-TEACHER-005）；明文导出需 `read_sensitive`，留给明文导出批次 |
| 范围 | 按 `edu_teacher.school_id = 任务学校` 过滤；缺学校上下文直接拒绝（D-218 口径） |

## 2. 聚合字段的取数

| 列 | 来源 |
|---|---|
| 教育角色 | `edu_user_role`（`status='1'`，`edu_role` 码值转中文） |
| 任教学科 | `edu_teaching_assignment`（`status='1'`）→ `edu_subject.subject_name`，多学科用「、」连接 |
| 任课班级数 | 同一批任教关系里 `class_id` 去重计数 |
| 所属学校 | `edu_school.school_name`（按任务学校取一次） |

全部按教师 ID 批量查询，避免 N+1。

## 3. 码值映射放在哪

教育角色与在职状态的中文映射写在**后端导出器**里（与前端 `enums/edu/TeacherEnum.ts` 一一对应）。
理由：导出文件是脱离前端的产物，后端必须自己能把码值翻译成可读中文；映射表在前端只是展示口径。
历史数据里若存在直接存中文的旧值（早期前端曾用中文当码值），`getOrDefault` 会原样透传，不会丢。
