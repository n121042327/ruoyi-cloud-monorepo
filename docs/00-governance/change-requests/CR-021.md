# CR-021 编班表四列清单补充版本

- 日期：2026-10-01
- 关联：GAP-056、REQ-CLS-035～037。
- 状态：列清单及后续业务裁决已确认并形成新版本补充；实现未执行。
- 决策依据：用户确认四列方案；随后选择学年、年级、班名组合定位，姓名不符阻止该行，行政班与教学班一起支持。

## 变更对象

保留 `docs/10-prd/modules/class/PRD.md`，新增
`docs/10-prd/modules/class/import-template-v2.md`，作为第 4.5 节编班表列清单的补充版本。
原 GAP-056 建议写第 4.6 节，但当前第 4.6 节是教学班，编班导入实际在第 4.5 节，故按实际位置引用。

## 原因与内容

PRD 只要求一行一个学生及目标班级列，原型另列推荐四列；新增版本明确列顺序与必填要求：
学号必填、姓名选填、目标班级必填、班级类型选填且默认行政班。
后续裁决补入新版本：学年、年级、班名组合定位，不采用编号定位；姓名不一致阻止该行；
行政班与教学班一起支持。仍使用导入向导既有的学校及目标学期上下文。
用户随后确认教学班组合不符阻止该行，重新生成保留合规导入关系（GAP-070）。

## 影响与替代方案

模板示例、下载定义与校验应最终引用同一列清单；当前原型已有相同四列，无需改变页面视觉。
校验规则有依据并获确认后，再同步相应原型、接口与验收细则。
替代方案为仅两列或继续延期；两列会失去姓名核对信息，延期会继续缺乏权威列清单。
若定位或核对规则选错，可能把学生编入错误班级，因此本批只落列清单，不执行未定义的校验。
