## 口径（与 PRD / BR 对齐）

- 教师主体带**所属学校**；跨校任教**不复制教师记录**，由任教关系的 `school_id`（任教学校）与 `edu_user_role` 表达（`BR-TEACHER-001`）。
- 工号**学校租户内唯一**（`BR-TEACHER-007`）；修改工号必须带原因（≥ 5 字），对应「需校级管理员权限并留审计」（`REQ-TCH-022`）。
- 新增教师**保存成功后自动创建登录账号**：账号信息在 `sys_user`（`edu_teacher` 只留 `user_id` 引用），通过 Dubbo 调 `RemoteUserService.registerUserInfo` 创建。
- 学校级教育角色只落 `edu_user_role`（校领导 / 教务主任），唯一键 `uk_user_role = tenant_id + school_id + user_id + edu_role`；移除角色置 `status='0'`。
- 任教关系是 **DS-07**（任课教师只看本人所授班级与学科）的权威来源；唯一键 `uk_assignment = term_id + teacher_id + subject_id + class_type + class_id`，重复保存时复用原记录；结束任教必须填原因且只置 `status='0'`。
- 复制上一学年任教关系时，目标学期已有同一「班级 + 学科」的行**跳过、不覆盖已有配置**。
- 非在职教师**不可新增任教**，且只保留查看与撤销离职登记（`GAP-075` 裁决），编辑与角色入口在服务层直接拒绝。
