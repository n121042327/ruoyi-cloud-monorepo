## 2. 两个明确的口径

1. **导入任务暂不领取**：执行者只领取 `taskType = export`。导入的解析器还没落地，先领取会把导入任务
   误标为失败，掩盖真实进度；`claimableTasks()` 里写死条件并注释引用 GAP-094a。
2. **多实例安全**：用「状态条件更新」抢占（`where task_status = 'queued'`），而不是先查后改；
   更新行数为 0 即认为他人已领取，直接跳过。

## 3. 默认列与字段来源

任教关系表只有 `term_id / teacher_id / subject_id / class_type / class_id / status`
（schema.yaml），**没有周课时列**，因此导出列定为：学年学期 / 学科 / 教师 / 工号 / 班级 / 班级类型 / 状态。
状态按 `'1' 有效 / '0' 失效` 翻译，班级类型按 `administrative 行政班 / teaching 教学班` 翻译。
