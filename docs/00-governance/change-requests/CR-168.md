# CR-168 — 阶段 8 验收缺陷修复（第二批）：编班落库、列表派生字段

阶段 8 运行时验收（蜀国 / liubei，含自建最小数据：1 学科 + 1 教师 + 1 学生 + 1 任教关系）连中 4 个缺陷，
本批一并修复。全部由运行现场与 `logs/ruoyi-edu/error.log` 定位，不是静态猜测。

## 1. 编班 / 调班插入失败：`edu_class_member.school_id` 未落库

- 现象：`POST /edu/class/{classId}/roster` 返回 `code 500`，堆栈为
  `DataIntegrityViolationException: Field 'school_id' doesn't have a default value`
  （`EduClassServiceImpl.insertMember` ← `addRoster`）。
- 根因：`insertMember` 只写 class_id / term_id / student_id 等，没有写 `school_id`，而该列 NOT NULL 无默认值。
- 修复：`insertMember` 改为接收 `EduClass`，显式落 `school_id`；`addRoster` / `transferClass` 两个调用点同步。
  顺带修掉 `effectiveDate` 参数被忽略的问题（此前 join_date 一律取当天，现在按生效日期入库，留空才取当天）。

## 2. 任教关系列表「学科 / 任教教师 / 班级」为空

- 现象：`GET /edu/teacher/assignment/list` 返回 `subjectName / teacherName / className / termName / schoolName`
  全为 null，页面三列空白。
- 根因：`EduTeacherServiceImpl.queryAssignmentPageList` 只做分页查询，没有回填名称（mapper 是 selectVoPage）。
- 修复：新增 `fillAssignmentNames`，按 id 集合批量取学科 / 教师 / 班级 / 学年学期 / 学校名称，并计算
  `crossSchool`（任教学校 ≠ 教师所属学校）。写法与 `EduClassServiceImpl.fillNames` 一致，外键为空时不查 Map。

## 3. 教师列表「所属学校 / 教育角色 / 任教学科 / 任课班级数」为空

- 现象：教师列表这四列显示 空 /「未分配」/「—」/ 空，抽屉「任职信息」同样为空。
- 根因：`EduTeacherServiceImpl.queryPageList` 未回填派生字段（VO 里有字段但无人赋值）。
- 修复：新增 `fillListFields`（列表与 `queryById` 共用）：学校名、教育角色（`edu_user_role` 生效记录 → 中文，
  口径与 `TeacherExportHandler` 一致）、任教学科（`edu_teaching_assignment` + `edu_subject`）、任课班级数（去重班级数）。

## 4. 学生列表「学段 / 年级 / 班级 / 学籍状态」为空

- 现象：学生列表这四列为空（带不带 termId 都一样），详情抽屉同样。
- 根因：`EduStudentServiceImpl.queryPageList` 未回填；学生是平台级实体，这四列必须经
  「在校记录 + 班级关系」两段式取数（AGENTS 第 7 节），此前完全没有实现。
- 修复：新增 `fillListFields`（列表与 `queryById` 共用）：在校记录取学籍状态，
  `edu_class_member`(status='1') → `edu_class` → `edu_grade` 取班级 / 年级 / 学段。
