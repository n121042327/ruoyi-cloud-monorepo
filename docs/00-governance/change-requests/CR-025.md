# CR-025 — 班级、教师表格与编辑表单字段布局

用户于 2026-10-01 要求继续建议的班级、教师两页批次，按 `docs/00-governance/page-field-layout.md` 整理表格与编辑表单。继续授权不记为人工验收通过。

## 变更

- 班级表格教育信息：校区 → 年级 → 班级名称 → 类型 → 班主任 → 教室；管理信息：容量 → 在读人数 → 状态；操作列最右独立。页面学校和学期上下文在查询区，未重复补造新列。
- 班级共用新建 / 编辑表单：教育信息按校区 → 学年学期 → 年级 → 班级名称 → 类型 → 班主任 → 教室排列；容量独立归管理信息。名称冲突紧跟名称，校验与保存结果保持原控件与行为，提交操作仍在独立页脚。
- 教师表格现有列序已与业务分组相符，保留顺序，补基础信息、教育信息、职业信息、联系方式标识。选择列和操作列独立。
- 教师编辑表单：基础信息（工号、姓名、性别）、教育信息（所属学校、教育角色）、职业信息（入职日期、在职状态）、联系方式（手机、邮箱）、补充信息（备注）。只读属性、角色限制、状态变更入口保持原规则。
- 每个表格数据单元格登记字段名，脚本按字段名读取，替代班级、教师行的数字列索引。班级名称链接样式改为字段选择器。列配置和导出仍是原型演示入口，未实现真实配置持久化或导出接口，不声称这些生产能力已验证。
- 冻结 v1 保留；修改已有 v2 页及新增变更单。工具 `tools/align_table_form_layout.py` 只整理四个 v2 文件，检测标记避免重复处理，无额外依赖。

## 验证与验收

新增 `verify-table-form-layout.html` 验证两页两层的字段分组、表格顺序、班级编辑对象 / 班主任 / 容量 / 教室、教师既有苏睿样例的编辑对象。教师非完整详情样例行的编辑数据绑定不在本批修复，不能从该样例推断所有教师编辑均已完整实现。

既有班级列表、弹窗回归复制为 `verify-class-layout-list.html`、`verify-class-layout-dialogs.html`：数字列位置改为字段选择器，CL-04 按用户新布局裁决调整预期列序，其余交互预期保留。教师载体、详情及两页上下文回归同步运行。最终计数见 `evidence/stage2-prototype-v2/2026-10-01_table-form-batch-verification.log`。

最终 171 项通过：新布局 30、班级列表 39、弹窗 36、教师载体 14、详情 6、两页上下文两层 46。独立审查无阻断项，表格与表单四张 1440 × 900 截图已查看。旧列序验证器及其历史通过结论不作为当前版本证据。

人工验收：班级确认校区、年级、班级在前；打开编辑高一 (1) 班，确认名称、班主任、校区、教室与原行一致。教师编辑苏睿，检查各组字段及只读形态。两页操作列最右。人工验收待确认，后端权限与接口未执行。

## 边界

本批未整理所有详情、批量生成、复制、任教关系等其他浮层；未补齐全量级联、需求追踪或组件映射。下一批建议年级、学生表格与编辑表单，验收后另行执行。未提交、推送或合并。
