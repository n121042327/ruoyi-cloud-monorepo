## 口径（与 PRD / BR 对齐）

- 年级与学段固定映射：学段与学段内序号必填，且**一经创建不可修改**（`REQ-GRD-018` / `RV-GRD-03`）——`updateByBo` 显式只允许改名。
- 年级**不允许跨学段改名**（`BR-GRADE-006`）：改写请求里带了不同学段直接拒绝。
- 有班级或学生关系时**不允许删除、只允许归档**（`BR-GRADE-004`）：`removeGrade` 先查该年级下是否还有班级，归档原因至少 5 个字。
- 升班的唯一执行入口是升班模块，年级管理只提供「学段内序号 +1」的**只读视图**（`REQ-GRD-032` / AGENTS 第 7 节模块边界）——`promotionView` 只查不写。
- 年级主任任职是 DS-05 的权威来源：同一学年学期同一人只允许一条任职（唯一键 `uk_grade_leader = term_id + grade_id + user_id`），重复保存时复用原记录；离任置 `status=0`，不物理删除。
- 数据范围：查询条件在服务层拼进 wrapper，不先取数再判断（`DS-DENY-07`）。
