## 1. 交付

`job/ClassRosterImportHandler`（模块编码 `class_roster`），复用 `fe527fc` 的导入框架。

| 项 | 说明 |
|---|---|
| 模板列 | 学号 / 姓名 / 目标班级 / 班级类型 —— 来源是编班表导入页的模板说明与 `REQ-CLS-035`（一行一个学生、含目标班级列） |
| 学号 | 必须存在，且必须在本校在校记录中（学生主体平台级 → 经在校记录两段式取数） |

| 目标班级 | 必须存在于本校 + 该学年学期，且班级类型匹配 |
| 班级类型 | 中文 / 码值都接受，空值默认行政班，其他值报错 |

## 2. 模块边界

编班表导入**只写班级关系，不创建学生主体**。学生建档的唯一入口是学生模块的新增 / 学生导入
（`DP-01`：学生班级归属的唯一写入入口是班级管理）。若这里顺带建学生，同一个学生会有两条建档路径，
出现重号或档案不一致时无法判断是谁写的。
