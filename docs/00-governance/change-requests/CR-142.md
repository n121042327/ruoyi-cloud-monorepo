## 2. 两个判断

1. **跨校教师拒绝导入**：模板里有「所属学校」列，但校验要求它等于当前导入的学校，否则拒绝并提示
   「跨校教师请在目标学校账号下导入」。依据是 `BR-TEACHER-001`（跨校任教不复制教师记录，
   由 `edu_teaching_assignment` 与 `edu_user_role` 表达）。若这里放行，同一个教师会在两个学校各存一行，
   后续任教关系与角色就分不清挂在谁身上。
2. **教育角色同时接受码值与中文**：页面上展示的是中文（校领导 / 教务主任 / …），接口与库里是下划线码值；
   导入模板由人填写，两种写法都可能出现，因此校验时两种都接受，入库前由执行阶段统一归一化。
