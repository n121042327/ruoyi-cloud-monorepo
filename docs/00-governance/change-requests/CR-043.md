# CR-043 — 补齐激活码与教师账号 / 任教关系复制接口（GAP-082 / GAP-083）

按两条缺项的推荐 A 补契约。两处都已有需求与验收用例，缺的只是第 8 节的 operationId。

## 一、学生激活码四项（GAP-082）

学生 PRD 升 **1.0.7**，第 8 节新增 4 个 operationId：

| operationId | 方法 | 路径 | 对应需求 |
|---|---|---|---|
| `getStudentActivationCode` | GET | `/edu/student/{id}/activation-code` | `REQ-STU-087` 查看激活码，默认掩码，`reveal=true` 揭示明文并逐条写审计 |
| `printStudentActivationSlip` | POST | `/edu/student/activation-slip/print` | `REQ-STU-088` 批量打印密码条（姓名 / 学号 / 登录名 / 激活码） |
| `exportStudentActivationCode` | POST | `/edu/student/activation-code/export` | `REQ-STU-089` 导出未激活学生加密清单，写审计并记录行数 |
| `activateStudentAccount` | POST | `/edu/student/{id}/activate` | `REQ-STU-092` 班主任代激活并设置密码，写审计 |

数据落点已有 `edu_activation_code`；查看与导出按敏感字段口径写 `edu_audit_log`，导出文件引用落 `edu_file_ref`。

## 二、教师账号启用与任教关系复制（GAP-083）

教师 PRD 升 **1.0.6-draft**，第 8 节新增 2 个 operationId：

| operationId | 方法 | 路径 | 对应需求 |
|---|---|---|---|
| `enableTeacherAccount` | POST | `/edu/teacher/{id}/account/enable` | `REQ-TCH-047` 启用账号，与停用对称，写审计 |
| `copyTeachingAssignment` | POST | `/edu/teacher/assignment/copy` | `REQ-TCH-070` 复制上一学年任教关系，预览 + 冲突清单 + 异步执行 |

`copyTeachingAssignment` 按异步接口登记（沿用 `executeImport` / `executePromotionTask` 的写法，返回 `task_no`），
已加入 `tools/extract_api_catalog.py` 的 `ASYNC_HINTS`。
