## 2. 发现的问题：两个权限点漏登记菜单种子

| 权限点 | 用在哪 | 后果 |
|---|---|---|
| `org.class:remove` | 班级列表「更多▾ → 删除班级」 | 除 super_admin 外任何角色都拿不到 → 按钮永远不显示，且不报错 |
| `person.student_guardian:update` | 学生详情监护人编辑 | 同上 |

两者都已在 `05-permission-matrix.yaml` 定义，属实现漏种子。处置：

- `edu-menu.sql` 补两行按钮权限（13164 parent 13023 班级管理；13165 parent 13020 学生管理）；
- 新增门禁 `tools/check_perm_seed.py`：比对前端 `v-hasPermi`/`checkPermi` 与后端 `@SaCheckPermission`
  用到的权限点是否都出现在菜单种子里，缺失即失败。

## 3. 生效方式

重跑 `edu-menu.sql`（幂等）并在「角色管理」里给角色勾选新按钮权限 —— super_admin 无需授权，
因此这个问题在开发机上「看起来正常」，只有换成教务主任账号才会暴露。
