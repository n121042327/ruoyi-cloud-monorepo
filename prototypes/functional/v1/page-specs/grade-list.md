## 1. 页面目的

教务主任与租户管理员在这里维护"这所学校有哪些年级、每个年级谁负责"：
新建或按学段批量生成年级、修改年级名称、指定年级主任、归档不再使用的年级、
删除建错且尚未编班的空年级。年级主任、班主任、任课教师与校领导进入本页时是只读形态，
分别按 `DS-05` / `DS-06` / `DS-07` / `DS-04` 收窄数据范围。

年级是数据范围的第四层：如果年级建错或年级主任漏配，
该年级的班主任与任课教师数据范围解析不出来，整年级数据不可见，因此本页需要把"未指定年级主任"显式标出来。

## 5. 状态清单

本页用左下角演示面板的「页面状态」真实切换，七类形态都有可见片段（`GL-22` 实测）。

| 状态 | `data-state` | 表现 | 主动作 |
|---|---|---|---|
| 加载中 | `loading` | 表格区域内骨架（5 段），不使用全屏遮罩 | — |
| 空数据 | `empty` | 两个芯片分别演示「筛选无结果」与「本校还没有建年级」 | 清空筛选条件 / 按学段批量生成 |
| 查询失败 | `error` | 错误说明 + 请求编号 `REQ-20260930-000311` + 错误码 `DS-5001` | 重试 |
| 无权限 | `forbidden` | 说明数据范围为空集，并写明不会降级为全量（`DS-DENY-03`） | 返回入口 |
| 提交中 | `submitting` | 顶部提示条 + 写操作按钮置 loading 并禁用 | — |
| 部分失败 | `partial` | 按学段批量生成的部分冲突表格（3 条中 2 成功 1 冲突） | 下载失败明细（批次 2-9） |
| 排队中 | `queued` | 任务编号 + 队列位置 + 并发配额（`BR-IMP-015`） | 查看任务中心（批次 2-9） |

## 6. 跳转关系

| 触发 | 目标 | 打开方式 | 返回行为 |
|---|---|---|---|
| 点击数据行 | `PAGE-GRD-DETAIL` 年级详情 | 抽屉 | 关闭后回到列表，保留筛选与页码 |
| 点击班级数 | `PAGE-CLS-LIST` 班级管理 | 跳页（批次 2-3） | 带入年级筛选，返回保留年级上下文 |
| 新增 / 编辑 | `PAGE-GRD-CREATE` 年级表单 | 弹窗（md，本批已交付） | 保存成功后刷新列表 |
| 按学段批量生成 | `PAGE-GRD-BATCH` | 弹窗（md，本批已交付） | 生成后刷新列表并列出冲突 |
| 指定年级主任 | `PAGE-GRD-LEADER` | 弹窗（md，本批已交付） | 保存后刷新「年级主任」列 |
| 归档 | `PAGE-GRD-ARCHIVE` | 弹窗（sm，本批已交付） | 归档后行内不再出现写操作 |
| 删除 | `DIALOG-GRD-DELETE` | 同页浮层片段（本批已交付） | 成功后刷新列表 |

## 7. 权限与数据范围

| 角色 | 可见内容 | 可见按钮 | 字段级限制 |
|---|---|---|---|
| 教务主任 | 本校全部年级（`DS-04`） | 新增、按学段批量生成、导出；行内编辑 / 指定年级主任 / 归档；空年级行可删除 | 全部可见 |
| 租户管理员 | 本租户组织配置（`DS-02`） | 新增、按学段批量生成；行内编辑 / 指定年级主任 / 归档；空年级行可删除 | 无 `data.export` 授权，因此看不到导出 |
| 校领导 | 本校全部年级（`DS-04`） | 只有导出 | 全列只读（`GAP-034` 裁决 B） |
| 年级主任 | 本人负责的年级（`DS-05`） | 只有导出 | 操作列显示「只读」 |
| 班主任 | 本班所属年级（`DS-06`） | 无 | 操作列显示「只读」 |
| 任课教师 | 任教班级所属年级的年级摘要（`DS-07`） | 无 | 操作列显示「只读」 |
| 平台运营 | 全平台（`DS-01`），默认只读 | 只有「导出（需授权）」 | 切换他校时顶部出现协助视图提示 |
| 超级管理员 | 全平台，不受范围限制（`BR-ORG-014` / `DP-07`） | 全部按钮与全部行内操作 | 无字段级限制；顶部有专用提示，操作强制留痕 |

## 8. 样例数据

取自 `content-samples.json` 的 `grades`（14 条）与 `list_totals.grade_list_total`（18）。
本页选择这些样本的理由：

| 样本 | 用途 |
|---|---|
| 202601 / 202501 / 202401（高中一 / 二 / 三） | 与 `classes`、`students` 的样例严格一致，用于验证"班级数 / 在读学生数"与班级模块口径一致 |
| 202611 ~ 202116（小学一 ~ 六年级） | 补齐小学学段，让列表能同时看到三个学段；`202116` 班级数与学生数都是 0，是**空年级**，用来演示删除入口 |
| 202621 / 202522 / 202423（初中一 / 二 / 三） | `202423` 是毕业年级（序号取到最大值）；`202522` 有班级有学生但**没有年级主任**，用来演示"未指定"与数据范围解析失败的后果 |
| 202223（2022 级 初中三年级，已归档） | 终态样本：行内没有任何写操作，「状态」列用 `el-tag.info`，历史统计仍显示 |
| 202602（云溪外国语学校 初一） | 跨校样本：默认筛选看不到，平台运营切到他校时才会出现 |
| 年级主任 阿依努尔·艾山 | 间隔号姓名样本，验证不截断、不换行 |
