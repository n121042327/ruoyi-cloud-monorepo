# 年级详情（抽屉）

| 项 | 值 |
|---|---|
| 页面编号 | `PAGE-GRD-DETAIL`（取自 `navigation.yaml`，`container: drawer` + `size: lg`） |
| 所属模块 | 年级管理（`grade`） |
| 页面类型 | detail（挂在 `PAGE-GRD-LIST` 的浮层片段） |
| 骨架模板 | `TPL-DETAIL` |
| 所属批次 | 2-2（2-2b-2b） |
| 上游需求 | `REQ-GRD-007` ~ `REQ-GRD-010`、`REQ-GRD-021` ~ `REQ-GRD-027`、`REQ-GRD-035` |
| 上游规则 | `BR-GRADE-005`、`DP-01`、`DP-06`、`DS-DENY-07`、`DS-DENY-08` |
| 权限资源 | `org.grade` 的 `read` / `update`；`org.class` 的 `read`；`person.student` 的 `read`；`audit.log` 的 `read` |
| 数据范围 | `DS-04`（校领导 / 教务主任）、`DS-05`（年级主任）、`DS-02`（租户管理员）；超级管理员按 `DP-07` 放行 |
| 原型文件 | `pages/grade-list.html` 的 `data-demo-panel="PAGE-GRD-DETAIL"` |

## 1. 页面目的

教务主任从列表点任意行进入，确认这个年级的**归属、下辖班级、在读人数、年级主任任职历史与变更记录**，
判断"数据范围是否解析得出来"。年级主任与校领导也能看，但只看得到范围内数据且没有写入口。

## 2. 页面结构（5 个分区，抽屉内可滚动）

| 顺序 | 区块 | `data-block` | 组件 | 说明 |
|---|---|---|---|---|
| 0 | 抽屉头 | — | `el-drawer` header | 年级名称 + 状态标签 + 学段内序号 |
| 1 | 基本信息 | `section` | `el-descriptions` | 名称 / 学段 / 入学年份 / 学段内序号 / 所属学校 / 状态 + 命名规则说明 |
| 2 | 下辖班级 | `section` | `el-table` | 班级名称 / 班主任 / 容量 / 在读 / 教室 / 状态；空态给"去班级管理新建" |
| 3 | 在读学生统计 | `section` | `el-table` | 按班级分行 + 合计行；空态说明"空集不降级为全量" |
| 4 | 年级主任任职历史 | `section` | `el-table` | 学年学期 / 姓名 / 是否主要负责人 / 状态 / 任职期间；含历史只读行 |
| 5 | 变更记录 | `section` | `el-timeline` | 时间线，含操作人与来源 IP |

## 3. 字段清单

| 字段名 | 中文 | 组件 | 必填 | 可编辑角色 | 说明 |
|---|---|---|---|---|---|
| `grade_name` | 年级名称 | 文本 | — | — | 只读；编辑走 `PAGE-GRD-CREATE` |
| `stage_code` | 学段 | 文本（标签映射） | — | — | 小学 / 初中 / 高中，不可配置 |
| `enroll_year` | 入学年份 | 文本 | — | — | 4 位年份 |
| `grade_level` | 学段内序号 | 文本 | — | — | 抽屉头与基本信息两处都显示 |
| `school_id` | 所属学校 | 文本 | — | — | 学校用户只看到本校 |
| `grade_status` | 状态 | `el-tag` | — | — | 在读 / 已归档 |
| `class_name` / `head_teacher_id` / `class_capacity` / `student_count` | 下辖班级 | `el-table` | — | — | 只读；点击班级名称跳班级详情（批次 2-3） |
| `leader_user_id` / `is_primary` / `leader_status` / `effective_date` / `expire_date` / `term_id` | 年级主任任职 | `el-table` | — | — | 历史只读；新增走 `PAGE-GRD-LEADER` |

## 4. 动作清单

| 动作编号 | 元素 | 触发 | 可用条件 | 结果 |
|---|---|---|---|---|
| `ACT-GRD-009` | 点击数据行 | 单击行 | `org.grade:read` | 打开本抽屉 |
| `ACT-GRD-012` | 编辑 | 点击 | `org.grade:update` 且未归档 | 打开 `PAGE-GRD-CREATE` 编辑态 |
| `ACT-GRD-013` | 指定年级主任 | 点击 | `org.grade:update` | 打开 `PAGE-GRD-LEADER` |
| `ACT-GRD-014` | 查看全部班级 | 点击 | `org.class:read` | 跳班级管理并带入年级筛选（批次 2-3） |
| `ACT-GRD-015` | 关闭 | 点击 / Esc | 始终可用 | 关闭抽屉，回到列表并保留筛选与页码 |

## 5. 状态清单

| 状态 | 表现 |
|---|---|
| 加载中 | 分区骨架；沿用列表页的 `loading` 状态 |
| 空数据 | **两个形态**：样本 A（有数据）与样本 B（空年级）—— 下辖班级、学生统计、任职历史三个分区同时给空态文案 |
| 查询失败 | 沿用列表页 `error` 片段；抽屉不打开 |
| 无权限 | 行本身不可见（范围过滤在查询里完成，`DS-DENY-07`） |
| 提交中 | 本抽屉只读，无提交动作 |

## 6. 跳转关系

| 触发 | 目标 | 打开方式 | 返回行为 |
|---|---|---|---|
| 列表点行 | 本抽屉 | 抽屉（lg，800px） | 关闭后回到列表，筛选与页码保留 |
| 编辑 | `PAGE-GRD-CREATE` | 弹窗（md） | 保存后列表刷新，抽屉保留当前年级 |
| 指定年级主任 | `PAGE-GRD-LEADER` | 弹窗（md） | 保存后"年级主任任职历史"分区刷新 |
| 查看全部班级 | `PAGE-CLS-LIST` | 跳页（批次 2-3） | 带入年级筛选 |

## 7. 权限与数据范围

| 角色 | 可见内容 | 可见按钮 |
|---|---|---|
| 教务主任 / 租户管理员 | 本校全部年级 | 编辑、指定年级主任、查看全部班级 |
| 校领导 | 本校全部年级 | 查看全部班级（只读） |
| 年级主任 | 只有本人负责的年级 | 查看全部班级 |
| 班主任 / 任课教师 | 只有本班 / 任教班级所属年级的摘要 | 无 |
| 平台运营 | 全平台（切他校时有协助视图提示） | 无 |
| 超级管理员 | 全平台不受限 | 全部（强制留痕） |
