# 批量生成班级（弹窗）

| 项 | 值 |
|---|---|
| 页面编号 | `PAGE-CLS-BATCH`（取自 `navigation.yaml`，`type: dialog` + `size: md`） |
| 所属模块 | 班级管理（`class`） |
| 页面类型 | dialog（挂在 `PAGE-CLS-LIST` 的浮层片段） |
| 骨架模板 | `TPL-OVERLAY` |
| 所属批次 | 2-3（2-3c） |
| 上游需求 | `REQ-CLS-020`、`REQ-CLS-002`、`REQ-CLS-007` |
| 上游规则 | `BR-CLASS-002`、`BR-CLASS-003`、`BR-CLASS-005`、`REQ-TERM-030` |
| 权限资源 | `org.class` 的 `create` |
| 数据范围 | `DS-04`（教务主任）；超级管理员按 `DP-07` 放行 |
| 原型文件 | `pages/class-list.html` 的 `data-demo-panel="PAGE-CLS-BATCH"` |

## 1. 页面目的

按年级一次性生成区间内的多个班级（如高一 1–6 班），逐个校验名称唯一；
已存在的名称**跳过并在预览里标出**，不覆盖、不改名（`REQ-CLS-020`）。

## 2. 页面结构

| 顺序 | 区块 | 组件 | 说明 |
|---|---|---|---|
| 1 | 弹窗头 | `el-dialog` header | 标题 + 学校名 + 「按年级一次生成多个班级」 |
| 2 | 生成规则提示 | `el-alert.info` | 写明命名规则与唯一性口径 |
| 3 | 表单 | `el-form` | 学年学期 / 年级 / 序号区间 / 容量 / 校区 |
| 4 | 生成预览 | 列表（**不是表格**） | 每行：班级名称 + 「将生成 / 已存在，跳过」 |
| 5 | 冲突提示 | `el-alert.warning` | 写明跳过数量与「不覆盖、不改名」 |
| 6 | 校验汇总 | `el-alert.danger` | 区间或必填不合法时展开 |
| 7 | 底部操作条 | footer | 取消 / 确认生成 |

## 3. 字段清单

| 字段名 | 中文 | 组件 | 必填 | 说明 |
|---|---|---|---|---|
| `term_id` | 学年学期 | `el-select` | 是 | 只列未归档学年学期（`REQ-TERM-030`） |
| `grade_id` | 年级 | `el-select` | 是 | 已归档年级不出现在选项中 |
| `class_seq_range` | 序号区间 | `el-input-number` ×2 | 是 | 起始 ≥ 1 且不大于结束；序号只用于生成名称 |
| `class_capacity` | 容量 | `el-input-number` | 否 | 统一预填，建班后可逐班调整；不强制校验（`BR-CLASS-005`） |
| `campus_id` | 校区 | `el-select` | 否 | 教室不批量生成，建班后逐班设置 |

## 4. 动作清单

| 动作编号 | 元素 | 触发 | 可用条件 | 结果 |
|---|---|---|---|---|
| `ACT-CLS-002` | 列表工具条「批量生成」 | 点击 | `org.class:create` | 打开本弹窗并渲染默认预览 |
| `ACT-CLS-037` | 年级 / 序号区间 / 容量 / 校区 | 选择或输入 | 同新建 | 实时重算预览与冲突标记 |
| `ACT-CLS-038` | 取消 / 关闭 | 点击或 Esc | 始终可用 | 关闭弹窗，不生成 |
| `ACT-CLS-039` | 确认生成 | 点击 | 学期与年级已选，且起始序号 ≤ 结束序号 | 调 `batchAddClass`，冲突项跳过并列入结果，写审计 |

## 5. 状态清单

| 状态 | 表现 |
|---|---|
| 默认预览 | 高一 序号 1–6 → 6 行，其中 1–3 班标「已存在，跳过」（`CDL-16` 实测） |
| 冲突提示 | 写明「本次将跳过 3 个」，并声明不覆盖、不改名（`CDL-17` 实测） |
| 区间不合法 | 起 5 止 3 时字段级错误 + 汇总，提交被拦（`CDL-18` 实测） |
| 大区间 | 序号 1–100 时预览只展开前 30 行并追加说明行（`CDL-19` 实测） |
| 不可编辑角色 | 非 `data-role-editable` 名单内的角色字段全禁用，确认按钮不渲染 |

## 6. 跳转关系

| 触发 | 目标 | 打开方式 | 返回行为 |
|---|---|---|---|
| 生成成功 | `PAGE-CLS-LIST` | 关闭弹窗 | 列表刷新，新增班级出现在当前筛选下 |
| 生成量大 | 异步任务中心（批次 2-9） | — | 接口若返回任务编号，弹窗提示内给出入口 |

## 7. 权限与数据范围

| 角色 | 入口 | 字段 |
|---|---|---|
| 教务主任 | 可见可操作 | 全部 |
| 年级主任 | **无入口**（与 `ACT-CLS-002` 的权限登记一致，批量写入不放给年级主任） | — |
| 校领导 / 班主任 / 任课教师 / 租户管理员 / 平台运营 | 无入口 | — |
| 超级管理员 | 全部可见 | 全部可写，强制留痕 |

## 8. 样例数据

默认学年学期 `202601`、年级 `2026 级 高一`、序号 1–6、容量 45、校区本部校区。
高一本学年学期已有 1–3 班，因此预览里 3 行冲突、3 行将生成。

## 9. 自查

- [x] 弹窗内不含表格，生成预览用列表渲染
- [x] `data-action-id` 全部登记（`ACT-CLS-002` / `037` ~ `039`）
- [x] 冲突口径与 `BR-CLASS-003` 一致（同校 + 同学年学期 + 同学段）

> 原型假设（不是业务规则，需在阶段 4 接口清单定稿时确认）：预览只展开前 30 行属于**渲染保护**，
> 提交时按真实区间处理；PRD 未规定单次生成的上限，因此本页不设上限、也不在界面上编造上限。
