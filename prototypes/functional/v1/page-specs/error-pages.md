# 异常页（403 / 404 / 500）

| 项 | 值 |
|---|---|
| 页面编号 | `PAGE-403`（`pages/403.html`）/ `PAGE-404`（`pages/404.html`）/ `PAGE-500`（`pages/500.html`） |
| 所属模块 | 公共（`common`） |
| 页面类型 | standalone（**不套管理外壳**） |
| 所属批次 | 2-4 |
| 上游依据 | `DS-DENY-03`（无权限不降级为全量）、`NFR-SEC-05`、`NFR-MQ-02`（异步失败整批记录）、`NFR-AUDIT-02`、`navigation.yaml` 的页面注册表 |
| 交付证据 | `evidence/stage2-prototype/verify-import-login.html`、`error-403_1440x900.png` / `error-404_1440x900.png` / `error-500_1440x900.png` |

## 1. 页面目的

三个异常页各自回答一个问题：**为什么没权限**（403，且明确不降级为全量）、**地址为什么不对**（404，指向页面注册表）、
**这次操作有没有产生部分写入**（500，说明批量写走异步任务、不产生部分写入）。

## 2. 页面结构

| 页面 | 结构 | 主动作 |
|---|---|---|
| 403 | 错误码 + 标题 + 说明（功能权限 / 数据范围为空集的区别）+ 元信息 | 返回工作台、申请开通权限 |
| 404 | 错误码 + 标题 + 说明（以 `navigation.yaml` 的页面注册表为准）+ 元信息 | 返回上一页、返回工作台 |
| 500 | 错误码 + 标题 + 说明（不产生部分写入）+ 请求编号与错误码 + 已自动上报 | 重试、去异步任务中心、返回工作台 |

## 3. 字段清单

无表单字段；500 页展示 `request_id`（`REQ-20261001-000701`）与错误码（`EDU-SYS-5001`）。

## 4. 动作清单

| 动作编号 | 元素 | 页面 | 结果 |
|---|---|---|---|
| `ACT-ERR-001` | 返回工作台 | 403 / 404 / 500 | 回到登录后的工作台首页（原型给轻提示） |
| `ACT-ERR-002` | 申请开通权限 | 403 | 提示联系管理员开通；缺少权限的访问同样写审计（`NFR-AUDIT-02`） |
| `ACT-ERR-003` | 返回上一页 | 404 | 返回来源页面 |
| `ACT-ERR-004` | 重试 | 500 | 重发上一个请求；批量写操作走异步任务（`NFR-MQ-02`） |
| `ACT-ERR-005` | 去异步任务中心 | 500 | 进入 `PAGE-IMP-TASK-LIST`（批次 2-9） |

## 5. 状态清单

三个页面都是**静态终态页**：没有加载中 / 空数据形态，页面本身就是「错误态」；按钮点击给轻提示（原型约定）。

## 6. 跳转关系

`ACT-ERR-005` → `PAGE-IMP-TASK-LIST`（批次 2-9，本批给批次提示）；其余动作在原型里只给轻提示，不真跳转。

## 7. 权限与数据范围

异常页本身不展示业务数据；403 页明确「无权限时不渲染空表格，接口层同样拒绝」（`DS-DENY-03` / `NFR-SEC-05`）。

## 8. 样例数据

无业务样例；500 页的请求编号与错误码为固定样例值。

## 9. 自查
