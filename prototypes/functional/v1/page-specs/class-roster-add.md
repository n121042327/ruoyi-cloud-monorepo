# 编班（添加学生）独立页

| 项 | 值 |
|---|---|
| 页面编号 | `PAGE-CLS-ROSTER-ADD`（取自 `navigation.yaml`，`type: page` + `route: /edu/class/roster/add`） |
| 所属模块 | 班级管理（`class`） |
| 页面类型 | page（独立页，**不是抽屉**） |
| 骨架模板 | `TPL-LIST` 的双栏变体（左学生池 + 右待加入清单） |
| 所属批次 | 2-3（2-3d） |
| 上游需求 | `REQ-CLS-027` ~ `REQ-CLS-029`、`REQ-CLS-012`、`REQ-CLS-032` |
| 上游规则 | `BR-STU-003`、`BR-STU-012`、`BR-STU-023`、`BR-CLASS-005`、`BR-PROMO-007`、`DS-DENY-06`、`DP-01` |
| 权限资源 | `org.class` 的 `update`（写入）；`person.student` 的 `read`（读学生池） |
| 数据范围 | `DS-03`（年级主任，限本人负责年级）/ `DS-04`（教务主任）；超级管理员按 `DP-07` 放行 |
| 原型文件 | `prototypes/functional/v1/pages/class-roster-add.html` |

## 1. 页面目的

从**本校学生池**按姓名 / 学号检索并勾选学生，批量加入目标班级；加入前逐条校验唯一行政班，
**任一条冲突则整体拒绝并列出冲突清单**，每个冲突学生给出「调班」入口（`REQ-CLS-028` / `029`）。

**载体决策**：`CR-009` / `D-059` 已把「添加学生」由抽屉改为**独立页**——它含可检索列表（等价含表格），
抽屉装不下；双栏形态来自 class PRD 6.1 的原文「左学生池 + 右待加入」。

## 2. 页面结构

| 顺序 | 区块 | 组件 | 说明 |
|---|---|---|---|
| 1 | 页头 | `el-page-header` 形态 | 返回班级详情 + 目标班级 + 类型 / 学期 / 容量标签 + 数据范围提示 |
| 2 | 编班规则提示 | `el-alert.info` | 唯一行政班、整体拒绝、容量不拦截 |
| 3 | 左栏 · 本校学生池 | `el-card` + `el-table` | 姓名 / 学号检索、「只看可加入」视图、7 列（勾选 / 学号 / 姓名 / 性别 / 学籍状态 / 当前行政班 / 加入校验） |
| 4 | 右栏 · 待加入清单 | `el-card` + 列表 | 已选人数、逐行移除、冲突标记 + 「调班」入口；清单为空时给空态 |
| 5 | 冲突清单 | `el-alert.danger` + 列表 | 整体拒绝时展开，按学生列出原因与「调班」入口 |
| 6 | 加入结果 | `el-alert.success` | 成功后写明加入人数与在读人数变化 |
| 7 | 底部操作条 | footer | 取消 / 加入班级 |
| 8 | 状态块 | 7 类状态 | loading / empty / error / forbidden / submitting / partial |

## 3. 字段清单

| 字段名 | 中文 | 组件 | 必填 | 说明 |
|---|---|---|---|---|
| `keyword` | 姓名 / 学号 | `el-input` | 否 | 命中姓名或学号（`REQ-CLS-027`） |
| `pool_view` | 视图 | `el-radio-button` | 否 | 全部学生 / 只看可加入（纯视图收窄，不改变校验口径） |
| `student_no` / `student_name` / `gender` / `enrollment_status` | 学生基本信息 | 只读列 | — | 只取识别身份所必需的列 |
| `student_class_id` | 当前行政班 | 只读列 | — | 用 `el-tag` 标出；本班显示为 primary，他班为 info |
| `join_check` | 加入校验 | 只读列 | — | 可加入 / 已在本班 / 已有行政班 / 转入未报到 / 终态不能编班 |

## 4. 动作清单

| 动作编号 | 元素 | 触发 | 可用条件 | 结果 |
|---|---|---|---|---|
| `ACT-CLS-021` | 班级详情的「编班（添加学生）」 | 点击 | `org.class:update` | 进入本页并带 `class=<本班>` |
| `ACT-CLS-007` | 班级列表行内「更多」→「编班（添加学生）」 | 点击 | `org.class:update` | 同上，带该行班级名 |
| `ACT-CLS-053` | 检索 / 视图切换 / 搜索 / 重置 / 清空清单 | 输入或点击 | `person.student:read` | 收窄学生池；清空清单不写库 |
| `ACT-CLS-054` | 学生池勾选 / 取消勾选 | 勾选 | 非终态且不在本班 | 加入 / 移出待加入清单；勾选冲突学生时立即提示 |
| `ACT-CLS-055` | 待加入清单行内「移除」 | 点击 | 始终可用 | 从清单移除，不写库 |
| `ACT-CLS-056` | 冲突行「调班」 | 点击 | 该生已有行政班 | 跳到班级详情的调班弹窗，带 `student` / `from` / `to` 并预填 |
| `ACT-CLS-057` | 加入班级 | 点击 | 清单非空且逐条校验通过 | 任一条冲突则整体拒绝；全部通过则调 `addClassRoster` 并写审计 |
| `ACT-CLS-058` | 返回班级详情 / 取消 | 点击 | 始终可用 | 回到 `PAGE-CLS-DETAIL` |

## 5. 状态清单

| 状态 | 表现 |
|---|---|
| 默认 | 15 行样例：可加入 2 / 已在本班 4 / 已有行政班 6 / 转入未报到 1 / 终态 2（`RA-03` 实测） |
| 勾选可用性 | 已在本班与终态两类的复选框禁用（6 行），其余 9 行可勾选（`RA-04` 实测） |
| 「只看可加入」 | 只留 2 行（潘思彤、蒋知远）（`RA-05` 实测） |
| 冲突 | 清单标红 + 「调班」入口；点加入 → 冲突清单块 + 整体拒绝提示 + 清单不清空（`RA-08` / `RA-09` 实测） |
| 成功 | 出现「加入结果」块、待加入清单清空（`RA-11` 实测） |
| 终态学生 | 已转出 / 退学行禁用复选框，校验列写明「终态不能编班」 |
| 转入未报到 | 校验列写明「报到后才可编班（BR-STU-023）」，可勾选但提交时按冲突整体拒绝 |
| 历史学年学期 | 顶部只读提示条 + 全部复选框禁用 + 隐藏「加入班级」 |
| 不可编辑角色 | 校领导 / 班主任 / 任课教师 / 租户管理员 / 平台运营只读（`forbidden` 状态块给出替代路径说明） |

## 6. 跳转关系

| 触发 | 目标 | 打开方式 | 返回行为 |
|---|---|---|---|
| 保存成功 | `PAGE-CLS-DETAIL`（花名册页签） | 关闭本页 | 花名册与班级列表在读人数刷新 |
| 「返回班级详情」/ 取消 | `PAGE-CLS-DETAIL` | 同目录跳转 | 保留班级上下文 |
| 冲突行「调班」 | `pages/class-detail.html#panel=PAGE-CLS-TRANSFER&student=…&from=…&to=…` | 同目录跳转 + 自动打开弹窗 | 详见 `class-transfer.md` |

## 7. 权限与数据范围

| 角色 | 入口 | 字段 |
|---|---|---|
| 教务主任 | 可见可操作 | 全部 |
| 年级主任 | 可见可操作，且只能编入本人负责年级的班级 | 全部 |
