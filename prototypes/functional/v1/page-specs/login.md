# 登录

| 项 | 值 |
|---|---|
| 页面编号 | `PAGE-LOGIN`（`pages/login.html`） |
| 所属模块 | 公共（`common`） |
| 页面类型 | standalone（**不套管理外壳**，与真实登录页一致） |
| 所属批次 | 2-4 |
| 上游需求 | 见学生 / 教师 PRD 的账号章节与 `05-permission-matrix.yaml` 的角色定义 |
| 上游规则 | `BR-ACCOUNT-002`（学生登录名 = s + 学号）、`BR-ACCOUNT-004`、`D-039`（一次性激活码）、`NFR-SEC-04`（连续错误锁定）、`NFR-AUDIT-01`（登录写审计） |
| 权限资源 | 无（未登录） |
| 数据范围 | 登录后按角色解析；学校用户登录后学校不可切换，集团与运营方可在顶部切换 |
| 交付证据 | `evidence/stage2-prototype/verify-import-login.html`、`login_*.png` |

## 1. 页面目的

三类用户（学校 / 集团 / 运营方）用同一个入口登录：学生用 `s` + 学号、教师用工号、管理员用账号；
首次登录必须改密（一次性激活码，`D-039`）；连续 5 次密码错误锁定 5 分钟（`NFR-SEC-04`）。

## 2. 页面结构

| 顺序 | 区块 | 组件 | 说明 |
|---|---|---|---|
| 1 | 品牌区 | 文字 + 方块标记 | 平台名与「PC 端」说明 |
| 2 | 学校选择 | `el-select` | 多校账号可切换；学校用户登录后不可切换 |
| 3 | 登录名 | `el-input` | 占位符给出三类账号形态；学生示例 `s2026000001` |
| 4 | 密码 | `el-input.password` | 必填 |
| 5 | 记住登录名 / 忘记密码 | checkbox + link | 忘记密码首轮不做自助找回，给提示 |
| 6 | 提示区 | `el-alert` × 3 | 登录失败（含剩余次数）/ 账号锁定 / 首次登录改密 |
| 7 | 登录按钮 | `el-button.primary` | 提交中置 loading 并禁用 |
| 8 | 页脚说明 | 文本 | 三类账号的口径（学生 / 教师 / 运营方） |

## 3. 字段清单

| 字段名 | 中文 | 组件 | 必填 | 校验规则 | 备注 |
|---|---|---|---|---|---|
| `tenant_id` | 学校 | `el-select` | 否 | — | 多校账号可切换，写审计 |
| `login_name` | 登录名 | `el-input` | 是 | 非空 | 学生 `s` + 学号（`BR-ACCOUNT-002`） |
| `password` | 密码 | `el-input.password` | 是 | 非空；连续 5 次错误锁定 5 分钟 | 首登强制改密（`D-039`） |

## 4. 动作清单

| 动作编号 | 元素 | 可用条件 | 结果 | 接口 |
|---|---|---|---|---|
| `ACT-AUTH-001` | 登录 | 必填已填 | 校验账号密码并写审计；错误给剩余次数；达成 5 次锁定 | `login` |
| `ACT-AUTH-002` | 学校切换 | 多校账号 | 切换登录入口租户 / 学校 | — |
| `ACT-AUTH-003` | 忘记密码 | 始终可用 | 提示联系管理员重置（不做自助找回） | — |

## 5. 状态清单

| 状态 | 表现 |
|---|---|
| 正常 | 表单可填，按钮可用 |
| 校验失败 | 字段级红字（登录名 / 密码必填），不发请求 |
| 登录失败 | 错误提示条给出「账号或密码错误，还可尝试 N 次」 |
| 账号锁定 | 连续 5 次错误后显示锁定提示（5 分钟） |
| 首次登录 | 提示必须用一次性激活码换取初始凭据并立即改密 |
| 提交中 | 按钮 loading 并禁用 |

## 6. 跳转关系

登录成功后按角色进入工作台（教师 → 我的班级、教务主任 → 学生管理、平台运营 → 学校管理）；原型只给轻提示，不真跳转。

## 7. 权限与数据范围

未登录状态无任何业务数据；登录成功后才解析数据范围（`DS-01` ~ `DS-07`）。登录与失败都写审计（`NFR-AUDIT-01`）。

## 8. 样例数据

无业务样例；学校下拉取自 `org` 的学校样本（云溪实验学校 / 云溪外国语学校 / 集团 / 运营方）。
原型约定：密码输入 `wrong` 触发失败与锁定路径，其余任意密码走成功路径。
