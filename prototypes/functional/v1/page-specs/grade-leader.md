# 指定年级主任（弹窗）

| 项 | 值 |
|---|---|
| 页面编号 | `PAGE-GRD-LEADER`（取自 `navigation.yaml`，`type: dialog` + `size: md`） |
| 所属模块 | 年级管理（`grade`） |
| 页面类型 | dialog（挂在 `PAGE-GRD-LIST` 的浮层片段；与教师模块的教育角色分配是"同一张表两个入口"） |
| 骨架模板 | `TPL-OVERLAY` |
| 所属批次 | 2-2（2-2b-2b） |
| 上游需求 | `REQ-GRD-021` ~ `REQ-GRD-027`、`REQ-GRD-035`；`SCN-TEACHER-01` |
| 上游规则 | `BR-GRADE-004`、`DP-01`、`DP-02`、`DP-06` |
| 权限资源 | `org.grade` 的 `update`；`person.teacher` 的 `read` |
| 数据范围 | `DS-02` / `DS-04`；超级管理员按 `DP-07` 放行 |
| 原型文件 | `pages/grade-list.html` 的 `data-demo-panel="PAGE-GRD-LEADER"` |

## 1. 页面目的

给某个年级指定**一名或多名**年级主任，并标记一名主要负责人。任职必须绑定学年学期；
保存后立即失效相关用户的数据范围缓存，并写审计（原任职人 / 新任职人 / 生效日期）。

## 2. 页面结构

| 顺序 | 区块 | 组件 | 说明 |
|---|---|---|---|
| 1 | 弹窗头 | header | 标题 + 年级名 + "必须绑定学年学期" |
| 2 | 学年学期 | `el-select` | 当前学期 / 下学期 / 历史学期（历史学期只读） |
| 3 | 当前任职清单 | 列表（**不是表格**） | 每行：姓名 + 主要负责人标记 + 状态 + 任职期间 + 移除 |
| 4 | 添加年级主任 | 行内表单 | 教师下拉 + "设为主要负责人" + 生效日期 + 添加 |
| 5 | 保存前检查 | `el-alert.warning` | 四条检查（学期、在职、不重复、缓存失效与审计） |
| 6 | 底部操作条 | footer | 取消 / 保存 |

## 3. 字段清单

| 字段名 | 中文 | 组件 | 必填 | 说明 |
|---|---|---|---|---|
| `term_id` | 学年学期 | `el-select` | 是 | 唯一键的一部分；历史学期只读，不提供新增入口（`REQ-GRD-022`） |
| `leader_user_id` | 年级主任 | `el-select` | 是（添加时） | 只能选本校在职教师；跨校任教教师需按任教学校判定 |
| `is_primary` | 主要负责人 | `el-checkbox` | 否 | 同一学期同一年级只保留一名（`REQ-GRD-023`） |
| `effective_date` | 生效日期 | `el-date-picker` | 否 | 默认当前学年学期开始日 |
| `grade_status` / `leader_status` | 状态 | `el-tag` | — | 生效中 / 已解除 |

## 4. 动作清单

| 动作编号 | 元素 | 触发 | 可用条件 | 结果 |
|---|---|---|---|---|
| `ACT-GRD-005` / `ACT-GRD-013` | 列表行内 / 详情内「指定年级主任」 | 点击 | `org.grade:update` | 打开本弹窗并带入该年级 |
| `ACT-GRD-022` | 选择学年学期 | 选择 | 同上 | 切换任职清单；历史学期只读 |
| `ACT-GRD-023` | 填写待添加的年级主任 | 选择 / 勾选 / 选日期 | 当前不是历史学期 | 只加入待保存清单 |
| `ACT-GRD-024` | 添加 | 点击 | 已选教师且未重复 | 加入清单；重复时被拒绝（`GL-32` 实测） |
| `ACT-GRD-025` | 取消 | 点击 | 始终可用 | 关闭弹窗，不保存 |
| `ACT-GRD-026` | 保存 | 点击 | 学年学期已选 | 写入 `edu_grade_leader` + 写审计 + 失效数据范围缓存 |
| `ACT-GRD-027` | 移除 | 点击清单行内按钮 | `org.grade:update` | 只从待保存清单移除；点保存后才真正解除 |

## 5. 状态清单

| 状态 | 表现 |
|---|---|
| 空数据 | "当前学期还没有年级主任" + 说明未指定会导致该年级数据范围解析不出来 |
| 校验失败 | 未选学年学期时字段级错误 + 顶部汇总 |
| 重复任职 | 添加时即拒绝并提示 `REQ-GRD-024`（`GL-32` 实测） |
| 历史学期 | 学年学期下拉选到历史学期时，"添加"被拒绝并提示只读 |
| 提交中 | 保存按钮置 loading 并禁用 |

## 6. 跳转关系

| 触发 | 目标 | 打开方式 | 返回行为 |
|---|---|---|---|
| 保存成功 | 回到列表或详情 | 关闭弹窗 | 列表「年级主任」列与详情「任职历史」分区刷新 |

## 7. 权限与数据范围

| 角色 | 入口 | 字段 |
|---|---|---|
| 教务主任 / 租户管理员 | 可见可操作 | 全部 |
| 校领导 | 无入口（只读 + 审批口径，见 `GAP-034` 裁决 B） | — |
| 年级主任 / 班主任 / 任课教师 / 平台运营 | 无入口 | — |
| 超级管理员 | 全部可见 | 全部可写，强制留痕 |

## 8. 样例数据

默认带入被点击行的年级；任职清单来自 `content-samples.json` 的 `grade_detail_samples.A.leaders`
（何文博为现任主要负责人、冯振国为上学期已解除任职）。
教师下拉取自 `teachers`，含跨校任教（苏睿）与无教育角色样本。
