# 指定 / 变更班主任（弹窗）

| 项 | 值 |
|---|---|
| 页面编号 | `PAGE-CLS-LEADER`（取自 `navigation.yaml`，`type: dialog` + `size: md`） |
| 所属模块 | 班级管理（`class`） |
| 页面类型 | dialog（挂在 `PAGE-CLS-LIST` 的浮层片段；一窗两态：指定 / 变更） |
| 骨架模板 | `TPL-OVERLAY` |
| 所属批次 | 2-3（2-3c） |
| 上游需求 | `REQ-CLS-006`、`REQ-CLS-016`、`REQ-CLS-024`、`REQ-CLS-048` ~ `REQ-CLS-051` |
| 上游规则 | `BR-CLASS-004`、`BR-CLASS-007`、`BR-CLASS-008`、`DP-01` |
| 权限资源 | `org.class` 的 `update`；`person.teacher` 的 `read` |
| 数据范围 | `DS-03`（年级主任，限本人负责年级）/ `DS-04`（教务主任）；超级管理员按 `DP-07` 放行 |
| 原型文件 | `pages/class-list.html` 的 `data-demo-panel="PAGE-CLS-LEADER"` |

## 1. 页面目的

给一个行政班指定或变更班主任，任职必须绑定学年学期并记录生效日期；
保存后原班主任的任职自动结束（同一时间只允许一名在任），
并立即失效原班主任与新班主任的数据范围缓存，同时写审计。

**模块边界**：本弹窗是班主任字段的**唯一写入入口**（`DP-01` / `REQ-CLS-048`）。
教师模块只读并跳转，班级表单在编辑态把班主任置为只读。

## 2. 页面结构

| 顺序 | 区块 | 组件 | 说明 |
|---|---|---|---|
| 1 | 弹窗头 | `el-dialog` header | 标题（指定 / 变更班主任）+ 班级名 + 「必须绑定学年学期」 |
| 2 | 学年学期 | `el-select` | 当前 / 下学期 / 历史学期（历史学期只读） |
| 3 | 当前班主任 | 列表（**不是表格**） | 姓名 + 生效中标签 + 任职期间；未指定时给空态文案 |
| 4 | 新任班主任 | `el-select` | 只列本校在职教师 |
| 5 | 生效日期 | `el-date-picker` | 默认当前学年学期开始日 |
| 6 | 变更原因 | `el-input.textarea` | 选填，写入审计备注 |
| 7 | 任职历史 | 列表（**不是表格**） | 当前学期一行 + 「更早历史见班级详情」说明；带「查看全部任职历史」入口 |
| 8 | 保存前检查 | `el-alert.warning` | 四条检查：学期只读 / 本校在职 / 一名在任 / 缓存失效与审计 |
| 9 | 校验汇总 | `el-alert.danger` | 按需展开 |
| 10 | 底部操作条 | footer | 取消 / 保存 |

## 3. 字段清单

| 字段名 | 中文 | 组件 | 必填 | 说明 |
|---|---|---|---|---|
| `term_id` | 学年学期 | `el-select` | 是 | 唯一键的一部分；历史学期只读，不提供保存（`REQ-CLS-050`） |
| `head_teacher_id` | 新任班主任 | `el-select` | 是 | 只列本校在职教师；离职 / 调离 / 非本校教师列出但不可选 |
| `effective_date` | 生效日期 | `el-date-picker` | 是 | 原班主任的结束日取生效日前一天 |
| `remark` | 变更原因 | `el-input.textarea` | 否 | 写入审计备注；变更本身无论是否填写都写审计（`REQ-CLS-052`） |

## 4. 动作清单

| 动作编号 | 元素 | 触发 | 可用条件 | 结果 |
|---|---|---|---|---|
| `ACT-CLS-006` | 列表行内「指定班主任」 | 点击 | `org.class:update`，且不是教学班与已停用班级 | 打开本弹窗并带入当前班主任与任职历史 |
| `ACT-CLS-020` | 班级详情 →「指定班主任」 | 点击 | 同上，且不是历史学年学期 | 跨页深链接回列表页并打开本弹窗 |
| `ACT-CLS-044` | 学年学期 / 新任班主任 / 生效日期 | 选择或输入 | 同上 | 切换任职历史并校验候选人资格 |
| `ACT-CLS-045` | 取消 / 关闭 | 点击或 Esc | 始终可用 | 关闭弹窗，班主任不变更 |
| `ACT-CLS-046` | 保存 | 点击 | 三项必填齐全，且当前不是历史学期 | 调 `assignHeadTeacher`，写审计，失效缓存 |
| `ACT-CLS-047` | 查看全部任职历史 | 点击 | `org.class:read` | 关闭弹窗并跳到 `PAGE-CLS-DETAIL` 的「班主任任职历史」页签 |

## 5. 状态清单

| 状态 | 表现 |
|---|---|
| 有在任班主任 | 标题「变更班主任」；当前班主任 1 行、任职历史 1 行 + 说明（`CDL-26` 实测） |
| 未指定班主任 | 标题「指定班主任」；当前班主任与任职历史都给空态文案（`CDL-27` 实测） |
| 候选人不合格 | 离职（高洪波）、调离（苗雨欣）、非本校（苏睿）三项列出但不可选（`CDL-28` 实测） |
| 历史学期 | 切到历史学期后保存被拦并提示只读（`CDL-29` 实测） |
| 必填缺失 | 未选新任班主任时字段级错误 + 汇总，弹窗不关闭（`CDL-30` 实测） |
| 提交中 | 保存按钮置 loading 并禁用 |

## 6. 跳转关系

| 触发 | 目标 | 打开方式 | 返回行为 |
|---|---|---|---|
| 保存成功 | `PAGE-CLS-LIST` | 关闭弹窗 | 列表「班主任」列刷新；原班主任立即失去本班范围 |
| 「查看全部任职历史」 | `PAGE-CLS-DETAIL`（`#tab=leader-history`） | 关闭弹窗 + 同目录跳转 | 详情页展示完整任职历史 |
| 班级详情 →「指定班主任」 | 本弹窗 | 跨页深链接 `class-list.html#panel=PAGE-CLS-LEADER&class=<班级名称>` | 深链接打开即带入该班级 |

## 7. 权限与数据范围

| 角色 | 入口 | 字段 |
|---|---|---|
| 教务主任 | 可见可操作 | 全部 |
| 年级主任 | 可见可操作，且限本人负责年级的班级 | 全部 |
| 校领导 / 班主任 / 任课教师 / 租户管理员 | 无入口（只读，见 `GAP-034` 裁决 B 的同口径） | — |
| 平台运营 | 无入口 | — |
| 超级管理员 | 全部可见 | 全部可写，强制留痕 |
