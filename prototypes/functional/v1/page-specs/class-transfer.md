# 调班（弹窗）与移出确认（片段）

| 项 | 值 |
|---|---|
| 页面编号 | `PAGE-CLS-TRANSFER`（`type: dialog` + `size: sm`，父页面 `PAGE-CLS-DETAIL`）；移出确认为 `DIALOG-CLS-ROSTER-REMOVE`（二次确认片段，不注册为页面） |
| 所属模块 | 班级管理（`class`） |
| 页面类型 | dialog（两块都随 `pages/class-detail.html` 交付） |
| 骨架模板 | `TPL-OVERLAY` |
| 所属批次 | 2-3（2-3d） |
| 上游需求 | `REQ-CLS-028`、`REQ-CLS-030`、`REQ-CLS-031`、`REQ-CLS-032`、`REQ-CLS-052` |
| 上游规则 | `BR-STU-003`、`BR-STU-012`、`BR-CLASS-005`、`BR-PROMO-007`、`DS-DENY-06`、`DP-01` |
| 权限资源 | `org.class` 的 `update` |
| 数据范围 | `DS-03` / `DS-04`；超级管理员按 `DP-07` 放行 |
| 原型文件 | `pages/class-detail.html` 的 `data-demo-panel="PAGE-CLS-TRANSFER"` 与 `data-demo-panel="DIALOG-CLS-ROSTER-REMOVE"` |

## 1. 页面目的

1. **调班**（`REQ-CLS-031`）：选目标班级 + 生效日期 + 原因，原关系保留历史；
   入口有两处——班级详情花名册行内「调班」，以及编班页冲突行的「调班」（带 `student` / `from` / `to` 深链接，预填目标班级）。
2. **移出确认**（`REQ-CLS-030`）：花名册行内「移出」与工具条「移出所选」都先弹确认；
   移出只结束本班在读关系，**不删除学生主体**，原关系保留历史。

两块都是「花名册关系变更」，因此都放在班级详情页；写入入口仍只有班级模块一处（`DP-01`）。

## 2. 页面结构

### 2.1 调班弹窗

| 顺序 | 区块 | 组件 | 说明 |
|---|---|---|---|
| 1 | 弹窗头 | header | 标题（调班 · 学生姓名（学号））+ 「原关系保留历史」 |
| 2 | 调班规则提示 | `el-alert.info` | 唯一行政班 + 结束原班关系并新增目标班关系 |
| 3 | 源班级 | 只读列表 | 由入口带入；源班级选项在目标下拉里禁用 |
| 4 | 目标班级 | `el-select` | 只列本校同学年学期行政班；已停用班级列出但不可选 |
| 5 | 生效日期 | `el-date-picker` | 默认当前学年学期开始日 |
| 6 | 调班原因 | `el-input.textarea` | 选填，写入审计备注 |
| 7 | 校验汇总 | `el-alert.danger` | 按需展开 |
| 8 | 底部操作条 | footer | 取消 / 确认调班 |

### 2.2 移出确认片段

| 顺序 | 区块 | 组件 | 说明 |
|---|---|---|---|
| 1 | 弹窗头 | header | 标题（移出学生 · N 名成员）+ 「保留关系历史」 |
| 2 | 影响范围 | `el-alert.warning` | 学生主体不删除、原关系保留、历史花名册仍可查；换班请改用调班 |
| 3 | 将移出的成员 | 列表（**不是表格**） | 姓名 · 学号 + 当前班级 |
| 4 | 移出原因 | `el-input.textarea` | 选填，写入审计备注 |
| 5 | 校验汇总 | `el-alert.danger` | 按需展开 |
| 6 | 底部操作条 | footer | 取消 / 确认移出 |

## 3. 字段清单

| 字段名 | 中文 | 组件 | 必填 | 说明 |
|---|---|---|---|---|
| `target_class_id` | 目标班级 | `el-select` | 是 | 排除源班级自身；已停用班级不可选（`REQ-CLS-044`） |
| `effective_date` | 生效日期 | `el-date-picker` | 是 | 生效日之前的归属按历史关系查询 |
| `remark` | 调班原因 / 移出原因 | `el-input.textarea` | 否 | 写入审计备注 |
| `student_no` | 成员 | 只读列表 | — | 移出确认里列出全部待移出成员 |

## 4. 动作清单

| 动作编号 | 元素 | 触发 | 可用条件 | 结果 |
|---|---|---|---|---|
| `ACT-CLS-029` | 花名册行内「调班」 | 点击 | `org.class:update`，且不是历史学年学期 | 打开调班弹窗并带入该生与源班级 |
| `ACT-CLS-056` | 编班页冲突行「调班」 | 点击 | 该生已有行政班 | 跳到本页并自动打开调班弹窗（带 `student` / `from` / `to`） |
| `ACT-CLS-050` | 选择目标班级 / 生效日期 | 选择 | `org.class:update` | 排除源班级与已停用班级 |
| `ACT-CLS-051` | 取消调班 | 点击或 Esc | 始终可用 | 关闭弹窗，归属不变 |
| `ACT-CLS-052` | 确认调班 | 点击 | 目标班级与生效日期齐全 | 调 `transferClass`；结束原班关系 + 新增目标班关系，写审计 |
| `ACT-CLS-026` | 行内「移出」/ 工具条「移出所选」 | 点击 | `org.class:update`；「移出所选」需先勾选 | 打开移出确认片段 |
| `ACT-CLS-064` | 花名册勾选待移出成员 | 勾选 | 非历史学年学期且非只读角色 | 只维护本地勾选集合 |
| `ACT-CLS-048` | 确认移出 | 点击 | 确认片段内已列出成员 | 调 `removeClassRoster`，写审计，原关系保留历史 |
| `ACT-CLS-049` | 取消移出 | 点击或 Esc | 始终可用 | 关闭片段，不写库 |

## 5. 状态清单

| 状态 | 表现 |
|---|---|
| 行内入口 | 点「移出」直接带入该生；点「调班」带入该生 + 源班级并禁用源班级选项（`TR-02` / `TR-06` 实测） |
| 未勾选 | 点「移出所选」只提示「请先在花名册里勾选」，不打开空弹窗（`TR-03` 实测） |
| 勾选后 | 确认片段按勾选列出成员（`TR-04` 实测） |
| 必填校验 | 未选目标班级时保存被拦：字段级错误 + 汇总 + 弹窗不关闭（`TR-07` 实测） |
| 深链接带入 | 编班页跳过来时 `student` / `from` / `to` 三个参数全部生效（`TR-09` 实测） |
| 历史学年学期 | 花名册勾选列全部禁用、行内只剩只读「详情」（`TR-10` 实测） |
| 弹窗内无表格 | 两块片段都不含 `<table>`（`TR-11` 实测，`layout-spec` 规则） |

## 6. 跳转关系

| 触发 | 目标 | 打开方式 | 返回行为 |
|---|---|---|---|
| 调班 / 移出成功 | `PAGE-CLS-DETAIL` | 关闭弹窗 | 花名册与在读人数刷新；原班主任 / 原班级关系保留历史 |
| 编班页「调班」 | 本页调班弹窗 | `class-detail.html#panel=PAGE-CLS-TRANSFER&student=…&from=…&to=…` | 关闭后留在班级详情页 |

## 7. 权限与数据范围

| 角色 | 入口 | 字段 |
|---|---|---|
| 教务主任 | 可见可操作 | 全部 |
| 年级主任 | 可见可操作，且限本人负责年级的班级 | 全部 |
| 校领导 / 班主任 / 任课教师 / 租户管理员 / 平台运营 | 无入口（只读） | — |
| 超级管理员 | 全部可见 | 全部可写，强制留痕 |

## 8. 样例数据
