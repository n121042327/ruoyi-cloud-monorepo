# 按学段批量生成（弹窗）

| 项 | 值 |
|---|---|
| 页面编号 | `PAGE-GRD-BATCH`（取自 `navigation.yaml`，`type: dialog` + `size: md`） |
| 所属模块 | 年级管理（`grade`） |
| 页面类型 | dialog（挂在 `PAGE-GRD-LIST` 的浮层片段） |
| 骨架模板 | `TPL-OVERLAY` |
| 所属批次 | 2-2（2-2b-2b） |
| 上游需求 | `REQ-GRD-015`、`REQ-GRD-012`、`REQ-GRD-014`、`REQ-GRD-035`；`SCN-GRADE-01` |
| 上游规则 | `BR-GRADE-003`、`BR-GRADE-006` |
| 权限资源 | `org.grade` 的 `create` |
| 数据范围 | `DS-02` / `DS-04`；超级管理员按 `DP-07` 放行 |
| 原型文件 | `pages/grade-list.html` 的 `data-demo-panel="PAGE-GRD-BATCH"` |

## 1. 页面目的

开学季一次性把某个学段的全部年级建出来。教务主任只选**学段 + 入学年份**，
系统按固定映射列出将生成的年级；已存在的会跳过并标出来，不覆盖、不改名（`AC-GRD-015`）。

## 2. 页面结构

| 顺序 | 区块 | 组件 | 说明 |
|---|---|---|---|
| 1 | 弹窗头 | header | 标题 + 学校名 + "一次生成一个学段的全部年级" |
| 2 | 生成规则提示 | `el-alert.info` | `REQ-GRD-015` 与"已存在跳过"口径 |
| 3 | 表单 | `el-form` | 学段、入学年份 |
| 4 | 将生成的年级 | 列表（**不是表格**） | 每项一行：年级名 + 学段内序号 + 状态标签（将生成 / 已存在，跳过） |
| 5 | 冲突提示 | `el-alert.warning` | 有冲突时显示"本次将跳过 N 个已存在的年级" |
| 6 | 底部操作条 | footer | 取消 / 确认生成 |

> 弹窗内不使用 `el-table`：`layout-spec.yaml` 规定弹窗只放短表单与二次确认，表格类内容放独立页。

## 3. 字段清单

| 字段名 | 中文 | 组件 | 必填 | 可编辑角色 | 校验规则 |
|---|---|---|---|---|---|
| `stage_code` | 学段 | `el-select` | 是 | 教务主任 / 租户管理员 | 三选一；选项文案带出该学段的年级个数（小学 6 / 初中 3 / 高中 3） |
| `enroll_year` | 入学年份 | `el-select` | 是 | 同上 | 4 位年份；默认取下一学年 |

## 4. 动作清单

| 动作编号 | 元素 | 触发 | 可用条件 | 结果 |
|---|---|---|---|---|
| `ACT-GRD-002` | 列表工具条「按学段批量生成」 | 点击 | `org.grade:create` | 打开本弹窗并渲染预览 |
| `ACT-GRD-019` | 学段 / 入学年份 | 选择 | 同上 | 重算预览清单并标出已存在项（`GL-30` 实测：高中 3 项、小学 6 项、冲突 1） |
| `ACT-GRD-020` | 取消 | 点击 | 始终可用 | 关闭弹窗，不生成 |
| `ACT-GRD-021` | 确认生成 | 点击 | 学段与年份已选 | 一次生成该学段全部年级；已存在跳过并列入结果；写审计 |

## 5. 状态清单

| 状态 | 表现 |
|---|---|
| 校验失败 | 未选学段 / 年份时字段级错误 + 顶部汇总 |
| 部分失败 | 生成后若有冲突项，走列表页的 `partial` 片段（任务编号 + 成功 / 跳过数）——对应 `TASK-20260930-000502` |
| 排队中 | 生成耗时超过阈值时转异步，走列表页的 `queued` 片段（`BR-IMP-015` 配额） |
| 提交中 | 确认生成按钮置 loading 并禁用 |

## 6. 跳转关系

| 触发 | 目标 | 打开方式 | 返回行为 |
|---|---|---|---|
| 确认生成成功 | 回到 `PAGE-GRD-LIST` | 关闭弹窗 | 列表刷新，能看到新生成的年级 |
| 冲突项 | 列表页的 `partial` 片段 | 同页状态切换 | 可下载失败明细（批次 2-9） |

## 7. 权限与数据范围

| 角色 | 入口 | 说明 |
|---|---|---|
| 教务主任 / 租户管理员 | 可见可操作 | 生成范围限本校（`BR-DATA-018` 不跨校共享） |
| 校领导 / 年级主任 / 班主任 / 任课教师 / 平台运营 | 无入口 | — |
| 超级管理员 | 全部可见 | 强制留痕 |

## 8. 样例数据

默认 `高中 + 2027`（下一学年，来自 `calendar.academic_years`）；
切到 `小学 + 2026` 时 `2026 级 小学一年级` 与列表里已有记录冲突，用来演示"已存在，跳过"（`GL-30` 实测）。
