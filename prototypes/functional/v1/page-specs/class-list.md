## 1. 页面目的

教务主任与年级主任在这里回答**"这个学年学期，学生被编到哪些班、谁带这个班"**：
按学年学期 / 年级 / 类型 / 班主任 / 校区筛选班级，进入班级详情与花名册，
新建或按年级批量生成班级，指定班主任，把学生编进班或整体迁到另一个班，
并把建错且没有在读学生的空班停用或删除。

本模块是**唯一有权写入"学生在哪个班"和"谁是班主任"的地方**（`DP-01`），
因此本页的行内入口必须按角色严格收口：班主任与任课教师在本页是只读的，
校领导与租户管理员也是只读，只有教务主任与年级主任（不含删除）可写。

## 5. 状态清单

## 7. 权限与数据范围

| 角色 | 可见内容 | 可见按钮 | 字段级限制 |
|---|---|---|---|
| 教务主任 | 本校全部班级（`DS-04`） | 新建、批量生成、导出；行内 详情 / 编辑 / 指定班主任 / 更多（含删除） | 全部可见 |
| 年级主任 | 本人负责年级的班级（`DS-05`） | 新建、导出；行内 详情 / 编辑 / 指定班主任 / 更多（**无删除**） | 全部可见 |
| 班主任 | 本人担任班主任的班级（`DS-06`） | 只有导出 | 操作列显示「只读」 |
| 任课教师 | 任教班级的必要资料（`DS-07`） | 无（禁止导出花名册，`REQ-CLS-034`） | 操作列显示「只读」；花名册字段裁剪见 `REQ-CLS-012` |
| 校领导 | 本校全部班级（`DS-04`） | 只有导出 | 全列只读 |
| 租户管理员 | 本租户组织配置（`DS-02`），无班级写权限 | 无 | 只读（矩阵显式禁止 `org.class.update`） |
| 平台运营 | 全平台（`DS-01`），默认只读 | 只有「导出（需授权）」 | 切换他校时顶部出现协助视图提示 |
| 超级管理员 | 全平台，不受范围限制（`BR-ORG-014` / `DP-07`） | 全部按钮与全部行内操作 | 无字段级限制；操作强制留痕 |

## 8. 样例数据

取自 `content-samples.json` 的 `classes`（7 条）与 `class_edge_cases`（5 条），
分页总条数取自 `list_totals.class_list_total`（34）。本页选择这些样本的理由：

| 样本 | 用途 |
|---|---|
| 高一 (1) / (2) / (3) 班 | 与 `students`、`student_class_relations` 严格一致（3 / 2 / 1 名在读），验证"在读"列口径 |
| 高一 物理 A 层 | 教学班样本：不设班主任、无容量与教室，且没有「指定班主任」入口（`BR-CLASS-007`） |
| 高二 (1) 班 | 任课教师范围样本（教师 1006 在此班任教外语），用于验证 `DS-07` 的 3 行视图 |
| 高二 (2) 班 | **空班**：已建班未编班（0 / 45），是「删除」可用条件的样本 |
| 高三 (1) 班 | 毕业年级班级（学段内序号取到最大值，升班结果为毕业，`BR-PROMO-005`） |
| 高三 (2) 班 | **已停用**：行内只留「详情」，验证写操作收敛（`REQ-CLS-044`） |
| 初中一年级 (1) 班 | **超容量**：48 / 45，验证"只提示不拦截"（`REQ-CLS-007`） |
| `2026 级 初中一年级 (2) 班（钱学森实验班）` | **超长名称**：验证省略号与 `title` 悬浮 |
| 高一 (3) 班 / 高二 (2) 班 | **未指定班主任**：验证筛选项 `__none` 与行内标签（`BR-CLASS-004`） |
| 初一 (1) 班（云溪外国语学校） | 他校样本：默认筛选看不到，平台运营切到他校时才会出现 |
| 班主任 阿依努尔·艾山 | 间隔号姓名样本，验证不截断、不换行（超长时省略并给 `title`） |
