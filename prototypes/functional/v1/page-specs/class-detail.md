## 1. 页面目的

回答"**这个班是谁带的班、里面有哪些人、都上哪些课、这个班被改过什么**"：
顶部基本信息卡给出归属与名额，下面四个区域分别是花名册、任课教师、班主任任职历史与变更记录。
本页是**只读视角为主**的详情页：写操作（编班、调班、移出、指定班主任）在这里只提供入口，
真正的写入仍走 `PAGE-CLS-ROSTER-ADD` / `PAGE-CLS-TRANSFER` / `PAGE-CLS-LEADER`（`DP-01`）。

## 2. 页面结构

| 顺序 | 区块 | `data-block` | 组件 | 说明 |
|---|---|---|---|---|
| 1 | 页头操作条 | — | `page-head` | 返回列表 + 标题 + 在读标签 + 班级类型 + 学年学期 + 数据范围；按钮组换行右对齐（6 个操作） |
| 2 | 基本信息卡 | `detail` | `el-card` + `el-descriptions` 形态 | 8 个字段：名称 / 年级 / 类型 / 班主任 / 学年学期 / 校区 / 教室 / 容量 |
| 3 | 页签 | `tabs` | `el-tabs` | 花名册（默认）/ 任课教师 / 班主任任职历史 / 变更记录，四个页签各带计数 |
| 4 | 花名册 | `table` | `el-table` | 9 列（学号 / 姓名 / 性别 / 学籍状态 / 加入日期 / 监护人 / 联系电话 / 班级归属 / 操作），`min-width: 1080px` |
| 5 | 任课教师 | — | `el-table` 按学科分组 | 只读展示，来源任教关系（`edu_teaching_assignment`）；未设置的学科给空态说明 |
| 6 | 班主任任职历史 | — | `el-table` | 学年学期 / 班主任 / 是否主管 / 状态 / 任职期间 / 操作人 |
| 7 | 变更记录 | — | `el-timeline` | 4 条样例（新建 / 添加学生 / 指定班主任 / 学籍状态变更），含操作人与来源 IP |

## 4. 动作清单

每个动作都已在 `page-actions.yaml` 的 `class_detail` 节点登记（`ACT-CLS-017` ~ `ACT-CLS-029`，
搜索 / 重置 / 刷新 / 分页复用 `ACT-COM-*`）。

| 动作编号 | 元素 | 可用条件 | 结果 |
|---|---|---|---|
| `ACT-CLS-017` | 返回列表 | 始终可用 | 回到 `PAGE-CLS-LIST`，保留筛选与页码 |
| `ACT-CLS-018` | 四个页签 | 始终可用 | 就地切换区域，不跳页 |
| `ACT-CLS-019` | 编辑班级 | `org.class:update` 且非历史学年 | 打开班级表单编辑态（批次 2-3c） |
| `ACT-CLS-020` | 指定班主任 | 同上，且非教学班 | 打开 `PAGE-CLS-LEADER`（批次 2-3c） |
| `ACT-CLS-021` | 编班（添加学生） | `org.class:update` 且非历史学年 | 进入 `PAGE-CLS-ROSTER-ADD`（批次 2-3d） |
| `ACT-CLS-022` | 复制班级 | `org.class:create` | 打开 `PAGE-CLS-COPY`（批次 2-3c） |
| `ACT-CLS-023` | 批量迁学生 | `org.class:update` 且非历史学年且在读 > 0 | 进入 `PAGE-CLS-MOVE`（批次 2-3d） |
| `ACT-CLS-024` | 导出花名册 | `data.export:export`；任课教师禁止 | 直接下载或转异步，写审计 |
| `ACT-CLS-025` | 成员范围切换 | 始终可用 | 在读成员 / 全部成员 |
| `ACT-CLS-026` | 移出（批量 / 行内） | `org.class:update` 且非历史学年 | 二次确认后移出，保留关系历史 |
| `ACT-CLS-027` | 查看全部变更记录 | `audit.log:read` | 跳操作日志（批次 2-8） |
| `ACT-CLS-028` | 花名册行内「详情」 | `person.student:read` | 打开学生详情（批次 2-5） |
| `ACT-CLS-029` | 花名册行内「调班」 | `org.class:update` 且非历史学年 | 打开调班弹窗（批次 2-3d） |

## 5. 状态清单

| 状态 | `data-state` | 表现 |
|---|---|---|
| 加载中 | `loading` | 花名册区域内骨架 3 段（不遮罩整个详情页） |
| 空数据 | `empty` | 空班：`该班级还没有学生` + 「编班」主动作；筛选无结果时改文案 |
| 查询失败 | `error` | 请求编号 `REQ-20260930-000517` + 错误码 `DS-5002` + 重试 |
| 无权限 | `forbidden` | 说明按 ID 取数前先过滤范围（`DS-DENY-07`），不因知道 ID 就看到数据 |
| 提交中 | `submitting` | 写操作按钮置 loading 并禁用 |
| 部分失败 | `partial` | 批量移出部分失败（3 条中 2 成功 1 失败，含失败原因） |
| 排队中 | `queued` | 导出转异步：任务编号 + 队列位置 + 并发配额 |

## 7. 权限与数据范围

| 角色 | 可见内容 | 可见按钮 | 字段级限制 |
|---|---|---|---|
| 教务主任 | 本班全部（`DS-04`） | 编辑 / 指定班主任 / 编班 / 批量迁学生 / 复制 / 导出 + 行内调班移出 | 全部可见 |
| 年级主任 | 本人负责年级的班级（`DS-05`） | 同教务主任（无复制班级） | 全部可见 |
| 班主任 | 本人担任班主任的班级（`DS-06`） | 只有导出花名册 | 行内无写入口 |
| 任课教师 | 任教班级的必要资料（`DS-07`） | 只有只读浏览 | **学号 / 姓名 / 性别**；监护人、联系电话整列隐藏；禁止导出 |
| 校领导 | 本校全部班级（`DS-04`） | 只有导出花名册 | 只读 |
| 租户管理员 | 本租户组织配置（`DS-02`） | 无 | 只读 |
| 平台运营 | 全平台（`DS-01`） | 只有「导出（需授权）」 | 只读并留痕 |
| 超级管理员 | 全平台不受限（`BR-ORG-014`） | 全部 | 无限制，强制留痕 |
