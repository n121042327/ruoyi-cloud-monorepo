# 归档确认（弹窗）

| 项 | 值 |
|---|---|
| 页面编号 | `PAGE-GRD-ARCHIVE`（取自 `navigation.yaml`，`type: dialog` + `size: sm`） |
| 所属模块 | 年级管理（`grade`） |
| 页面类型 | dialog（危险操作二次确认，只读对象信息 + 必填原因） |
| 骨架模板 | `TPL-OVERLAY` |
| 所属批次 | 2-2（2-2b-2b） |
| 上游需求 | `REQ-GRD-028` ~ `REQ-GRD-031`、`REQ-GRD-035` / `REQ-GRD-036` |
| 上游规则 | `BR-GRADE-005`、`BR-AUDIT-001`、`BR-AUDIT-003` |
| 权限资源 | `org.grade` 的 `update` |
| 数据范围 | `DS-02` / `DS-04`；超级管理员按 `DP-07` 放行 |
| 原型文件 | `pages/grade-list.html` 的 `data-demo-panel="PAGE-GRD-ARCHIVE"` |

## 1. 页面目的

把不再使用的年级停用。归档后年级不再出现在新建班级的下拉里，但历史班级关系、学生关系与统计全部保留。
**归档不等于删除**：年级记录不会消失，禁止物理删除（`REQ-GRD-030`）。

## 2. 页面结构

| 顺序 | 区块 | 组件 | 说明 |
|---|---|---|---|
| 1 | 弹窗头 | header | 标题 + 目标年级 + "危险操作" |
| 2 | 影响范围 | `el-alert.warning` | 归档后发生什么、不发生什么 |
| 3 | 当前引用情况 | 列表（**不是表格**） | 下辖行政班 / 在读学生 / 当前年级主任 |
| 4 | 归档原因 | `el-input.textarea` | 必填，写审计（`REQ-GRD-031`） |
| 5 | 底部操作条 | footer | 取消 / 确认归档（danger） |

## 3. 字段清单

| 字段名 | 中文 | 组件 | 必填 | 说明 |
|---|---|---|---|---|
| `grade_name` | 目标年级 | 只读文本 | — | 从被点击行带入 |
| `class_count` | 下辖行政班 | 只读标签 | — | 引用情况，帮助判断影响面 |
| `student_count` | 在读学生 | 只读标签 | — | 同上 |
| `leader_user_id` | 当前年级主任 | 只读标签 | — | 未指定时显示"未指定" |
| `remark` | 归档原因 | `el-input.textarea` | 是 | 至少 5 个字；写审计 |

## 4. 动作清单

| 动作编号 | 元素 | 触发 | 可用条件 | 结果 |
|---|---|---|---|---|
| `ACT-GRD-006` | 列表行内 / 详情内「归档」 | 点击 | `org.grade:update` 且未归档 | 打开本弹窗并带入该年级的引用情况 |
| `ACT-GRD-028` | 取消 | 点击 | 始终可用 | 关闭弹窗，不归档 |
| `ACT-GRD-029` | 确认归档 | 点击 | 已填归档原因 | 年级置为已归档 + 写审计；行内不再出现写操作 |

## 5. 状态清单

| 状态 | 表现 |
|---|---|
| 校验失败 | 未填原因时字段级红框 + 顶部汇总，弹窗不关闭（`GL-33` 实测） |
| 提交中 | 确认归档按钮置 loading 并禁用 |
| 归档后 | 列表行「状态」变成 `el-tag.info` 的"已归档"，操作列显示"已归档 · 仅可查看" |
| 有引用 | 本弹窗不阻止归档（归档允许有引用）；**删除**才要求无引用（`BR-GRADE-005`） |

## 6. 跳转关系

| 触发 | 目标 | 打开方式 | 返回行为 |
|---|---|---|---|
| 确认归档 | 回到 `PAGE-GRD-LIST` | 关闭弹窗 | 列表刷新；历史统计仍可查（`REQ-GRD-029`） |

## 7. 权限与数据范围

| 角色 | 入口 |
|---|---|
| 教务主任 / 租户管理员 | 可见可操作 |
| 校领导 / 年级主任 / 班主任 / 任课教师 / 平台运营 | 无入口 |
| 超级管理员 | 全部可见，强制留痕 |

## 8. 样例数据

用列表里的 `2024 级 初中三年级`（2 个班 / 88 名在读 / 年级主任 谢明轩）演示有引用的归档；
`2022 级 初中三年级` 是已归档结果，用来看归档后的行形态。
