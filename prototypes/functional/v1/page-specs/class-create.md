# 新建 / 编辑班级（弹窗）

| 项 | 值 |
|---|---|
| 页面编号 | `PAGE-CLS-CREATE`（取自 `navigation.yaml`，`type: dialog` + `size: md`） |
| 所属模块 | 班级管理（`class`） |
| 页面类型 | dialog（挂在 `PAGE-CLS-LIST` 的浮层片段，一窗两态：新建 / 编辑） |
| 骨架模板 | `TPL-OVERLAY` |
| 所属批次 | 2-3（2-3c） |
| 上游需求 | `REQ-CLS-014` ~ `REQ-CLS-023`、`REQ-CLS-061` |
| 上游规则 | `BR-CLASS-002`、`BR-CLASS-003`、`BR-CLASS-005`、`BR-CLASS-007`、`REQ-TERM-030`、`D-043`、`DP-01` |
| 权限资源 | `org.class` 的 `create`（新建） / `update`（编辑） |
| 数据范围 | `DS-04`（教务主任）/ `DS-03`（年级主任，限本人负责年级）；超级管理员按 `DP-07` 放行 |
| 原型文件 | `pages/class-list.html` 的 `data-demo-panel="PAGE-CLS-CREATE"` |

## 1. 页面目的

教务主任或年级主任录入一个**行政班**：选学年学期、年级、班级类型、名称，可选班主任、容量、校区、教室。
编辑时复用同一个弹窗，学年学期与年级只读，有花名册后班级类型也只读。

**载体决策**：`CR-009` / `D-059` 已把班级表单的载体由抽屉改为 `el-dialog`，
与 `markup-contract` 第 4 节的组件映射一致。

## 2. 页面结构

| 顺序 | 区块 | 组件 | 说明 |
|---|---|---|---|
| 1 | 弹窗头 | `el-dialog` header | 标题（新建班级 / 编辑班级）+ 年级 + 形态标签 |
| 2 | 命名与唯一性提示 | `el-alert.info` | 写明同校同学年学期同学段不重名（`BR-CLASS-003`） |
| 3 | 表单 | `el-form` | 学年学期 / 年级 / 班级类型 / 班级名称 / 班主任 / 容量 / 校区 / 教室 |
| 4 | 唯一性冲突 | `el-alert.danger` | 按需显示，指出冲突字段与规则编号 |
| 5 | 校验汇总 | `el-alert.danger` | 外壳校验失败时展开，字段级红框同时出现 |
| 6 | 保存结果 | `el-alert.success` | 成功后出现，含「继续新增 / 进入班级详情 / 立即编班」三个后续动作（`REQ-CLS-018`） |
| 7 | 保存后说明 | `el-alert.warning` | 写审计与重名拒绝口径 |
| 8 | 底部操作条 | footer | 取消 / 保存 |

## 3. 字段清单

| 字段名 | 中文 | 组件 | 必填 | 可编辑角色 | 编辑态 | 校验规则 |
|---|---|---|---|---|---|---|
| `term_id` | 学年学期 | `el-select` | 是 | 教务主任 / 年级主任 | **只读** | 已归档学年学期不出现在选项中（`REQ-TERM-030`）；创建后不可改（`REQ-CLS-022`） |
| `grade_id` | 年级 | `el-select` | 是 | 同上 | **只读** | 只列本校该学年学期下未归档的年级；创建后不可改（`REQ-CLS-022`） |
| `class_type` | 班级类型 | `el-select` | 是 | 同上 | 有花名册时只读 | 行政班可选；教学班选项置灰并指向批次 2-7（见第 9 节） |
| `class_name` | 班级名称 | `el-input` | 是 | 同上 | 可改 | 同校 + 同学年学期 + 同学段唯一（`BR-CLASS-003`） |
| `head_teacher_id` | 班主任 | `el-select` | 否 | 同上 | **只读** | 只列本校在职教师；变更走 `PAGE-CLS-LEADER`（`DP-01` / `REQ-CLS-024`） |
| `class_capacity` | 容量 | `el-input-number` | 否 | 同上 | 可改 | 仅参考值，超容量只提示（`BR-CLASS-005`） |
| `campus_id` | 校区 | `el-select` | 否 | 同上 | 可改 | 不参与权限判定（`BR-ORG-009`） |
| `classroom` | 教室 | `el-input` | 否 | 同上 | 可改 | 不参与任何校验拦截 |

## 4. 动作清单

| 动作编号 | 元素 | 触发 | 可用条件 | 结果 |
|---|---|---|---|---|
| `ACT-CLS-001` | 列表工具条「新建」 | 点击 | `org.class:create` | 打开本弹窗的新建态并重置为默认值 |
| `ACT-CLS-005` | 列表行内「编辑」 | 点击 | `org.class:update`，且不是教学班 | 打开本弹窗的编辑态并带入该班级 |
| `ACT-CLS-030` | 班级类型 | 选择 | 同新建 | 行政班唯一可选；教学班选项带原因置灰 |
| `ACT-CLS-031` | 按规则生成 | 点击 | 已选年级 | 按「年级短名 + 学段内已有序号 + 1」重算名称 |
| `ACT-CLS-032` | 取消 / 关闭 | 点击或 Esc | 始终可用 | 关闭弹窗，不保存 |
| `ACT-CLS-033` | 保存 | 点击 | 必填齐全且不重名 | 新建走 `addClass`；编辑走 `updateClass`；写审计 |
| `ACT-CLS-034` / `035` / `036` | 保存后三个后续动作 | 点击 | 上一次保存成功 | 继续新增 / 进入班级详情 / 立即编班（批次 2-3d） |

## 5. 状态清单

| 状态 | 表现 |
|---|---|
| 校验失败 | 字段级红框 + 错误文案 + 顶部汇总；弹窗不关闭（`CDL-10` 实测） |
| 唯一性冲突 | 独立的冲突提示块，且 1.3 秒后仍不出现「已保存」块（`CDL-11` 实测） |
| 保存成功 | 弹窗不关闭，「已保存」块出现并给出三个后续动作（`CDL-12` 实测） |
| 编辑态 | 学年学期 / 年级 / 类型 / 班主任灰底只读，并显示只读说明（`CDL-14` 实测） |
| 不可编辑角色 | 不在 `data-role-editable` 名单内的角色，8 个字段全部禁用且保存按钮不渲染（`CDL-33` 实测） |
| 提交中 | 保存按钮置 loading 并禁用（外壳统一行为） |

## 6. 跳转关系

| 触发 | 目标 | 打开方式 | 返回行为 |
|---|---|---|---|
| 新建保存成功 | 停留在本弹窗 | — | 出现三个后续动作 |
| 编辑保存成功 | `PAGE-CLS-LIST` | 关闭弹窗 | 列表刷新，保留筛选与页码 |
| 「进入班级详情」 | `PAGE-CLS-DETAIL` | 关闭弹窗 + 同目录跳转 | 详情页「← 返回列表」回到列表 |
| 「立即编班」 | `PAGE-CLS-ROSTER-ADD` | — | 批次 2-3d 交付，本批只验证入口 |
| 班级详情 → 「编辑班级」 | 本弹窗 | 跨页深链接 `class-list.html#panel=PAGE-CLS-CREATE&class=<班级名称>` | 深链接打开即带入该班级（`CDL-36` 实测） |

## 7. 权限与数据范围

| 角色 | 入口 | 字段 |
|---|---|---|
| 教务主任 | 新建 / 编辑 | 全部字段（编辑态：学期、年级、类型、班主任只读） |
| 年级主任 | 新建 / 编辑 | 同上，且年级候选限本人负责年级 |
| 校领导 / 班主任 / 任课教师 / 租户管理员 | 无入口 | — |
| 平台运营 | 无入口 | — |
| 超级管理员 | 新建 / 编辑 | 全部可写，强制留痕 |

## 8. 样例数据

新建态默认：学年学期 `202601`（当前）、年级 `202601`（2026 级 高一）、类型行政班、
名称按规则生成 `高一 (4) 班`（高一已有 1–3 班）、容量 45、校区默认本部校区。
编辑态取被点击行；重名样例用列表里的 `高一 (2) 班`（`CDL-11` 实测）。
数据取自 `content-samples.json` 的 `grades`、`classes`、`class_edge_cases`、`teachers` 与 `org.campuses`。
