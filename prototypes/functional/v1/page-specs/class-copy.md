# 复制班级（弹窗）

| 项 | 值 |
|---|---|
| 页面编号 | `PAGE-CLS-COPY`（取自 `navigation.yaml`，`type: dialog` + `size: md`） |
| 所属模块 | 班级管理（`class`） |
| 页面类型 | dialog（挂在 `PAGE-CLS-LIST` 的浮层片段；入口在行内「更多」下拉） |
| 骨架模板 | `TPL-OVERLAY` |
| 所属批次 | 2-3（2-3c） |
| 上游需求 | `REQ-CLS-061`（建错班级的配套缓解措施） |
| 上游规则 | `BR-CLASS-002`、`BR-CLASS-003`、`BR-CLASS-007`、`DP-01` |
| 权限资源 | `org.class` 的 `create` |
| 数据范围 | `DS-04`（教务主任）；超级管理员按 `DP-07` 放行 |
| 原型文件 | `pages/class-list.html` 的 `data-demo-panel="PAGE-CLS-COPY"` |

## 1. 页面目的

以某个班级为模板，在指定的学年学期与年级下生成一个新班级：复制班级类型、容量、校区、教室；
**不复制花名册、班主任与班主任任职历史**（`REQ-CLS-061`）。学生与班主任属于关系数据，
必须在新班级里重新建立，避免把上一批学生的班级归属误挂到新班级上。

## 2. 页面结构

| 顺序 | 区块 | 组件 | 说明 |
|---|---|---|---|
| 1 | 弹窗头 | `el-dialog` header | 标题 + 源班级名 + 「不复制花名册与班主任」 |
| 2 | 复制口径提示 | `el-alert.info` | 说明只复制配置项 |
| 3 | 源班级摘要 | 列表（**不是表格**） | 9 行：学期 / 年级 / 类型 / 容量 / 校区 / 教室 + 3 行标红的「不复制」 |
| 4 | 目标表单 | `el-form` | 目标学年学期 / 目标年级 / 新班级名称 |
| 5 | 唯一性冲突 | `el-alert.danger` | 按需显示 |
| 6 | 校验汇总 | `el-alert.danger` | 按需展开 |
| 7 | 复制后说明 | `el-alert.warning` | 写明源班级不做任何改动 |
| 8 | 底部操作条 | footer | 取消 / 确认复制 |

## 3. 字段清单

| 字段名 | 中文 | 组件 | 必填 | 说明 |
|---|---|---|---|---|
| `class_id` | 源班级 | 只读列表 | — | 从被点击行带入；教学班不可作为源（见第 5 节） |
| `term_id` | 目标学年学期 | `el-select` | 是 | 默认当前学年学期；已归档学期不出现在选项中 |
| `grade_id` | 目标年级 | `el-select` | 是 | 默认取源班级的年级；含已归档年级但不可选 |
| `class_name` | 新班级名称 | `el-input` | 是 | 默认按目标年级重算；同校 + 同学年学期 + 同学段唯一（`BR-CLASS-003`） |

## 4. 动作清单

| 动作编号 | 元素 | 触发 | 可用条件 | 结果 |
|---|---|---|---|---|
| `ACT-CLS-008` | 行内「更多」→「复制班级」 | 点击 | `org.class:create`，且该行不是教学班 | 打开本弹窗并带入源班级 |
| `ACT-CLS-040` | 目标学年学期 / 目标年级 | 选择 | 同上 | 重算新名称与冲突提示 |
| `ACT-CLS-041` | 按规则生成 | 点击 | 已选目标年级 | 按目标年级重算名称 |
| `ACT-CLS-042` | 取消 / 关闭 | 点击或 Esc | 始终可用 | 关闭弹窗，不创建 |
| `ACT-CLS-043` | 确认复制 | 点击 | 三项必填齐全且名称不冲突 | 调 `addClass`（见第 9 节），写审计 |

## 5. 状态清单

| 状态 | 表现 |
|---|---|
| 摘要展示 | 9 行配置，其中花名册 / 班主任 / 任职历史三行标红（`CDL-21` 实测） |
| 默认值 | 目标学期=当前、目标年级=源年级、名称按规则生成（`CDL-22` 实测） |
| 名称冲突 | 冲突块 + 字段级错误 + 弹窗不关闭（`CDL-23` 实测） |
| 教学班源 | 只给提示「复制班级只支持行政班」，不打开弹窗（`CDL-24` 实测） |
| 提交中 | 确认按钮置 loading 并禁用 |

## 6. 跳转关系

| 触发 | 目标 | 打开方式 | 返回行为 |
|---|---|---|---|
| 复制成功 | `PAGE-CLS-LIST` | 关闭弹窗 | 列表刷新；新班级没有花名册与班主任 |
| 班级详情 → 「复制班级」 | 本弹窗 | 跨页深链接 `class-list.html#panel=PAGE-CLS-COPY&class=<班级名称>` | 深链接打开即带入该班级 |

## 7. 权限与数据范围

| 角色 | 入口 | 字段 |
|---|---|---|
| 教务主任 | 行内「更多」可见「复制班级」 | 全部 |
| 年级主任 | 「更多」里**不出现**复制入口（与 `ACT-CLS-008` 的权限登记一致） | — |
| 校领导 / 班主任 / 任课教师 / 租户管理员 | 无入口 | — |
| 平台运营 | 无入口 | — |
| 超级管理员 | 可见可操作 | 全部 |

## 8. 样例数据

源班级取被点击行（默认样例：`高一 (1) 班`，行政班，容量 45，本部校区，教室本部教学楼 A203，
在读 2 人，班主任邓丽娟）；目标学期 `202601`、目标年级 `202601`、新名称 `高一 (4) 班`。
