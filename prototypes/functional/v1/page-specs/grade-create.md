# 新建 / 编辑年级（弹窗）

| 项 | 值 |
|---|---|
| 页面编号 | `PAGE-GRD-CREATE`（取自 `navigation.yaml`，`type: dialog` + `size: md`） |
| 所属模块 | 年级管理（`grade`） |
| 页面类型 | dialog（挂在 `PAGE-GRD-LIST` 的浮层片段，一窗两态：新建 / 编辑） |
| 骨架模板 | `TPL-OVERLAY` |
| 所属批次 | 2-2（2-2b-2b） |
| 上游需求 | `REQ-GRD-011` ~ `REQ-GRD-020`、`REQ-GRD-035` |
| 上游规则 | `BR-GRADE-001`、`BR-GRADE-002`、`BR-GRADE-003`、`BR-GRADE-006` |
| 权限资源 | `org.grade` 的 `create`（新建） / `update`（编辑） |
| 数据范围 | `DS-02`（租户管理员）、`DS-04`（教务主任）；超级管理员按 `DP-07` 放行 |
| 原型文件 | `pages/grade-list.html` 的 `data-demo-panel="PAGE-GRD-CREATE"` |

## 1. 页面目的

教务主任或租户管理员录入一个年级：选学校、学段、入学年份、学段内序号，名称按规则自动生成并可微调。
编辑时复用同一个弹窗，只放开允许改的字段。

**载体决策**：`apps/plus-ui` 全库 40 处 `el-dialog`、0 处 `el-drawer`，因此表单统一用弹窗，
抽屉只用于详情（`GAP-038` 裁决 A / `CR-007` / `D-058`）。年级 PRD 6.1 本来就写"弹窗"，无需改 PRD。

## 2. 页面结构

| 顺序 | 区块 | 组件 | 说明 |
|---|---|---|---|
| 1 | 弹窗头 | `el-dialog` header | 标题（新建年级 / 编辑年级）+ 学段 + 形态标签（新建 / 编辑） |
| 2 | 命名规则提示 | `el-alert.info` | 说明默认生成规则与可微调（`REQ-GRD-011`） |
| 3 | 表单 | `el-form` | 所属学校 / 学段 / 入学年份 / 学段内序号 / 年级名称 |
| 4 | 冲突与校验汇总 | `el-alert.danger` | 重名冲突与必填校验汇总，按需显示 |
| 5 | 保存后说明 | `el-alert.warning` | 写审计与唯一键冲突口径 |
| 6 | 底部操作条 | footer | 取消 / 保存 |

## 3. 字段清单

| 字段名 | 中文 | 组件 | 必填 | 可编辑角色 | 编辑态 | 校验规则 |
|---|---|---|---|---|---|---|
| `school_id` | 所属学校 | `el-select` | 是 | 教务主任 / 租户管理员 | 可改（受数据范围约束） | 只能选数据范围内的学校 |
| `stage_code` | 学段 | `el-select` | 是 | 同上 | **只读** | `primary` / `junior` / `senior`，创建后不可改（`REQ-GRD-018`） |
| `enroll_year` | 入学年份 | `el-select` | 是 | 同上 | **只读** | 4 位年份；有班级时不可改（`REQ-GRD-019`） |
| `grade_level` | 学段内序号 | `el-select` | 是 | 同上 | **只读** | 小学 1–6、初中 1–3、高中 1–3，超范围拒绝（`REQ-GRD-012`） |
| `grade_name` | 年级名称 | `el-input` | 是 | 同上 | 可改 | 同校同学段下唯一（`BR-GRADE-002`） |

## 4. 动作清单

| 动作编号 | 元素 | 触发 | 可用条件 | 结果 |
|---|---|---|---|---|
| `ACT-GRD-001` | 列表工具条「新增」 | 点击 | `org.grade:create` | 打开本弹窗的新建态并重置为默认值 |
| `ACT-GRD-004` / `ACT-GRD-012` | 列表行内 / 详情内「编辑」 | 点击 | `org.grade:update` | 打开本弹窗的编辑态并带入该年级 |
| `ACT-GRD-016` | 按规则重新生成 | 点击 | 始终可用 | 名称重算，仍可人工微调 |
| `ACT-GRD-017` | 取消 | 点击 | 始终可用 | 关闭弹窗，不写入 |
| `ACT-GRD-018` | 保存 | 点击 | 必填齐全且不重名 | 前端先拦重名，接口再校验唯一键；成功后写审计并刷新列表 |

## 5. 状态清单

| 状态 | 表现 |
|---|---|
| 校验失败 | 字段级红框 + 错误文案 + 顶部汇总；弹窗不关闭（`GL-28` 实测） |
| 唯一性冲突 | 独立的冲突提示块，指出"同校同学段已有同名年级"（`BR-GRADE-002`） |
| 提交中 | 保存按钮置 loading 并禁用，禁止重复提交 |
| 不可编辑角色 | 不在 `data-role-editable` 名单内的角色，字段整体灰底只读（含只读说明） |

## 6. 跳转关系

| 触发 | 目标 | 打开方式 | 返回行为 |
|---|---|---|---|
| 保存成功 | 回到 `PAGE-GRD-LIST` | 关闭弹窗 | 列表刷新；新建后可继续新增或查看详情 |
| 取消 | 回到 `PAGE-GRD-LIST` | 关闭弹窗 | 已填内容不保留（年级表单字段少，不额外做放弃确认） |

## 7. 权限与数据范围

| 角色 | 入口 | 字段 |
|---|---|---|
| 教务主任 | 新增 / 编辑 | 全部字段（编辑态：学段、序号、入学年份只读） |
| 租户管理员 | 新增 / 编辑 | 同上（属非教学配置） |
| 校领导 / 年级主任 / 班主任 / 任课教师 / 平台运营 | 无入口 | — |
| 超级管理员 | 新增 / 编辑 | 全部可写，强制留痕 |

## 8. 样例数据

新建态默认 `2027 级 高一`（入学年份 2027 + 高中 + 序号 1），来自 `content-samples.json` 的
`calendar.academic_years` 下一学年；编辑态来自被点击的列表行。
重名样例用列表里已存在的 `2026 级 小学一年级`（`GL-28` 实测）。
