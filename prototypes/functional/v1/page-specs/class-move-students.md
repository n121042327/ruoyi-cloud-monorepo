# 批量迁学生独立页

| 项 | 值 |
|---|---|
| 页面编号 | `PAGE-CLS-MOVE`（取自 `navigation.yaml`，`type: page` + `route: /edu/class/move-students`） |
| 所属模块 | 班级管理（`class`） |
| 页面类型 | page（独立页，含影响预览表格，按 `D-059` 不用抽屉 / 弹窗） |
| 骨架模板 | `TPL-LIST` 的分段变体（三步：选学生 → 选目标班 → 影响预览） |
| 所属批次 | 2-3（2-3d） |
| 上游需求 | `REQ-CLS-062`、`REQ-CLS-030`、`REQ-CLS-032`、`REQ-CLS-052` |
| 上游规则 | `BR-STU-003`、`BR-STU-012`、`BR-CLASS-005`、`BR-CLASS-008`、`BR-PROMO-007`、`DS-DENY-06`、`DP-01` |
| 权限资源 | `org.class` 的 `update`（写入）；`org.class` 的 `read`（读花名册） |
| 数据范围 | `DS-03` / `DS-04`；超级管理员按 `DP-07` 放行 |
| 原型文件 | `prototypes/functional/v1/pages/class-move-students.html` |

## 1. 页面目的

把源班级选中的**在读学生**整体迁入目标班级：先展示影响预览，再逐条校验唯一行政班后执行；
原班级关系保留历史、不覆盖（`REQ-CLS-062` / `BR-PROMO-007`）。

**与「升班」的区别**：升班跨学年学期新增下一学年的关系（一年一次，按学年追加）；
批量迁学生只在同一学年学期内调整行政班归属，不改年级、不产生新学年数据。

## 2. 页面结构

| 顺序 | 区块 | 组件 | 说明 |
|---|---|---|---|
| 1 | 页头 | `el-page-header` 形态 | 返回班级列表 + 源班级 + 学期标签 + 数据范围提示 |
| 2 | 迁移规则提示 | `el-alert.info` | 整体迁移、逐条校验、保留历史、休学不参与 |
| 3 | 1 · 选择要迁移的学生 | `el-card` + `el-table` | 5 列（勾选 / 学号 / 姓名 / 学籍状态 / 当前行政班）；全选在读成员 / 清空选择 |
| 4 | 2 · 选择目标班级 | `el-card` + `el-form` | 目标班级下拉（排除源班级与已停用班级）+ 迁移说明 |
| 5 | 3 · 影响预览 | `el-card` + `el-table` | 5 列（学号 / 学生 / 当前行政班 / 迁移后行政班 / 校验结果）+ 执行迁移 |
| 6 | 结果块 | `el-alert.success` | 成功后写明迁移人数与两个班级 |
| 7 | 状态块 | 7 类状态 | loading / empty / error / forbidden / submitting / partial |

## 3. 字段清单

| 字段名 | 中文 | 组件 | 必填 | 说明 |
|---|---|---|---|---|
| `student_no` | 学号 | 只读列 + 勾选 | — | 只有在读成员的复选框可用（休学等保留关系的不参与，`BR-STU-012`） |
| `target_class_id` | 目标班级 | `el-select` | 是 | 只列本校同学年学期的行政班；源班级自身与已停用班级不可选（`REQ-CLS-044`） |
| `remark` | 迁移说明 | `el-input` | 否 | 写入审计备注；迁移本身无论是否填写都写审计（`REQ-CLS-052`） |

## 4. 动作清单

| 动作编号 | 元素 | 触发 | 可用条件 | 结果 |
|---|---|---|---|---|
| `ACT-CLS-009` | 班级列表行内「更多」→「批量迁学生」 | 点击 | `org.class:update`，且在读人数 > 0 | 进入本页并带 `class=<源班级>` |
| `ACT-CLS-023` | 班级详情的「批量迁学生」 | 点击 | 同上，且不是历史学年学期 | 同上 |
| `ACT-CLS-059` | 勾选 / 全选 / 清空源班级在读成员 | 勾选或点击 | 只有 `data-movable=true`（在读）的成员可勾选 | 影响预览随之重算；不写库 |
| `ACT-CLS-060` | 选择目标班级 / 填写迁移说明 | 选择或输入 | `org.class:update` | 跨年级时给确认提示；已停用班级选中即给错误提示 |
| `ACT-CLS-061` | 刷新影响预览 | 点击 | `org.class:read` | 按最新勾选与目标班级重算预览（只读） |
| `ACT-CLS-062` | 执行迁移 | 点击 | 至少一名在读成员被勾选且目标班级未停用 | 调 `transferClass`，逐条校验、任一条失败列失败清单，写审计 |
| `ACT-CLS-063` | 返回班级列表 / 取消 | 点击 | 始终可用 | 回到 `PAGE-CLS-LIST`，不写库 |

## 5. 状态清单

| 状态 | 表现 |
|---|---|
| 默认 | 源班级高一 (1) 班：在读 2 人、默认全选；预览 2 行全部「校验通过：可迁移」（`MV-01` / `MV-03` 实测） |
| 休学成员 | 显示但复选框禁用，当前行政班标签写明「保留关系，不参与迁移」（`MV-02` 实测） |
| 清空选择 | 预览给「请先在 1 里勾选…」提示，已选人数归零（`MV-04` 实测） |
| 目标班级已停用 | 出现专用提示块 + 预览每行「目标班级已停用，不可迁入」+ 执行被拦（`MV-05` / `MV-07` 实测） |
| 跨年级目标 | 出现确认提示并写明依据（`BR-CLASS-008`）（`MV-06` 实测） |
| 执行成功 | 结果块写明「已迁移 N 名学生：源班 → 目标班」+ 保留历史说明（`MV-08` 实测） |
| 空班 | 源班级没有在读成员时给空态，而不是一张空表（`MV-09` 实测） |
| 历史学年学期 | 顶部只读提示条 + 勾选全部禁用 + 隐藏「执行迁移」（`REQ-CLS-032`） |
| 部分失败 | `partial` 状态块给出失败清单样例（逐条校验、不整体回滚，`DS-DENY-06`） |

## 6. 跳转关系

| 触发 | 目标 | 打开方式 | 返回行为 |
|---|---|---|---|
| 执行成功 | `PAGE-CLS-LIST` | 关闭本页 | 两个班级的在读人数刷新 |
| 「返回班级列表」/ 取消 | `PAGE-CLS-LIST` | 同目录跳转 | 保留列表筛选与页码 |
