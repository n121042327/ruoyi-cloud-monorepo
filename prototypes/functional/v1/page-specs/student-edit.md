# 编辑学生（抽屉）

| 项 | 值 |
|---|---|
| 页面编号 | `PAGE-STU-EDIT` |
| 所属模块 | 学生管理（`student`） |
| 页面类型 | drawer |
| 骨架模板 | `TPL-OVERLAY`（抽屉 md = 640px） |
| 所属批次 | 2-1（样板） |
| 上游需求 | `REQ-STU-026` ~ `REQ-STU-032` |
| 上游规则 | `BR-STU-010`、`BR-STU-011`、`BR-STU-021`、`NFR-SEC-05`、`NFR-PERF-03` |
| 权限资源 | `person.student` 的 `update`；监护人字段取 `person.student_guardian:update`；联系方式取 `person.student_contact:update` |
| 数据范围 | `DS-04` 本校 / `DS-05` 本年级 / `DS-06` 本班 |
| 原型文件 | `pages/student-list.html` 内 `data-demo-panel="PAGE-STU-EDIT"` |

## 1. 页面目的

从列表行内"编辑"进入，用于修改数据范围内的学生信息。
本页的核心不是"能改什么"，而是**同一个抽屉在不同角色下呈现不同的可编辑字段**：
灰底字段为只读，后端同样拒绝写入（`NFR-SEC-05`）。改完后回到列表并保留筛选与页码。

## 2. 页面结构

| 顺序 | 区块 | `data-block` | 组件 | 说明 |
|---|---|---|---|---|
| 1 | 抽屉头 | — | `el-drawer` 标题 | 学生姓名 + 学号标签 + 当前学籍状态标签 |
| 2 | 字段级权限提示 | — | 提示条 | 说明灰底字段为只读、后端同样拒绝 |
| 3 | 步骤条 | — | `el-steps` | 与新增一致的三步，编辑时同样分步 |
| 4 | 步骤内容 | `form` | `el-form` | 学号在高权限角色下才出现"高级操作 · 修改学号" |
| 5 | 底部操作条 | `footer` | 固定 64px | 取消 / 上一步 / 下一步 / 保存 |

## 4. 动作清单

| 动作编号 | 元素 | 触发 | 可用条件 | 结果 | 接口 |
|---|---|---|---|---|---|
| `ACT-STU-011` | 下一步 | 点击 | 当前步骤校验通过 | 进入下一步 | — |
| `ACT-STU-012` | 上一步 | 点击 | 非第一步 | 返回上一步 | — |
| `ACT-STU-013` | 保存 | 点击 | 校验通过且有字段级写权限 | 保存成功；并发冲突时提示"已被他人更新，请刷新后重试" | `updateStudent` |
| `ACT-STU-014` | 取消 / 关闭 | 点击 | 始终可用 | 二次确认后关闭，不保存 | — |
| `ACT-STU-015` | 添加监护人 | 点击 | 少于上限 3 | 新增一行 | `saveStudentGuardian` |
| `ACT-STU-016` | 删除监护人 | 点击 | 至少保留一行 | 移除该行 | `saveStudentGuardian` |
| `ACT-STU-018` | 修改学号（首轮不提供） | — | 首轮不渲染入口（`GAP-030` 裁决 B） | 无 | — |
| `ACT-STU-021` | 上传 / 更换学生照片 | 点击 | `person.student:create` / `update` | 单张上传；保存后只展示缩略图 | `uploadStudentPhoto` |
| `ACT-STU-022` | 查看照片原图 | 点击缩略图 | `read_sensitive` | 展示原图并写访问日志 | `getStudentPhoto` |
| `ACT-STU-010` | 查看完整证件号 | 点击 | `read_sensitive` | 就地展示完整值并写访问日志（见 `GAP-026`） | `viewStudentIdCard` |

> `ACT-STU-010` 在 `page-actions.yaml` 中登记在 `PAGE-STU-LIST`；本批在编辑抽屉内复用，已把该动作的 `page` 扩展为 `[PAGE-STU-LIST, PAGE-STU-EDIT, PAGE-STU-DETAIL]`。

## 5. 状态清单

| 状态 | `data-state` | 表现 | 主动作 |
|---|---|---|---|
| 加载中 | `loading` | 抽屉内字段区骨架 | — |
| 空数据 | `empty` | 该学生尚未登记监护人时给"暂无监护人信息，可点添加监护人" | 添加监护人 |
| 查询失败 | `error` | 详情加载失败给请求编号 | 重试 |
| 无权限 | `forbidden` | 无 `person.student:update` 时列表页不出现"编辑"入口 | 返回 |
| 提交中 | `submitting` | 保存按钮 loading 且禁用 | — |
| 部分失败 | `partial` | 学生字段保存成功但监护人保存失败时，提示"学生信息已保存，监护人未保存" | 重试监护人保存 |

## 6. 跳转关系

| 触发 | 目标 | 打开方式 | 返回行为 |
|---|---|---|---|
| 取消 | 二次确认弹窗 | 弹窗（sm） | 确认后关闭并回到列表，保留筛选与页码 |
| 点击"查看完整证件号" | 访问日志 | 后台写入 | 不影响页面结构 |
| 点击"修改学号" | 二次确认 | 弹窗 | 确认后刷新抽屉与列表 |

## 7. 权限与数据范围

| 角色 | 是否有"编辑"入口 | 可写字段 | 说明 |
|---|---|---|---|
| 教务主任 | 有 | 除学号、行政班、学籍状态、年级外全部 | 主要维护者 |
| 年级主任 | 有 | 同教务主任，但监护人只读 | `05-permission-matrix.yaml` 的 `grade_leader.forbidden` |
| 班主任 | 有 | 仅 `student_phone`、`address` 与监护人字段 | 不能改学号、姓名、性别、班级归属、学籍状态 |
| 任课教师 | 无 | — | 只读必要基本信息 |
| 校领导 | 无 | — | 审批类操作在异动与选科模块 |
| 平台运营 | 无 | — | 默认只读 |
