怎么演示（2 分钟）

  1. 打开 学生管理列表，左侧菜单与顶部导航、页签栏、面包屑为完整外壳。
  2. 右下角「原型演示」面板（点标题栏展开）切换角色（超级管理员 / 教务主任 / 班主任 / 年级主任 / 任课教师 / 校领导 / 平台运营），观察按钮与字段的显隐差异。
  3. 切换页面状态（加载中 / 空数据 / 查询失败 / 无权限 / 提交中 / 部分失败 / 排队中），逐条核对状态形态。
  4. 点「新增」打开三步弹窗，只填姓名直接点「下一步」可见字段级校验；填完三步点「保存」见成功反馈。
  5. 点行内「编辑」打开编辑弹窗，切换角色可见「字段级可编辑性矩阵」效果（灰底字段为只读）。
  6. 打开 教师管理列表，点任意数据行打开教师详情抽屉：左上角切换「跨校任教（苏睿）」与「班主任 + 任课（邓丽娟）」两种形态，看跨校说明、教育角色空态与变更记录时间线。
  7. 在教师列表点「新增」打开三步弹窗：只填姓名直接点「下一步」看字段级校验；走到第三步点「保存」看成功结果条与「继续新增 / 查看详情 / 立即设置任教」三个后续动作。
  8. 点「取消」看放弃确认弹窗：写清影响范围，确认后同时关闭两个浮层。
  9. 在教师列表点行内「角色」打开教育角色分配：看学校级角色勾选、年级主任任职（学年学期 + 年级必填）与保存前四条检查；点「新增年级主任任职」展开子表单。
  10. 在教师列表点行内「任教」进入 任教关系设置：左栏切「班级视角 / 教师视角」，点不同班级或教师看右栏变化；点「复制上一学年」看冲突预览（复制 / 跳过 / 待处理）。
  11. 学生列表点任意数据行：学生详情在批次 2-5 交付，本批只给占位提示，用于验证入口与权限显隐。
  12. 打开 年级管理列表，点工具条「导出」上方的空年级行（也可直接用 #enroll=2021 只筛出它）：它是唯一带「删除」入口的行，点「删除」看二次确认，不填原因直接确认可看到字段级校验。
  13. 打开 班级管理列表，先看默认形态：在读 / 容量是两列，「初中一年级 (1) 班」行有「超容量」提示但写操作仍然可用（只提示不拦截）。再切演示面板的角色：班主任 只剩 1 行、任课教师 只剩 3 行且禁止导出花名册、年级主任 4 行且菜单里没有「删除」。最后点任一行的「更多 ▾」：有在读学生的班没有「删除」，空班（高二 (2) 班）才有，点它看删除二次确认与字段级校验。
  14. 在年级列表把角色切到「校领导」与「年级主任」：两者都看不到新增 / 批量生成，操作列显示「只读」；再切到「超级管理员」，页头出现全平台与强制留痕提示，且全部按钮与行内操作都可见。
