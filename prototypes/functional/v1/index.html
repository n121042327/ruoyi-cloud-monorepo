怎么演示（2 分钟）

  1. 打开 学生管理列表，左侧菜单与顶部导航、页签栏、面包屑为完整外壳。
  2. 右下角「原型演示」面板（点标题栏展开）切换角色（教务主任 / 班主任 / 年级主任 / 任课教师 / 校领导 / 平台运营），观察按钮与字段的显隐差异。
  3. 切换页面状态（加载中 / 空数据 / 查询失败 / 无权限 / 提交中 / 部分失败 / 排队中），逐条核对状态形态。
  4. 点「新增」打开三步抽屉，只填姓名直接点「下一步」可见字段级校验；填完三步点「保存」见成功反馈。
  5. 点行内「编辑」打开编辑抽屉，切换角色可见「字段级可编辑性矩阵」效果（灰底字段为只读）。
  6. 点任意数据行：详情页在批次 2-5 交付，本批只给占位提示，用于验证入口与权限显隐。
