# 原型质量规范（"空洞"根因与约束）

本文件回答一个问题：**为什么之前的原型"看着像 demo"，以及每一条怎么被约束住。**

只写"要企业级"没有用——那是形容词，不是约束。下面的 18 条每条都给出：空洞的具体表现、对应的约束、约束写在哪、怎么检查。

## 0. 一句话判断

> 一个页面像不像 demo，不看它好不好看，看它**敢不敢把真实世界的复杂度画出来**：
> 空的、满的、超长的、没权限的、失败的、被驳回的、跨校的、休学的，都得有。

## 1. 根因清单

| # | 根因 | 空洞的具体表现 | 约束 | 落在哪 | 检查方式 |
|---|---|---|---|---|---|

| 16 | 页面没标出"当前在看谁的数据" | 同一个列表，教务主任与班主任看到的内容不同，页面上却没有任何范围提示，验收时无法判断谁是对的 | 每个列表 / 详情页必须在页头给出当前数据范围（学校 · 年级 · 班级，或跨校共享授权）与数据截止时间 | `layout-spec.yaml` 的 `page_head` + 本文件第 4 节 | 截图里必须能看到范围提示 |
| 17 | 字段级可编辑性没有落到原型上 | 只画了"按钮有没有"，没画"同一个字段在不同角色下是可写还是只读"，生产端只能靠猜 | 表单字段必须标 `data-role-editable`；只读用灰底 disabled 形态表达，不用纯文本；每个可编辑页面至少给出 2 个角色的字段级差异 | `markup-contract.md` 第 2 节 + PRD 的字段级可编辑性矩阵 | 切换角色逐字段核对 |

## 2. 数据真实性约束

1. 所有演示数据取自 `content-samples.json`（`students` / `students_edge_cases` / `classes` / `grades` / `async_tasks` / `list_totals` 等节点），**不得在页面里临时编造**。
2. 占位词黑名单（出现即判不合格）：`张三`、`李四`、`王五`、`test`、`demo`、`示例`、`xxx`、`TODO`、`Lorem`、`1`（作为唯一的字段值）。
3. 每张表格原型必须给出**不少于 10 行**数据，并显示分页器与总条数（例如"共 137 条"），否则看不出翻页与列宽的真实表现。
4. 金额、人数、条数一律给真实量级（如"在读学生 128 名"），不给 `0` 或 `1` 作为唯一值。
5. 学校、年级、班级、教师、学生的名称必须前后一致：同一个班级在列表、详情、下拉里是同一个名字。

## 3. 边界数据约束

`content-samples.json` 的 `edge_cases` 定义了 8 类边界样本，`students_edge_cases` 把其中只有文字描述的样本补成可直接渲染的记录（超长姓名、间隔号、终态）。**每个页面至少用到与其相关的 3 类**：

| 类别 | 样本 | 用它的页面要看到什么 |
|---|---|---|
| 空 | 某个班 0 名学生、某个年级无班主任 | 空态文案与主动作 |
| 满 | 一个班 45/45 人 | 容量提示（只提示不拦截，`BR-CLASS-005`） |
| 超长 | 姓名 8 字（如"欧阳慕容芷若"）、地址 60 字 | 表格超长省略 + 悬浮完整；详情不折行错乱 |
| 缺失 | 学生没有手机号、没有全国学籍号 | 显示为 `—`，不显示 `null` / 空字符串 |
| 特殊 | 姓名含间隔号（"阿依古丽·买买提"） | 不截断成乱码、排序正确 |
| 终态 | 已毕业、已转出、死亡 | 终态学生无任何异动入口 |
| 待办中 | 转入未报到、待审批 | 警示色标签 + 可执行动作 |
| 跨校 | 跨校任教、跨校转学、平台运营查看他校 | 学校用户看不到他校数据；平台运营视图要有"协助视图 · 只读"标识与留痕提示。**共享授权只针对题库习题与试卷等资源，不放开学生、班级、教师、成绩等业务数据** |

## 4. 角色视角约束

1. 每个页面至少给出**两种角色形态**，且差异必须落在"按钮是否出现"和"字段是否可见"上，不能只改一句提示。
2. 推荐对照组：

| 页面类型 | 管理角色 | 执行角色 | 必须看到的差异 |
|---|---|---|---|
| 学生列表 | 教务主任 | 班主任 | 教务主任有新增/导入/导出；班主任无新增导入、有导出（受限）、能编辑监护人 |
| 学生详情 | 教务主任 | 任课教师 | 教务主任能看到证件号（掩码）、监护人；任课教师只看到学号、姓名、性别、班级 |
| 班级详情 | 教务主任 | 班主任 | 教务主任能编班、调班；班主任只读花名册 |
| 日志查询 | 校领导 | 任课教师 | 校领导能查本校；任课教师整页不可见（菜单与路由都不出现） |
| 平台运营视角 | — | 平台运营 | 无任何写操作入口；敏感字段默认掩码；页面顶部有"当前为运营协助视图"提示 |

3. 角色切换用原型顶部的角色切换器（`data-demo="role-switcher"`）演示，不复制多份页面。

## 5. 组件选择决策表

选错容器是"不专业"最直观的来源。按"数据量 × 是否离开上下文"决策：

| 场景 | 必须使用 | 禁止 |
|---|---|---|
| 新增 / 编辑 3 个以上字段 | 抽屉（`el-drawer`） | 弹窗 |
| 新增 / 编辑 1—2 个字段 | 弹窗（`el-dialog`） | 抽屉 |
| 二次确认、危险操作 | 弹窗（小尺寸 sm） | 直接执行 |
| 需要对照列表数据填写 | 抽屉（保留背景列表可见） | 跳新页 |
| 包含表格、分页、批量选择 | 独立页 | 弹窗、抽屉 |
| 多步骤且有前置依赖 | 向导页（`el-steps`，不跳页） | Tab 假装多步 |
| 只读展示一组字段 | `el-descriptions` | 一整块 disabled 表单 |
| 同一对象的多个平行维度 | `el-tabs`（页签） | 纵向堆 8 个卡片 |

> **载体以现有代码库为准（2026-09-30，`D-058` / `CR-007`）**：上面这张表里的"抽屉"是设计上的推荐值，
> 但 `apps/plus-ui` 的真实习惯是**表单与详情都用 `el-dialog`**（全库 40 处 `el-dialog`、0 处 `el-drawer`）。
> 因此本项目的落地规则是：**表单类与二次确认统一用弹窗**；抽屉只用于上游 PRD 显式写明的详情页
> （教师详情、学生详情、日志详情、任务详情）。年级模块已按此实现，其余模块的差异登记在 `GAP-039`。

## 6. 交批验收清单

每批原型交付前逐条打勾，缺项不许交：

- [ ] 页面骨架属于四种模板之一（`layout-spec.yaml`）
- [ ] 渲染完整外壳：侧边菜单 + 顶部导航 + 页签栏 + 面包屑 + 租户切换
- [ ] 列表页密度达标：筛选项 ≥ 4、列 ≥ 6、行操作 ≥ 2、表格 ≥ 10 行、有分页器与总条数
- [ ] 状态列用 `el-tag` 且颜色符合语义映射表
- [ ] 六类状态（加载 / 空 / 错误 / 无权限 / 提交中 / 部分失败）都有可见形态
- [ ] 至少用到 3 类边界数据（空、满、超长、缺失、特殊、终态、待办中、跨校）
- [ ] 至少给出 2 种角色形态，差异落在按钮与字段上
- [ ] 页头给出当前数据范围与数据截止时间
- [ ] 枚举值、标签与颜色与 `06-field-dictionary.yaml` 一致，未自行发明状态文案
- [ ] 表单字段标 `data-role-editable`，只读字段用灰底 disabled 形态
- [ ] 写操作成功后受影响的列表会刷新，页签标记待刷新；返回来源页保留筛选与页码
- [ ] 每个可交互元素带 `data-page` / `data-role` / `data-action-id`（跳转类带 `data-nav`）
- [ ] 每个 `data-action-id` 在 `page-actions.yaml` 中可查
- [ ] 每个写动作有确认（危险动作）→ loading → 成功提示 → 刷新 → 失败原因
- [ ] 文案走模板，不出现"操作成功""数据不存在"这类泛化文案
- [ ] 日期 / 时间 / 数字 / 电话格式统一（见 `layout-spec.yaml` 的 `text_format`）
- [ ] 1366×768 / 1440×900 / 1920×1080 三档截图无破裂，截图归档到 `evidence/`
- [ ] 原型内可点击演示主流程（纯 JS，无需后端）
- [ ] 无占位词（`tools/check_docs.py` 自动扫描）

## 7. 与其它规范的分工

| 文件 | 管什么 |
|---|---|
| `layout-spec.yaml` | 尺寸、间距、栅格、字阶、格式、外壳 |
| `navigation.yaml` | 有哪些页面、怎么跳、谁能进 |
| `page-actions.yaml` | 每个按钮做什么、给什么反馈 |
| `markup-contract.md` | 元素怎么标注、怎么映射到组件、原型怎么可点 |
| `content-samples.json` | 用什么数据、有哪些边界样本 |
| **本文件** | **为什么这么要求、怎样才算合格** |
