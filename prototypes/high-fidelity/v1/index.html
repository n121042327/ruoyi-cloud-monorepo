怎么演示（2 分钟）

  1. 打开 学生管理列表：白色卡片浮在浅灰底上、表头有底色、主行动是主色按钮——这就是阶段 3 与阶段 2 的视觉差异。
  2. 右下角「高保真演示」面板（点标题栏展开）切换 8 种角色：任课教师 会隐藏「联系电话」整列，租户管理员 直接进入无权限形态（DS-02 无教学数据范围）。
  3. 切换页面状态：空数据 / 查询失败 / 无权限 / 提交中——状态片段会替换主内容而不是堆在下方。
  4. 点任一行「详情」：抽屉带回该行学生的姓名 / 学号 / 班级 / 状态，并展示证件号掩码口径与变更记录时间线。
  5. 点「新增学生」：清空姓名点保存会出现字段级错误；「保存」的反馈写明系统发号与「默认未分班」。
  6. 点行内「编辑」：联系电话字段登记了字段级可编辑性——把角色切到「年级主任」看它变灰底只读。
