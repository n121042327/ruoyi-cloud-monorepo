# 高保真原型交互说明

本文档说明 `prototypes/high-fidelity/v1/pages/` 里 45 个页面的**交互约定**：
状态怎么切、加载怎么表现、空态与错误态长什么样、角色与权限怎么演示、页面之间怎么跳。

它不重复视觉参数（在 `design-tokens.json` 与 `component-spec.md`），
也不重复组件映射（在 `component-mapping.yaml` 与 `business-components.yaml`）。

## 1. 三条硬约定（阶段 6 必须沿用）

| 编号 | 约定 | 原因 |
|---|---|---|
| IA-01 | **状态片段替换主内容，不是叠加浮层** | 主内容包在 `[data-normal-view]` 内；切到空态 / 错误态 / 无权限时整个主区域被替换，避免「错误提示浮在正常数据上」 |
| IA-02 | **表单类浮层用 `el-dialog`，详情类用 `el-drawer`，含表格或分页的用独立页** | D-059 / CR-015；判断标准是内容形态，不是开发习惯 |
| IA-03 | **错误态必须同时给出错误码与请求编号** | 用户报障时运维能直接定位；错误码表见 `docs/40-detailed-design/api/error-codes.yaml` |

## 2. 状态片段机制

高保真原型用一套统一机制演示同一页面的多种状态，页脚「演示面板」可以切换：

```html
<!-- 正常态：主内容 -->
<main data-normal-view> ... 表格 / 表单 ... </main>

<!-- 状态片段：同一位置的替代内容 -->
<section data-demo-state-panel="empty"> ... 空态 ... </section>
<section data-demo-state-panel="error"> ... 错误态 ... </section>
<section data-demo-state-panel="forbidden"> ... 无权限 ... </section>
```

切换逻辑由 `assets/hifi-shell.js` 提供：选中某个状态片段时，`[data-normal-view]` 隐藏、
对应 `[data-demo-state-panel]` 显示。阶段 6 的生产前端用 `v-if / v-else-if` 表达同一组分支，
**不要**改成弹窗或 toast 叠加。

各页面登记的状态片段集合由 `prototypes/functional/v1/navigation.yaml` 定义，
阶段 3 与阶段 2 的片段集合一致（由 `tools/make_hifi_coverage.py` 门禁校验）。

## 3. 角色与可编辑性

演示面板可以切换角色，角色决定两件事：

| 属性 | 作用 | 阶段 6 对应实现 |
|---|---|---|
| `data-role-visible="<角色列表>"` | 元素是否可见 | `v-permission` 指令 + 后端 `@SaCheckPermission` |
| `data-role-editable="<角色列表>"` | 元素是否可编辑 | 字段级可编辑性矩阵；不可编辑时用 `disabled` + 灰底，并给出原因提示 |

关键约定：

- **不可编辑不等于不可见**。字段级只读时保留内容并置灰，让用户知道「有这条数据，只是你不能改」；
  完全无权限的数据范围则表现为查不到（`DS-DENY-07`），不显示占位。
- **前端不判定数据范围**。页头的 `scope-hint` 只是把后端解析结果展示出来；
  范围判定的唯一权威在后端 `DataScopeResolver`。
- **超级管理员**演示态可以看到全部入口，但危险动作仍走二次确认，且操作写审计。

## 4. 加载态

| 场景 | 表现 |
|---|---|
| 列表首屏加载 | 表格骨架（`el-skeleton`），保留表头与筛选区，不整页转圈 |
| 列表翻页 / 筛选 | 表格区域局部 loading（`el-table` 的 `v-loading`），筛选条保持可操作 |
| 详情抽屉 / 弹窗打开 | 内容区 loading，标题与关闭按钮立即可用 |
| 按钮提交 | 按钮进入 loading 并禁用，防重复提交；文案保持原样不改成「提交中」以外的省略号 |
| 异步任务 | 显示任务编号 + 进度条 + 预计剩余；离开页面后停止轮询 |
| 导出 / 导入超过阈值 | 明确提示「已转异步」，给出任务中心入口，不静默等待 |

## 5. 空态

空态分三种，文案与操作不同：

| 类型 | 判断 | 表现 |
|---|---|---|
| 无数据 | 范围内确实没有记录 | 图标 + 「暂无数据」+ 主行动按钮（如「新增学生」） |
| 无结果 | 有筛选条件但无匹配 | 图标 + 「没有符合条件的结果」+「清除筛选」按钮 |
| 无权限范围为空 | 数据范围为空集（`DS-DENY-03`） | 图标 + 「你的数据范围为空」+ 联系管理员说明；不显示新增按钮 |

三种空态都不允许出现裸白屏或只有一行灰字。

## 6. 错误态

错误态统一包含四部分：

```
错误码        例如 EDU-GRD-4002
请求编号      例如 REQ-20261001-000318
一句话原因    例如「同一学校同一学段已存在同名年级：高一」
下一步动作    「查看已有年级」/「返回列表」/「重试」
```

| 级别 | 载体 | 例子 |
|---|---|---|
| 字段级校验 | 表单字段下方红字 | 学号重复、年级序号超范围 |
| 业务规则拒绝 | 页面内错误片段或弹窗内提示 | 有在读学生不能删除班级 |
| 权限拒绝 | 403 页面（`403.html`） | 任课教师导出名单 |
| 服务异常 | 500 页面（`500.html`） | 未捕获异常，显示请求编号 |
| 降级提示 | 页面顶部横幅 | 审计日志写入失败 → 业务只读 |

阶段 6 的要求：错误码与请求编号**必须来自接口响应**，不允许前端自己拼一个错误码。

## 7. 危险动作二次确认

删除、停用、归档、覆盖、重放五类动作必须二次确认（`layout-spec.yaml` 的 `state_rules`）：

- 文案必须写清**对象**与**影响范围**（例：「停用高一 (1) 班，该班 42 名学生的班级归属保留，但不再出现在在读班级列表」）
- 原因必填的动作用 `el-input` 收集，后端二次校验（`EDU-SYS-4002` 之外按模块返回）
- 归档 / 重放这类影响面大的动作，要求输入对象名称确认
- 确认后写审计；重放复用原幂等键

确认载体统一用 `el-dialog`（`BC-COMMON-CONFIRM`）。

## 8. 跨页跳转与返回

| 路径 | 规则 |
|---|---|
| 列表 → 详情 | 优先抽屉（`el-drawer`）；需要表格或分页时用独立页 |
| 列表 → 新建 / 编辑 | `el-dialog`；字段超过两屏或需要分步时用独立页（如导入向导、升班向导） |
| 跨模块跳转 | 带查询参数（如 `?classId=xxx&termId=yyy`），返回时恢复筛选条件 |
| 跳转权限 | 目标页面无权限时直接进 403 页，不做「假入口 + 点进去报错」 |
| 面包屑 | 与侧边菜单层级一致；跨模块跳转时追加来源页面 |

带参数跳转在阶段 2 的 `navigation.yaml` 已登记，阶段 6 直接复用到路由 query。

## 9. 三档分辨率

| 档位 | 用途 | 关键约束 |
|---|---|---|
| 1366×900 | 教室与办公室主流笔记本 | 表格列宽之和必须等于 `min-width`，**不允许表格内横向滚动** |
| 1440×900 | 主流开发与办公显示器 | 内容区最大宽度 1360，两侧留白 |
| 1920×1080 | 大屏与演示 | 内容区不拉伸到全宽，保持信息密度 |

三档截图在 `screenshots/1366`、`screenshots/1440`、`screenshots/1920`，
由 `tools/capture_hifi_screenshots.ps1` 生成（headless Chrome）。

## 10. 与阶段 2 的差异

| 维度 | 阶段 2（业务原型） | 阶段 3（高保真） |
|---|---|---|
| 信息架构 | 已确定 | 不变 |
| 字段与动作 | 已确定 | 不变（`data-action-id` 与阶段 2 一一对应） |
| 状态片段 | 已登记 | 不变（片段集合由门禁校验一致） |
| 视觉 | Element Plus 默认 + 最小调整 | 按 `visual-spec.yaml` 精修 |
| 密度 | 相对宽松 | 表格行高 48px、控件高 36px、卡片内边距 20px |

阶段 3 **不改阶段 2 的任何文件**，两套原型并存，用于对照。

## 11. 阶段 6 的落地映射

| 原型机制 | 生产实现 |
|---|---|
| `data-normal-view` / `data-demo-state-panel` | `v-if / v-else-if` 状态分支 |
| `data-role-visible` | `v-permission="'person.student:create'"` |
| `data-role-editable` | 字段级 `disabled` + 只读原因提示 |
| 演示面板 | **不实现**（`BC-DEMO-PANEL` 已在 `business-components.yaml` 标记为不进入生产） |
| 页头 `scope-hint` | 后端返回的范围文案，组件 `BC-COMMON-SCOPE-HINT` |
| 错误片段 | `el-alert` / 表单校验 / 403、500 页 |

## 12. 验收方法

1. 打开 `prototypes/high-fidelity/v1/index.html`，进入任一页面
2. 用页脚演示面板切换角色，确认可见性与可编辑性变化符合字段级矩阵
3. 切换状态片段，确认主内容被**替换**而不是叠加
4. 触发危险动作，确认二次确认文案写清对象与影响范围
5. 在 1366 档检查表格是否有横向滚动（不应有）
6. 对照 `screenshots/` 的三档截图，确认无布局错位

阶段 3 的批量验收结论记录在 `prototypes/high-fidelity/v1/visual-checklist.md` 与
`evidence/stage3-highfidelity/`。
